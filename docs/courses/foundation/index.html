統計の基礎

4級・3級の内容をまとめて学び、2級へ進む。具体例を読み、問題で確かめながら進めます。詳しい説明は必要なときに開けます。

最初から学ぶ
読み方

基本の説明と例題を読んだら、解答を開く前に確認問題を考えてください。折りたたんだ発展部分は、後から読んでも構いません。

講座の本文・問題・詳しい説明を検索します。

保存した位置から再開

自分で付ける確認マークです。理解度・合格率の自動判定ではありません。記録はこのブラウザだけに保存し、別端末には同期しません。

図を動かして学ぶ · 出題範囲との対応を見る

第1章 データを読む前に

  1. F01統計で答えられる問いをつくる対象・期間・知りたいことを決め、記述と推測を区別する→
  2. F02データの1行・1列は何を表すか観測単位・変数・値を区別し、欠測と0を扱い分ける→
  3. F03データの種類と4つの尺度数値の見た目ではなく、順序・差・比の意味から判断する→
  4. F04母集団・標本と偏りのない選び方知りたい集団と調べた集団を分け、無作為とでたらめを区別する→
  5. F05観察と実験を区別する比較の条件を確かめ、無作為抽出と無作為割付を区別する→

第2章 表とグラフで整理する

  1. F06割合・百分率とパーセントポイント分母を決め、割合の差と増減率を計算する→
  2. F07度数分布表と累積度数階級・階級値・相対度数・累積相対度数を求める→
  3. F08ヒストグラム・幹葉図と分布の形階級幅・裾・山・外れ値を読み取る→
  4. F09棒・円・帯グラフを使い分ける棒・円・帯・積み上げ・絵・面・パレート図の用途を説明する→
  5. F10クロス集計表とモザイク図行比率・列比率を区別して2変数を比較する→
  6. F11複合グラフ・レーダー・バブル・ローソク足軸・面積・基準・単位を確認して特殊なグラフを読む→

第3章 中心と散らばりを数値で表す

  1. F12平均値・中央値・最頻値代表値を計算し、分布に合う要約を選ぶ→
  2. F13加重平均と度数分布表からの平均重みと階級値の近似を区別して平均を求める→
  3. F14四分位数・範囲・箱ひげ図四分位数の計算法を明示し、中心と散らばりを比較する→
  4. F15分散と標準偏差偏差の二乗を使う理由と分母nの意味を説明する→
  5. F16値を足す・掛けると平均や分散はどう変わるか単位変換と分散・標準偏差の性質を使う→
  6. F17標準化・z値・偏差値平均との差を共通の尺度にそろえ、正規化と混同しない→
  7. F18変動係数と外れ値の点検変動係数の条件を確認し、外れ値を機械的に削除しない→

第4章 関係と時間変化を読む

  1. F19散布図・共分散・相関係数関連の方向・強さと計算の意味を説明する→
  2. F20回帰直線・最小二乗法・予測係数・残差・予測の範囲を読む→
  3. F21相関・擬相関・因果関係第三の変数や逆方向の関係を検討する→
  4. F22時系列・指数・増減率・移動平均基準時点と平滑化を明示し、時間・地域の比較をする→

第5章 確率を考える

  1. F23試行・事象と確率同様に確からしい条件と標本空間を確認する→
  2. F24余事象と加法定理少なくとも・または・両方を区別する→
  3. F25樹形図と場合の数漏れ・重複を避け、順序を区別して数える→
  4. F26独立な試行と繰返し掛け算の条件と復元・非復元の違いを説明する→
  5. F27条件付き確率条件で対象を絞り直して確率を求める→
  6. F28確率と実際の頻度の違い有限回の結果のぶれを理解し、シミュレーションを読む→

第6章 確率分布を使う

  1. F29確率変数・期待値・分散値と確率の表から平均と散らばりを計算する→
  2. F30二項分布成功確率と試行回数を定めて確率を求める→
  3. F31連続分布と正規分布の面積密度の高さと確率を区別して分布を読む→
  4. F32正規分布表と1.96の使い方片側・両側と標準化の条件を確認する→
  5. F33二項分布の正規近似近似の条件と連続性補正の意味を理解する→

第7章 標本から全体を考える

  1. F34標本平均・標本比率の分布標本分布と標準誤差を元データの分布から区別する→
  2. F35母平均の区間推定母分散既知の基本式と信頼係数の意味を説明する→
  3. F36母比率の区間推定近似の条件を確認して母比率の区間を求める→
  4. F37仮説検定・p値・有意水準帰無仮説のもとの確率と仮説自体の確率を区別する→
  5. F38母平均・母比率の検定を使う対象と条件に応じて基本的な検定を使い分ける→

第8章 2級へつなぐ

  1. F39方法を選び、結果と限界を伝える問い・データ・方法・結果・限界を一つの報告にまとめる→
  2. F40基礎の総合確認と2級への準備初見の例で基礎を確かめ、数式・推定・検定の補習先を判断する→

このコースの範囲

4級・3級の公式出題範囲をもとに構成しています。基礎40講座を公開しています。各テーマの説明・問題との対応は範囲対応表で確認できます。全種類の本試験問題を再現した教材や、合格を保証するものではありません。試験の公式教材・公認講座ではありません。
