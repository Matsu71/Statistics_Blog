出題範囲と講座・演習の対応 · 確率・正規分布・信頼区間を動かす

第1章 基礎を2級の道具へつなぐ

  1. G01母数・推定量・観測値と総和記号ランダムに変わる量と観測後の数値を区別し、式を読む→
  2. G02分散・歪度・尖度と定義の違いnとn−1、高次の中心モーメント、外れ値の影響を区別する→
  3. G03ローレンツ曲線とジニ係数累積比率の図から面積を計算し、不均等を解釈する→
  4. G04幾何平均・指数・系列相関成長率を連鎖させ、基準時点と時間依存を読む→

第2章 推測できるデータを集める

  1. G05標本抽出法と有限母集団補正抽出法と重みを選び、標本誤差と偏りを区別する→
  2. G06実験計画とフィッシャーの3原則無作為化・反復・局所管理の役割を実験の設計へ使う→

第3章 確率モデルを組み立てる

  1. G07条件付き確率とベイズの定理条件の向きと分母を確かめ、多段階の確率を求める→
  2. G08同時分布・周辺分布・独立二変数の表から周辺と条件付き分布を作る→
  3. G09期待値・分散・共分散と和や差共分散を残す必要があるか判断して線形結合を計算する→
  4. G10密度・分布関数・変数変換積分を面積として使い、変換後の値域と密度を求める→

第4章 分布を選び、確率を求める

  1. G11二項分布と超幾何分布復元の有無と固定した試行回数から成功数の分布を選ぶ→
  2. G12幾何分布と負の二項分布何を数えて止めるかを定め、値域と式を対応させる→
  3. G13ポアソン分布と指数分布単位時間あたりの回数と待ち時間を区別する→
  4. G14正規分布と2変量正規分布標準化・線形結合・条件付き分布を条件とともに使う→

第5章 標本分布から推測へ

  1. G15標本平均・標本比率・不偏分散標本分布の平均と分散を求め、n−1の根拠を説明する→
  2. G16大数の法則・中心極限定理・正規近似不等式の上界と近似を区別し、連続修正を使う→
  3. G17t分布と分布表の読み方標準誤差の推定と自由度の意味を理解して分位点を読む→
  4. G18カイ二乗分布・F分布と分位点二乗和と分散比から分布を選び、裾と自由度を対応させる→

第6章 母数を推定する

  1. G19不偏性・一致性・平均二乗誤差推定量の性質を有限標本と極限に分けて評価する→
  2. G20母平均の区間推定：zとt分散既知・未知の条件で区間を作り被覆率を解釈する→
  3. G21平均差の区間推定：対応と等分散対応あり、分散既知、等分散、Welchを選び分ける→
  4. G22母比率と比率差の区間推定近似の条件と標準誤差を確かめ、区間を作る→
  5. G23母分散と分散比の区間推定非対称な分位点を使い、不等式の逆数操作を理解する→
  6. G24相関行列・偏相関・相関の区間推定関連の調整とFisher変換を、因果推論と区別して使う→

第7章 仮説を検定する

  1. G25仮説・p値・片側と両側仮説のもとでの確率と仮説が真の確率を区別する→
  2. G262種類の過誤・検出力・標本サイズ効果と標準誤差から検出力を考える→
  3. G27一つの母平均の検定z検定とt検定を選び、統計量・p値・結論を結ぶ→
  4. G28平均差の検定：独立2群と対応ありデータの対応と分散の条件から検定を選ぶ→
  5. G29母比率と比率差の検定帰無仮説のもとの比率を使って標準誤差を求める→
  6. G30母分散と分散比の検定正規性・自由度・片側両側を確認して分散を比べる→

第8章 カテゴリの度数を比べる

  1. G31カイ二乗適合度検定期待度数・推定した母数・自由度を対応させる→
  2. G32クロス集計と独立性の検定周辺合計から期待度数を求め、関連と効果を区別する→

第9章 回帰と分散分析で説明する

  1. G33単回帰の推定と標準誤差最小二乗・残差分散・係数の不確かさをつなぐ→
  2. G34回帰の検定・信頼区間・予測区間平均応答と新しい観測の予測を区別する→
  3. G35重回帰・偏回帰係数・ダミー変数ほかの変数を一定とする意味と基準カテゴリを読む→
  4. G36残差診断・多重共線性・調整済み決定係数当てはまりとモデルの条件・予測性能を別々に評価する→
  5. G37一元配置分散分析平方和・自由度・F比を計算し、全体検定を解釈する→

第10章 出力を読み、問題を解決する

  1. G38解析出力を読み、手法を選ぶ係数表・分散分析表・区間を計算と結び付けて読む→
  2. G39データから分析と報告を再現する原データ・出典・手順・結果・限界を一つの分析にそろえる→
  3. G402級の総合演習と準1級への接続初見の混合問題で条件・方法・解釈を確かめる→
