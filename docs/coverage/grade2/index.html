公式範囲の行をもとに整理した27項目群です。既習の基礎を再利用し、2級で必要な条件・計算・解釈へ進みます。

項目群への対応は、すべての出題形式や合格を保証する意味ではありません。公式の認定教材ではありません。折りたたみの証明は、基本の試験対策では任意の発展も含みます。
