まず「1件」が何かを読む

データの表は、数字を入れるだけの箱ではありません。同じ4行の表でも、4人の記録、1人の4日分の記録、4回の受付の記録では意味が変わります。どれも行数は4ですが、調べた人数が4人とは限りません。

一つの記録が何を表すかを、観測単位と呼びます。この講座では、学習室の「1回の来室」を1件として記録する例を使います。来室者を匿名のIDで区別し、同じ人が別の日に来た場合も別の1件にします。以下の表は説明用の架空データです。

来室者ID来室日予約方法待ち時間（分）
A019月1日アプリ4
A029月1日窓口0
A039月1日ウェブ未記録
A019月2日アプリ8

この表には4回の来室、3人の来室者が含まれます。A01の2行は日付が違うため、この記録のルールでは重複入力ではありません。「同じIDがあるから削除する」と判断してはいけません。

列は変数、セルは観測値

記録する特徴や項目を変数、個々の記録で得られた内容を観測値と呼びます。待ち時間は変数、最初の行の「4分」は観測値です。予約方法も変数で、「アプリ」はその値です。変数は数値でなければならない、ということではありません。[1]

ここでいう変数は、方程式の未知数だけを指す言葉ではありません。「観測対象ごとに値を記録する項目」と考えると分かりやすくなります。ある小さな標本の中で、たまたま全員が同じ値を持つ項目も、変数として扱えます。

見る場所この表での意味
1行1回の来室についての記録
待ち時間の列各来室で測定する特徴
最初の行の4A01の9月1日の待ち時間という観測値
来室者ID別の来室でも同じ人と分かるための識別情報

IDは計算の対象というより、記録を対応させるために使います。IDに数字を使っても、その平均が利用者の特徴を示すわけではありません。数値の形をしていても数量とは限らない点は、次の尺度の講座で詳しく扱います。

「未記録」と「0分」は別の情報

A02の0分は、記録の定義に従って「待たずに受付が始まった」と分かった値です。一方、A03の未記録は、待ち時間が分からない状態です。これを欠測と呼びます。

記録されている待ち時間の平均なら、4、0、8の3件を使い、

4+0+83=4分\frac{4+0+8}{3}=4\text{分}34+0+8​=4分

です。欠測を勝手に0にすると、12/4=312/4=312/4=3 分になり、元の情報とは異なる計算になります。また、0分を「値がない」と除いても、(4+8)/2=6(4+8)/2=6(4+8)/2=6 分と変わってしまいます。

この4分は、あくまで待ち時間が記録された3件の平均です。欠測を除けば利用者全体を正しく推測できる、という結論ではありません。例えば、忙しいときほど記録が抜けるなら、記録された値だけでは長い待ち時間を見落とす可能性があります。欠測の扱いは、数値の穴埋めだけでなく、なぜ欠けたかも含めて考えます。

行数を、そのまま人数や独立な件数にしない

上の表から「4人を調べた」と書くのは誤りです。調べた来室者はA01、A02、A03の3人です。来室ごとのサービス状況を調べるなら4件という数え方は自然ですが、人ごとの体験を比べたいなら、同じ人の複数回の記録をどうまとめるかを決めます。

例えばA01の記録は4分と8分なので、その人の観測された2回の平均は6分です。人ごとの平均と、来室ごとの平均では、何を一つとして数えるかが違います。頻繁に来る人の記録が多い表で、来室をすべて同じ重みで平均すると、その人の経験が多く反映されます。

さらに、同じ人の複数回の記録は、その人に共通する行動や条件を持つ場合があります。行が別だから互いに独立だとは限りません。ここでは独立性の数式は不要ですが、後で推定や検定を使うときの大切な確認事項です。

集計前の小さな点検

表を受け取ったら、1件の定義、測定単位、対象期間、欠測の記号を確認します。待ち時間の120が秒なら2分ですが、分なら120分です。単位のない数字は、そのまま比べられません。

次に、同じ出来事の二重登録と、同じ対象の別の観測を区別します。来室者IDと日付だけでは、同じ日に2回来た記録を区別できない場合もあります。必要なら受付番号や時刻を追加します。「どの列の組合せが一つの出来事を識別するか」を決める作業です。

最後に、集計に使った件数を結果と一緒に書きます。「平均4分」より「記録がある3件の平均4分」の方が、読み手はどの情報に基づく数字かを判断できます。これは難しい数式以前の、分析の再現性を支える習慣です。

確認問題

問1：行数と人数

本文の表について、来室記録は何件、来室者は何人、待ち時間が記録されているのは何件ですか。

解答と考え方

来室記録は4件、来室者は3人、待ち時間の記録は3件です。A01は2回来室しています。A02の0分は有効な観測値なので、待ち時間が記録された件数に含めます。

問2：欠測を0にすると

本文の未記録を0分として計算した平均と、記録がある値だけの平均を、それぞれ求めてください。どちらが「記録がある3件の平均」ですか。

解答と考え方

0で埋めた計算は 12/4=312/4=312/4=3 分、記録がある値だけの計算は 12/3=412/3=412/3=4 分です。後者が質問への答えです。前者は、未記録だった待ち時間を0分と仮定した別のデータを計算しています。どちらも、追加の検討なしに全利用者の平均とは言えません。

問3：同じIDを見つけたら

ある表で同じ利用者IDが2行ありました。「重複だから片方を消す」と決める前に、何を確認しますか。

解答例と考え方

一行が人を表すのか、来室や測定を表すのかを確認し、日付・時刻・受付番号を見ます。別の来室なら残す必要があります。同じ出来事を誤って二重登録したと確認できた場合に、修正方法を記録して処理します。

詳しく確かめる

なぜ「人ごとの平均」と「来室ごとの平均」は違うのか（重みの数値例）

欠測のない別の架空例を考えます。Pさんは1回来室して2分、Qさんは3回来室して毎回10分待ちました。来室ごとの平均は、

2+10+10+104=8分.\frac{2+10+10+10}{4}=8\text{分}.42+10+10+10​=8分.

人ごとの平均待ち時間はPさんが2分、Qさんが10分なので、2人を同じ重みで平均すると、

2+102=6分.\frac{2+10}{2}=6\text{分}.22+10​=6分.

8分と6分のどちらかが計算ミスなのではありません。前者は来室という出来事を等しく扱い、後者は人を等しく扱っています。知りたい対象に合う集計単位を選び、その単位を明記する必要があります。加重平均は後の講座で一般化します。
