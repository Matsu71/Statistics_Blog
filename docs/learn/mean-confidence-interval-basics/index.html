母平均の区間推定

標本平均のぶれを使って、未知の母平均を区間で推定します。95%が何に対する割合かと、σが未知のときの違いを確認します。

読む目安 12分 ＋ 確認問題 8分（編集上の目安）

このページでできること

  • 母分散既知の正規モデルで、母平均の信頼区間を作る。

  • 信頼区間と個々の値の範囲、z法とt法を区別する。

平均52だけでは、推定のぶれが見えない

未知の母平均μを知るため、同じ正規分布から独立にn=100個を観測し、標本平均が52だったとします。母標準偏差σ=10は別の根拠により既知とする、説明用の仮想モデルです。

標本平均52は点推定値ですが、別の100個なら違う平均になる可能性があります。標準誤差は10/√100=1です。この変動の大きさを使って、母平均を区間で推定します。σが既知という条件は教材上の前提で、現実で標本標準偏差を計算しただけで「既知」にはなりません。

標準誤差の1.96倍を左右へ取る

正規・独立・σ既知の条件では、母平均の95%信頼区間は、正確な標準正規分位点をcとして xˉ±cσ/n\bar x\pm c\sigma/\sqrt nxˉ±cσ/n​ です。c≈1.96を使うと、

52±1.96×10100=52±1.96=[50.04,53.96].52\pm1.96\times\frac{10}{\sqrt{100}} =52\pm1.96=[50.04,53.96].52±1.96×100​10​=52±1.96=[50.04,53.96].

点推定値を中心として、その標準誤差に基づく幅を付けたものです。母平均μが未知で、区間の両端は観測データから決まります。

正規分布でない母集団でも、中心極限定理などの条件のもとで平均の正規近似を使う区間は作れますが、その場合は近似です。母分布に極端な歪みや依存がある場合など、形式的に1.96を付けるだけでは妥当性は保証されません。[1]

95%は、方法を繰り返したときの割合

同じ母集団から同じ方法で標本を取り直し、そのたびに区間を作るとします。仮定が正しく、正確な95%区間の方法なら、生成される区間が固定した母平均μを含む確率は95%です。

観測前には区間の両端がランダムに変わり、母平均は固定です。観測後の[50.04,53.96]は固定した一つの区間で、その中でμが95%の確率で動き回るという説明ではありません。母数自体へ確率分布を置くベイズの信用区間とは、構成と解釈を区別します。

また、100回作れば必ずちょうど95本が当たるという意味でもありません。有限回の被覆本数もばらつきます。正しい被覆率は、モデルの仮定と区間構成の方法に関する性質です。

区間の中に、データの95%が入るわけではない

ここで推定するのは母平均μです。個々のXの標準偏差は10ですが、標本平均のSEは1でした。個々の値の大半を囲みたいなら、それは別の区間の問題です。

母平均μとσが両方既知の正規分布なら、個々の値の中央約95%はμ±1.96σです。しかしμを推定しているときの将来観測の予測区間には、推定の不確かさも入ります。xˉ±1.96σ\bar x\pm1.96\sigmaxˉ±1.96σ を自動的に厳密な予測区間と呼ばないようにします。

信頼区間が狭いことと、個々の観測がそろっていることも別です。大きなnを使えば、個々のSDが大きくても平均を精密に推定できる場合があります。何に対する不確かさかを常に指定します。

信頼度と標本サイズで幅は変わる

同じデータで99%信頼区間にすると、より広く母平均を覆う手続きを使うため、分位点は約2.576となり幅が広がります。「確信を高めれば区間が狭くなる」ではありません。

同じσ・同じ信頼係数なら半幅はnの平方根に反比例します。n=100から400へ増やすと半幅は1.96から0.98へ半分になります。逆に、望む半幅hを決めると、おおよその必要標本数は (1.96σ/h)2(1.96\sigma/h)^2(1.96σ/h)2 以上の整数です。

この標本サイズ設計は、既知σや同じ抽出条件という仮定を持ちます。非回答や集落内の依存がある調査では、単純な式の人数を集めれば同じ精度を得られるとは限りません。

母分散が未知なら、t分布を使う

独立な正規標本でσが未知なら、不偏分散の平方根sを使い、xˉ±tn−1,0.975s/n\bar x\pm t_{n-1,0.975}s/\sqrt nxˉ±tn−1,0.975​s/n​ とする方法が基本です。自由度n−1のt分布の分位点は、小標本では1.96より大きくなります。[1]

例えばn=10、平均53、s=3なら、自由度9の分位点約2.262157を用い、53±2.146071、つまり約[50.8539,55.1461]です。sをσの代わりに入れて同じ1.96で正確な区間だとすることはできません。t分布の導出は2級への発展として扱いますが、既知と未知の違いは今から明示します。

確認問題

問1：信頼区間を作る

正規・独立、既知σ=10、n=100、標本平均52です。1.96を使った95%信頼区間を求めてください。

解答と理由

[50.04,53.96]です。SEは10/10=1です。個々のSD10をそのまま左右に掛けた[32.4,71.6]は、求める母平均の信頼区間ではありません。

問2：95%の説明

「今回の信頼区間には、観測したデータの95%が入る」という説明は正しいですか。

解答と理由

正しくありません。区間の対象は母平均です。同じ手続きを繰り返して作る区間が、固定した母平均を覆う確率として95%を説明します。

問3：必要標本サイズ

σ=10、1.96を使い、区間の半幅を1以下にしたいとします。必要なnを整数で求めてください。

解答と理由

n≥(1.96×10/1)²=384.16なので、切り上げて385です。384へ丸めると指定の半幅を満たしません。nは個数なので整数にします。

詳しく確かめる

標準化の不等式を、未知の母平均について解く

正規の独立標本でσ>0既知なら、Z=(平均−μ)/(σ/√n)は標準正規分布です。c=z₀.₉₇₅とするとP(−c≤Z≤c)=0.95です。σ/√n>0を掛けて、μについて整理すると、

P(Xˉ−cσn≤μ≤Xˉ+cσn)=0.95.P\left(\bar X-c\frac\sigma{\sqrt n}\le\mu\le\bar X+c\frac\sigma{\sqrt n}\right)=0.95.P(Xˉ−cn​σ​≤μ≤Xˉ+cn​σ​)=0.95.

この確率は標本Xのランダム性に対して取っています。未知だが固定のμが、ランダムに生成される区間に含まれる事象です。観測後はXをxへ置き換えて区間を報告します。cを1.96へ丸めた場合、被覆率は約0.95000421です。

σ未知のt法では、独立正規標本の (Xˉ−μ)/(S/n)(\bar X-\mu)/(S/\sqrt n)(Xˉ−μ)/(S/n​) が自由度n−1のt分布に従うという定理を前提に、同じ不等式の反転を行います。その定理自体の証明と、この区間への変形は別の段階です。
