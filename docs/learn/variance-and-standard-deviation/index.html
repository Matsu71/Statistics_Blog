平均が同じでも、待ち方は違う

4回の待ち時間が2、4、6、8分だった場合と、5、5、5、5分だった場合を比べます。どちらの平均も5分ですが、後者は全値が同じで、前者は散らばっています。平均からどのくらい離れているかを数値にするのが、この講座の目的です。データは架空の例です。

各値から平均を引いた差を偏差と呼びます。2、4、6、8なら、平均5からの偏差は−3、−1、1、3です。負の値は平均より小さく、正の値は大きいことを示します。

ずれを足すだけでは、打ち消し合う

偏差を合計すると−3−1+1+3=0です。ばらついているのに合計は0になりました。平均からの偏差の和は、いつも0です。散らばりを測りたいときに、そのまま平均しても役に立ちません。

そこで偏差を二乗し、非負の大きさとして足す方法を使います。絶対値を使う指標もありますが、分散は二乗を使うと定義した指標です。二乗により、遠く離れた値へ強く反応します。

分散は、偏差の二乗の平均

この講座の記述統計では、全 nnn 個の偏差の二乗和を nnn で割ったものを分散 vvv と書きます。

v=1n∑i=1n(xi−xˉ)2.v=\frac1n\sum_{i=1}^n(x_i-\bar x)^2.v=n1​i=1∑n​(xi​−xˉ)2.

例では v=20/4=5v=20/4=5v=20/4=5 です。待ち時間の単位が分なので、分散の単位は分の二乗です。分散5を「平均から平均5分離れている」と解釈しません。ずれの二乗を平均した値だからです。

全値が5分なら、偏差はすべて0で分散も0です。逆に、実数データで分散0なら各二乗がすべて0なので、全値が平均と等しいことが分かります。分散が負になることはありません。計算でごく小さな負値が出る場合は、数値計算の丸め誤差などを疑います。

標準偏差は、元の単位で散らばりを見る

分散の平方根を標準偏差 sns_nsn​ とします。添字の nnn は、この講座では分散の分母が nnn であることを区別するためです。

sn=v=5≈2.236分.s_n=\sqrt v=\sqrt5\approx2.236\text{分}.sn​=v​=5​≈2.236分.

単位が元の分へ戻り、平均5分と一緒に読みやすくなります。標準偏差は平均からのずれの二乗平均平方根であり、絶対偏差の単純平均ではありません。この例の絶対偏差平均は(3+1+1+3)/4=2分で、標準偏差とは違います。

標準偏差が2.236分でも、すべての値が平均±2.236分へ入るとは限りません。正規分布についての「約68%が±1標準偏差」は、分布の形に関する条件付きの性質です。どんなデータにもその割合を当てはめません。

分母がn−1の式もある

母集団の分散を標本から推定するとき、偏差の二乗和を n−1n-1n−1 で割る不偏分散を使うことがあります。

s2=1n−1∑i(xi−xˉ)2(n≥2).s^2=\frac1{n-1}\sum_i(x_i-\bar x)^2\quad(n\ge2).s2=n−11​i∑​(xi​−xˉ)2(n≥2).

この例では20/3です。分母 nnn の5と違いますが、一方が計算ミスなのではありません。記述するための分散と、一定の標本抽出・確率モデルのもとで母分散を不偏推定する量の違いです。

「標本分散」という言葉にどちらの分母を使うかは文献で揺れることがあります。名称だけで判断せず、式と分母を確認します。本基礎コースのデータ要約では原則 nnn、母分散の推定で不偏分散を使う場合は n−1n-1n−1 と明記します。標準偏差の平方根を取った量まで自動的に不偏になるわけではありません。

計算を点検する

平均→偏差→二乗→合計→分母→平方根の順で表を作ると、何をしたか追えます。平均を早い段階で丸めると、偏差の和が0からずれて誤差を生むので、途中は十分な桁を残します。

後で使う「二乗の平均−平均の二乗」という同値な式は計算を短くできますが、大きくてほぼ同じ値を引く数値計算では精度が悪くなる場合があります。定義に戻って検算する習慣が大切です。

確認問題

問1：表から計算する

2、4、6、8の、分母 nnn の分散と標準偏差を求めてください。

解答と理由

平均5、二乗和20なので分散5、標準偏差 5≈2.236\sqrt5\approx2.2365​≈2.236 です。偏差の和0を分散として使わず、二乗してから足します。

問2：分母の違い

同じ4件の不偏分散と、分母nの分散との比を求めてください。

解答と理由

不偏分散20/3、比は(20/3)/5=4/3です。同じ二乗和を3で割るか4で割るかの違いです。母分散そのものがこの比で変わったわけではありません。

問3：標準偏差から言えること

平均5、標準偏差約2.236なので、「全員が約2.764〜7.236に入る」と言えますか。

解答と理由

言えません。実際のデータに2と8があります。標準偏差は全値を囲む最大距離ではなく、ずれの二乗を平均して平方根を取った尺度です。

不偏分散の n−1n-1n−1 の理由は、独立同分布で有限分散 σ2\sigma^2σ2 の確率変数を想定したとき、標本平均からの二乗和の期待値が (n−1)σ2(n-1)\sigma^2(n−1)σ2 になることです。ここでは結論の紹介にとどめ、期待値を学ぶ第29・34講で根拠を確かめます。有限のデータに関する上の恒等式と、確率モデルを使う不偏性を区別します。
