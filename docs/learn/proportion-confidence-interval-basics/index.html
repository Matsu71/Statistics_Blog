母比率の区間推定

標本の賛成率から、全体の割合の不確かさを考えます。基本の正規近似区間と、少数・端の割合での失敗を分けて学びます。

120人が賛成でも、全体が正確に60%とは限らない

同じ対象集団から独立に選ばれたとみなせる200人に、同じ二択の質問をし、120人が賛成したという架空の例です。回答の欠測はなく、各人の賛成確率が共通pの二項モデルを使います。標本比率は p^=120/200=0.6\hat p=120/200=0.6p^​=120/200=0.6 です。

標本を取り直せば、賛成者数と標本比率は変わります。標本比率の標準誤差は√(p(1−p)/n)ですが、未知のpが入っています。基本的な近似区間では、そのpを観測された p^\hat pp^​ で置き換えます。

基本のWald区間を計算する

正規近似と標準誤差の代入近似を使った区間を、Wald区間と呼びます。95%の場合は、

p^±1.96p^(1−p^)n.\hat p\pm1.96\sqrt{\frac{\hat p(1-\hat p)}n}.p^​±1.96np^​(1−p^​)​​.

例の推定SEは√(0.6×0.4/200)≈0.034641、半幅は約0.067896です。区間は約[0.532104,0.667896]、百分率なら53.21〜66.79%になります。

0.067896は約6.79パーセントポイントの半幅です。「60%から相対的に6.79%増減する」という読み方ではありません。第6講の割合と増減率の区別をここでも使います。

公式と一緒に、使える条件を見せる

独立性、共通のp、対象に届く標本の取り方を確認します。さらに成功・失敗の観測数が十分に多いかを見ます。n p^\hat pp^​ とn(1− p^\hat pp^​ )がそれぞれ10以上という目安なら、この例の120と80は満たします。[1]

ただし、目安を満たしたら被覆率が厳密に95%になるという保証ではありません。Wald区間は特に小標本やpが0・1に近い場合に問題があり、区間の選択には注意が必要です。基礎の式を学ぶことと、あらゆる実務で第一選択にすることは分けます。

非復元抽出で母集団の大きな割合を調べた場合には有限母集団修正、集落や繰返し測定で依存があるならその設計に合う方法が必要です。インターネットの自由回答を多数集めても、この区間が選択の偏りを自動的に直すわけではありません。

0件だから、区間も0でよいか

20件中成功が0件なら、p^=0\hat p=0p^​=0 を上の式へ代入すると[0,0]になります。しかし、少ない試行で成功が一度もなかったことは、母比率pが必ず0という証拠ではありません。例えばp=0.1でも、独立20回で成功0回の確率は0.9²⁰≈0.1216です。

これは式の適用条件を無視した結果の例です。計算が実行できることと、正しい被覆率を持つ区間が得られることは別です。負の下限や1を超える上限が出たときも、端を単に0と1へ切り取れば近似の問題が解決するわけではありません。

小標本や端の割合には、Wilson区間や二項分布に基づく区間などを検討します。どの区間にも前提と性質があり、方法名と信頼係数を示します。異なる方法で計算した区間の端が違っても、すぐ計算ミスとは言えません。

Wilson区間との比較

Wilson区間は、推定値を中心に左右対称に置くWald区間とは異なる構成です。1.96を使って計算すると、120/200のWilson区間は約[0.530835,0.665395]です。0/20の場合は約[0,0.161130]となり、幅0ではありません。[2]

120/200約[0.5321,0.6679]約[0.5308,0.6654]
0/20[0,0]：この用途では不適切約[0,0.1611]

Wilsonも任意の依存や選択の偏りを補正する方法ではなく、有限標本で必ず被覆率が95%以上という保証を持つわけでもありません。ここでは基礎式の限界を理解する比較として示し、詳しい導出を下に分けています。

95%の意味と、必要な標本サイズ

解釈は母平均の信頼区間と同様です。適用条件のもとで、同じ構成を繰り返した区間が固定したpを覆う割合を評価します。観測された一つの区間の中でpが動くという説明や、回答者の95%がこの区間の値を持つという説明ではありません。

調査前にpが分からず、単純な正規近似の標本サイズ設計をする場合、p(1−p)≤1/4を使えます。95%の半幅を0.05以下にしたい目安なら、n≥1.96²×0.25/0.05²=384.16なので385です。これは二項近似上の設計値で、非回答・依存・調査の偏りを無視した万能な人数ではありません。

確認問題

問1：基本区間

200人中120人が賛成です。二項モデルのWald区間を1.96で計算してください。

解答と理由

標本比率0.6、推定SE約0.034641、区間約[0.532104,0.667896]です。SEでは0.6×0.4を使い、0.6だけを200で割って平方根を取ることはしません。

問2：成功0件の解釈

20回で成功0回でした。p=0.1のモデルで、この結果の確率を求め、母比率0と確定できるか説明してください。

解答と理由

0.9²⁰≈0.1216です。p=0.1でもこの観測は起こり得るため、母比率0と確定できません。Wald式が[0,0]を返すことを正当化せず、条件と別の区間法を検討します。

問3：標本サイズの目安

二項正規近似でpの事前情報がなく、95%区間の半幅0.05を目指します。p(1−p)の上界を使ったnはいくつですか。

解答と理由

385です。上界1/4からn≥384.16を得て切り上げます。実際の調査設計や未回答の影響は別に考慮します。

詳しく確かめる

Wilson区間を、pについての二次不等式から導く

n>0、標本比率q=k/n、正の基準値zを使います。正規近似の統計量について、候補pを n(q−p)2≤z2p(1−p)n(q-p)^2\le z^2p(1-p)n(q−p)2≤z2p(1−p) を満たすものとして集めます。展開すると、

(n+z2)p2−(2nq+z2)p+nq2≤0.(n+z^2)p^2-(2nq+z^2)p+nq^2\le0.(n+z2)p2−(2nq+z2)p+nq2≤0.

上に開く二次式なので、二つの根の間が区間です。解の公式を整理すると、

q+z2/(2n) ± zq(1−q)/n+z2/(4n2)1+z2/n.\frac{q+z^2/(2n)\ \pm\ z\sqrt{q(1-q)/n+z^2/(4n^2)}}{1+z^2/n}.1+z2/nq+z2/(2n) ± zq(1−q)/n+z2/(4n2)​​.

q=0なら根は0とz²/(n+z²)です。n=20,z=1.96で上限約0.16113になります。端では、分母にpを含む標準化を直接定義せず、この二次不等式と連続な端の扱いで解釈できます。

ここで完全に解いたのは、正規近似の不等式から区間の公式を得る代数的導出です。二項分布の有限標本の被覆率が厳密に95%になることを証明したのではありません。
