余事象と加法定理

「AまたはB」「AかつB」「Aでない」を、結果の集合として読みます。重複して数えた分を引く理由まで確かめます。

「または」は、両方も含めます

公平なさいころを一回投げます。Aを偶数{2,4,6}、Bを4以上{4,5,6}とします。AまたはBは、AかBの少なくとも一方に入る結果で、{2,4,5,6}です。4と6は両方の条件を満たしますが、和事象に含みます。

数学の「または」は原則として、両方の場合も含める使い方です。「どちらか片方だけ」と指定された場合は、両方を満たす結果を除く別の条件になります。日常の言い方に引きずられず、どの結果を含むかを列挙すると確かめられます。

表現記号この例の結果
AまたはBA∪BA\cup BA∪B2、4、5、6
AかつBA∩BA\cap BA∩B4、6
AではないAcA^cAc1、3、5
AかBの片方だけ—2、5

二つの確率を足すだけでは、重なりを二回数える

P(A)=3/6、P(B)=3/6です。そのまま足すと1になりますが、AまたはBは4/6です。違いは、4と6をAで一度、Bでもう一度数えたためです。

重なりの確率P(A∩B)=2/6を一回分引けば正しい和になります。

P(A∪B)=P(A)+P(B)−P(A∩B).P(A\cup B)=P(A)+P(B)-P(A\cap B).P(A∪B)=P(A)+P(B)−P(A∩B).

この例は3/6+3/6−2/6=4/6=2/3です。加法定理は、AとBが独立かどうかに関係なく使えます。必要なのは同じ標本空間・同じ確率モデルで事象を扱っていることです。

排反なら、重なりがない

同時に起こらない事象を排反と呼びます。例えば一回のさいころの「1が出る」と「2が出る」は排反で、積事象は空集合です。重なりがないので和事象の確率は1/6+1/6=1/3です。

排反だから独立、とは言いません。「1が出た」と分かれば「2が出る」ことはなくなるため、二つの出来事は情報として無関係ではありません。独立は第26講で定義しますが、ここでは排反は同時に起こらないことと覚えます。

逆に、AまたはBの確率を単純な足し算で求めるには、重なりが0であることを確認します。重なっているか分からない段階で、都合よく排反とみなしてはいけません。

起こらない方を考えると、数えやすい

Aが起こらない事象 AcA^cAc を余事象と呼びます。Aと AcA^cAc は重ならず、合わせると全体になるので、

P(Ac)=1−P(A).P(A^c)=1-P(A).P(Ac)=1−P(A).

例えば6以外の目を一つずつ足す代わりに、1−1/6=5/6と計算できます。何の「反対」かを正確に決めることが必要です。「少なくとも一回成功する」の余事象は「一度も成功しない」です。「ちょうど一回成功する」の余事象には、0回だけでなく2回以上も入ります。

不等号の否定にも注意します。「Xが3以上ではない」はX<3です。境界を含むかどうかは、離散的な値では確率の違いに直接影響します。

同じ集合を、別の切り分け方で見る

AまたはBを「Aだけ」「Bだけ」「両方」の三つへ分けると、互いに重なりません。この例ではAだけ{2}、Bだけ{5}、両方{4,6}なので1/6+1/6+2/6=4/6です。

「どちらも起こらない」は、AまたはBが起こらないことです。従って確率は1−P(A∪B)=1/3で、結果は{1,3}です。一方、「少なくとも一方は起こらない」は両方同時の否定なので、1−P(A∩B)=2/3です。日本語が似ていても事象は違います。

数式を覚えるときも、どの領域を数えているのかへ戻れるようにします。大きな標本空間で列挙しづらくなっても、小さな例や表で条件を検証する習慣は役立ちます。

確認問題

問1：和事象と積事象

本文のAが偶数、Bが4以上のとき、AまたはBの確率と、AかつBの確率を求めてください。

解答と理由

和事象は{2,4,5,6}で2/3、積事象は{4,6}で1/3です。「または」の中には両方の場合も含めます。

問2：片方だけ

同じ例で、AかBの片方だけが起こる確率を求めてください。

解答と理由

結果は{2,5}で1/3です。和事象の確率2/3から、両方の確率1/3を引いても求められます。和事象と片方だけを混同しません。

問3：余事象を言葉にする

3回の試行で「少なくとも一回成功」と「ちょうど一回成功」の余事象を、それぞれ説明してください。

解答と理由

前者は成功0回、後者は成功0回または2回または3回です。「少なくとも」と「ちょうど」では、含める成功回数が違います。具体的な確率は各試行のモデルを決めてから計算します。

詳しく確かめる

加法定理と余事象の式を、重ならない分割から証明する

Aだけの領域を A∖BA\setminus BA∖B、Bだけを B∖AB\setminus AB∖A、両方を A∩BA\cap BA∩B とします。三つは互いに排反です。P(A)はAだけと両方の和、P(B)はBだけと両方の和なので、P(A)+P(B)では両方が二回入ります。その一回分を引くと三領域を一度ずつ足したP(A∪B)になります。

Aと AcA^cAc も排反で、和は標本空間Ωです。従って P(A)+P(Ac)=P(Ω)=1P(A)+P(A^c)=P(\Omega)=1P(A)+P(Ac)=P(Ω)=1 から余事象の式を得ます。

また、集合として (A∪B)c=Ac∩Bc(A\cup B)^c=A^c\cap B^c(A∪B)c=Ac∩Bc です。「どちらでもない」と「少なくとも一方の否定」の読み分けは、このように一つの結果が条件を満たすかどうかで確認できます。
