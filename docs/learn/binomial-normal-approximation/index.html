二項分布の正規近似

整数の成功回数を連続的な分布で近似します。平均と分散をそろえ、0.5の補正がどの領域を表すかを確かめます。

計算を簡単にするための近似

KがBin(100,0.5)に従うとき、Kが60以上の確率を求めたいとします。正確にはk=60から100までの二項確率を足します。計算機なら直接求められますが、正規近似を使うと分布表でも近い値を得られます。

二項分布の平均はnp=50、分散np(1−p)=25なので、平均50・標準偏差5の正規分布Yを対応させます。

K∼Bin(n,p)⇒Kを Y∼N(np,np(1−p))で近似する.K\sim\mathrm{Bin}(n,p)\quad\Rightarrow\quad K\text{を }Y\sim N(np,np(1-p))\text{で近似する}.K∼Bin(n,p)⇒Kを Y∼N(np,np(1−p))で近似する.

同じ分布になったという等号ではありません。整数しか取らないKと、連続的なYは異なる対象です。近似を使う目的と精度を確認します。

どのようなときに近似しやすいか

二項モデル自体の固定n・共通p・独立性をまず確認します。そのうえで、平均的な成功数npと失敗数n(1−p)が十分大きいと、正規近似を使いやすくなります。両方が10以上という条件はよく使う目安の一つです。[1]

これは誤差を一律に保証する定理の条件ではありません。分布の端の小さい確率を相対誤差まで正確に知りたい場合などは、目安を満たしても直接計算が必要になり得ます。

例えばn=100でもp=0.01ならnp=1で、0付近に大きく偏った分布です。「100回だから十分大きい」とnだけで判断しません。p=0または1では分散0で、標準化して正規分布を使う通常の方法は適用できません。

整数一個を、幅1の区間へ対応させる

K=60という整数の確率を、連続のYが59.5〜60.5へ入る面積に対応させるのが連続性補正の考え方です。従ってK≥60はY≥59.5で近似します。

二項側の条件連続性補正した正規側の領域
K=kk−0.5 ≤ Y ≤ k+0.5
K≤kY≤k+0.5
K<k（k整数）Y≤k−0.5
K≥kY≥k−0.5
a≤K≤b（a,b整数）a−0.5≤Y≤b+0.5

常に0.5を足す、あるいは常に引くという暗記はしません。含めたい整数の柱の外側の端まで面積を取る、と考えます。元のKには0〜nという端もありますが、正規分布は全実数へ裾が続きます。近似が端の外へ割り当てる確率が無視できるかも、精度の問題です。

60回以上の確率を比較する

Yの平均50・標準偏差5で、59.5を標準化すると、

z=59.5−505=1.9.z=\frac{59.5-50}{5}=1.9.z=559.5−50​=1.9.

上側確率は1−Φ(1.9)≈0.02871656です。一方、二項分布で直接計算した確率は約0.02844397です。補正なしで60を標準化するとz=2で、近似確率は約0.02275013になります。

計算法K≥60の確率
二項分布で直接約0.02844397
正規近似・補正あり約0.02871656
正規近似・補正なし約0.02275013

この例では連続性補正で直接計算に近づきました。ただし、どの問題でも誤差が同じ割合で減ると保証するものではありません。教材の近似値を、厳密な確率として等号で書かないようにします。

一点の確率を0にしない

K=50の確率は、正規分布のP(Y=50)=0で置き換えるのではなく、49.5〜50.5の面積で近似します。標準化すると−0.1〜0.1なので、約0.07965567です。二項分布の直接計算は約0.07958924です。

離散型の一点には正の確率があり、連続型の一点には0という違いを、幅1の領域へ対応させて扱っています。第31講で説明した「丸めた観測値の区間」ともつながります。

近似で不自然な負の境界や範囲外が目立つとき、単に答えを0〜1へ丸め込むのではなく、モデルと条件を見直します。二項分布の和を直接計算できるなら、それを基準にするのが明確です。

確認問題

問1：境界を補正する

KがBin(100,0.5)です。K≥60を近似するとき、Yの境界とz値を答えてください。

解答と理由

境界59.5、z=1.9です。60の整数を表す幅1の領域の左端から面積を取ります。60.5ではK≥61に対応する領域になってしまいます。

問2：整数一点

同じ分布でK=50を近似する正規側の区間と、標準化後の区間を答えてください。

解答と理由

49.5〜50.5、標準化後は−0.1〜0.1です。その面積は約0.07966です。正規分布の一点の確率0を代入しません。

問3：nだけを見ない

n=100、p=0.01です。両方の期待回数が10以上という目安を満たしますか。

解答と理由

満たしません。np=1、n(1−p)=99です。成功側が小さく、分布は強く非対称です。二項分布の直接計算などを検討します。

詳しく確かめる

正規近似の根拠と、連続性補正の位置づけ

共通成功確率0<p<1の独立な0/1変数I_iの和をKとします。固定したpのもとで中心極限定理により、

K−npnp(1−p)→dN(0,1)(n→∞)\frac{K-np}{\sqrt{np(1-p)}}\xrightarrow{d}N(0,1) \quad(n\to\infty)np(1−p)​K−np​d​N(0,1)(n→∞)

です。これが二項分布の正規近似を支える極限の主張です。ここでは定理を前提として適用しており、中心極限定理そのものの完全証明ではありません。

連続性補正は、離散的な格子の一個分を幅1の面積へ合わせる工夫です。極限の結論だけから有限nの誤差が0になるわけではありません。またpがnとともに端へ動く場合などは、固定pの主張をそのまま適用せず条件を見直します。直接計算と近似を比較して、必要な精度を確認することが重要です。

まとめと次の一歩

平均と分散をそろえ、整数の条件へ合う補正を使います。条件と近似誤差を隠しません。次章は、標本平均・標本比率がどのようにぶれるかを扱います。
