個数の確率を、係数として並べる

一つの注文に追加されるオプション数Nが、0個を確率0.2、1個を0.5、2個を0.3で取る仮想モデルを考えます。確率母関数は、個数をsの指数に、確率をその係数にした関数です。

GN(s)=E[sN]=0.2+0.5s+0.3s2.G_N(s)=E[s^N]=0.2+0.5s+0.3s^2.GN​(s)=E[sN]=0.2+0.5s+0.3s2.

一般にはNが0、1、2、…の非負整数を取り、GN(s)=∑k=0∞P(N=k)skG_N(s)=\sum_{k=0}^{\infty}P(N=k)s^kGN​(s)=∑k=0∞​P(N=k)sk と定義します。少なくとも|s|≤1で絶対収束します。Nが負の値や任意の実数を取る場合へ、この確率母関数の性質をそのまま移しません。[1]

モーメント母関数M(t)=E[etN]M(t)=E[e^{tN}]M(t)=E[etN]とは異なります。Mが有限な範囲ではM(t)=G(et)M(t)=G(e^t)M(t)=G(et)と対応しますが、確率を係数として取り出すにはGのsを使います。

s=0とs=1は何を取り出すか

s=0なら0個の項だけが残り、GN(0)=P(N=0)=0.2G_N(0)=P(N=0)=0.2GN​(0)=P(N=0)=0.2です。ここでは0次の項s0s^0s0を1とします。s=1ならすべての確率を足すのでGN(1)=1G_N(1)=1GN​(1)=1です。

逆に、適当な多項式が常に確率母関数になるわけではありません。各係数が非負で、s=1での和が1になる必要があります。係数が−0.1の項を含む多項式は、総和が1でも確率分布を表しません。

有限の多項式なら係数を読むだけですが、一般にも0の周りでk回微分すれば、

P(N=k)=GN(k)(0)k!P(N=k)=\frac{G_N^{(k)}(0)}{k!}P(N=k)=k!GN(k)​(0)​

です。微分する回数に対応する階乗で割り忘れないことが重要です。s=0で確率を取り出す操作と、次のs=1で平均を取り出す操作を区別します。

二階微分は、そのまま二乗平均ではない

G′(s)=E[NsN−1]G'(s)=E[Ns^{N-1}]G′(s)=E[NsN−1]、G′′(s)=E[N(N−1)sN−2]G''(s)=E[N(N-1)s^{N-2}]G′′(s)=E[N(N−1)sN−2]です。E[N²]<∞のもとで、sを1へ左から近づけると、G’(1−)=E[N]、G”(1−)=E[N(N−1)]を得ます。[1]

ポアソン個数を、独立に残す

ある時間帯のイベント数Nが平均4のポアソン分布とします。各イベントを、互いに独立かつNの値によらず確率1/4で記録に残す仮想モデルです。残る個数Kは、N=nのもとで二項分布Bin(n,1/4)です。

条件付き確率母関数は E[sK∣N]=(3/4+s/4)NE[s^K\mid N]=(3/4+s/4)^NE[sK∣N]=(3/4+s/4)N です。これをNについて平均するとGK(s)=GN(3/4+s/4)G_K(s)=G_N(3/4+s/4)GK​(s)=GN​(3/4+s/4)です。ポアソンの母関数 GN(s)=e4(s−1)G_N(s)=e^{4(s-1)}GN​(s)=e4(s−1) を代入すると、

GK(s)=es−1G_K(s)=e^{s-1}GK​(s)=es−1

となり、Kは平均1のポアソン分布と分かります。残る個数0の確率はe−1≈0.367879e^{-1}\approx0.367879e−1≈0.367879です。独立で一定の保持確率を使っている点が条件で、込み合うと記録率が下がる仕組みにはこのまま当てはまりません。

確認問題

問1：元の分布へ戻す

G(s)=0.2+0.5s+0.3s²から、0個、1個、2個の確率を求めてください。G”(0)を2個の確率としてよいですか。

解答と理由

確率は0.2、0.5、0.3です。G”(0)=0.6なので2!で割って0.3にします。微分で生じた階乗を戻す必要があります。

問2：平均と分散

G’(1)=1.1、G”(1)=0.6です。分散を求めてください。

解答と理由

0.6+1.1−1.1²=0.49です。G”(1)は階乗モーメントなので、E[N]を足してE[N²]にしてから平均の二乗を引きます。

問3：独立な和と二倍

本文の独立な二注文の合計が2個になる確率と、一つのNを二倍して2になる確率を求めてください。

解答と理由

前者は0.37、後者はP(N=1)=0.5です。G(s)²とG(s²)の差は、二つの注文が独立か、同じ値を使っているかの差です。

問4：間引き後の0個

平均4のポアソン個数から各イベントを独立に確率1/4で残します。残る個数の平均と、0個の確率は何ですか。

解答と理由

平均1、0個の確率e−1≈0.367879e^{-1}\approx0.367879e−1≈0.367879です。元の平均4を使ったe−4e^{-4}e−4ではありません。保持確率と独立性がモデルの条件です。

詳しく確かめる

確率母関数の微分と、1への左極限を分けて示す

|s|<1の内部では、絶対収束するべき級数を項別微分できます。sを0以上1未満として増やすと、各非負項kpksk−1kp_ks^{k-1}kpk​sk−1はkpkkp_kkpk​へ増えるので、単調収束によってG′(1−)=∑kkpkG'(1-)=\sum_k kp_kG′(1−)=∑k​kpk​です。同様に二階微分は∑kk(k−1)pk\sum_k k(k-1)p_k∑k​k(k−1)pk​へ近づきます。

この極限は無限大になることもあります。本文ではE[N²]<∞とし、二つのモーメントと分散を有限値として計算しました。すべてのNでs=1の右側まで母関数が存在する、と仮定しているわけではありません。

非負整数の独立同分布XiX_iXi​がNからも独立とし、S=∑i=1NXiS=\sum_{i=1}^N X_iS=∑i=1N​Xi​、N=0ならS=0とします。0≤s≤1でN=nを条件にすれば、独立性よりE[sS∣N=n]=GX(s)nE[s^S\mid N=n]=G_X(s)^nE[sS∣N=n]=GX​(s)nです。反復期待値を使うと

GS(s)=E[GX(s)N]=GN(GX(s)).G_S(s)=E[G_X(s)^N]=G_N(G_X(s)).GS​(s)=E[GX​(s)N]=GN​(GX​(s)).

この範囲では0≤GX(s)≤10\le G_X(s)\le10≤GX​(s)≤1なので、内外の母関数は定義できます。XiX_iXi​を0・1のベルヌーイ変数にした場合が本文の間引きです。平均・分散も必要ならP02の全期待値・全分散から求められ、モーメントが有限である条件を追加します。
