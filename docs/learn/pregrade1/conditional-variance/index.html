条件付き分散と全分散の公式

全体のばらつきには、群の中の揺れと群の平均の違いが含まれます。二つを足す公式から、予測誤差や個数が変わる合計を考えます。

群内の分散を平均するだけでは足りません

二つの班の作業時間が、それぞれ全員8分、全員12分だったとします。どちらの班も内側のばらつきは0です。しかし両班が同じ割合で集まる全体では、8と12の違いがあります。全体の平均10、分散4です。

この例だけでも「群の分散の平均が全体の分散」とは限らないことが分かります。全体には、群内の不確かさと、群の平均どうしの違いの両方が含まれるためです。以下では、すべて説明用の確率モデルを使います。

条件付き分散も、平均との差の二乗平均

P01の利用プランのモデルを使います。基本プランX=0の確率は0.75、拡張プランX=1は0.25でした。条件付き分布を使えば、分散の公式は通常の分散と同じ形です。

Var⁡(Y∣X=x)=E[Y2∣X=x]−{E[Y∣X=x]}2.\operatorname{Var}(Y\mid X=x) =E[Y^2\mid X=x]-\{E[Y\mid X=x]\}^2.Var(Y∣X=x)=E[Y2∣X=x]−{E[Y∣X=x]}2.

この講座では E[Y2]<∞E[Y^2]<\inftyE[Y2]<∞ を仮定します。標本の不偏分散のn−1を使う計算ではなく、与えた確率分布の母分散を計算しています。[1]

条件その確率条件付き平均条件付き二乗平均条件付き分散
X=00.7525.61.60
X=10.252.810.42.56

X=0の二乗平均は0²×0.2+2²×0.6+4²×0.2=5.6です。平均の二乗4を引くと1.6です。X=1も同様に10.4−7.84=2.56になります。

全分散は二つの項の和

観測する前の条件付き平均m(X)=E[Y|X]も、条件付き分散v(X)=Var(Y|X)も、Xによって値が変わります。全分散の公式は、

Var⁡(Y)=E[Var⁡(Y∣X)]+Var⁡(E[Y∣X]).\operatorname{Var}(Y) =E[\operatorname{Var}(Y\mid X)] +\operatorname{Var}(E[Y\mid X]).Var(Y)=E[Var(Y∣X)]+Var(E[Y∣X]).

最初の項は、各群の分散を群の確率で平均したものです。本文では0.75×1.6+0.25×2.56=1.84です。後の項は、平均2と2.8が全体平均2.2からどれだけ離れるかで、0.75×(2−2.2)²+0.25×(2.8−2.2)²=0.12です。

したがって全分散は1.84+0.12=1.96です。元の周辺分布からも、E[Y²]=6.8、E[Y]²=4.84なので差は1.96となります。群の確率と、分散を取る量を確かめながら照合できます。

二つの項が示す範囲

群内の項1.84は、Xを知ってもYにはまだ揺れが残ることを示します。群間の項0.12は、Xに応じて予測の中心を変える余地です。両方とも非負なので、条件付き分散の平均が全分散を上回ることはありません。

ただし、各群の条件付き分散がそれぞれ全分散以下になるという主張ではありません。本文ではX=1の分散2.56は全分散1.96より大きいです。大小が保証されるのは、群の確率で平均した1.84と全体1.96の比較です。

また、この分解だけで「プランが変動の原因」とは言えません。Xによる情報の分け方を説明しているのであって、プランを操作した場合の因果効果ではありません。

予測の中心に条件付き平均を使う理由

予測誤差を二乗で評価するなら、Xを知ったときの予測値m(X)が、Xだけから作る予測の中で平均二乗誤差を最小にします。本文のモデルでは、この予測の平均二乗誤差は1.84です。誰にでも全体平均2.2を予測する方法の誤差1.96より、0.12だけ小さくなります。

ここでは確率モデルが既知で、条件付き平均を正しく使えるとしています。実データから推定した複雑な予測器の、未知データでの性能まで保証するものではありません。絶対誤差を最小化したい場合など、損失が違えば適切な予測値も変わり得ます。

個数自体がランダムな合計

一日に届く依頼数Nが平均3のポアソン分布、各依頼の作業量C_iは3または7を等確率で取り、互いに独立でNからも独立、と仮定します。C_iの平均は5、分散4です。合計S=C_1+…+C_Nとし、N=0ならS=0です。

N=nと分かればE[S|N=n]=5n、Var(S|N=n)=4nです。Nの平均・分散がともに3なので、全分散から

E[S]=15,Var⁡(S)=4E[N]+25Var⁡(N)=12+75=87.E[S]=15,\qquad \operatorname{Var}(S)=4E[N]+25\operatorname{Var}(N)=12+75=87.E[S]=15,Var(S)=4E[N]+25Var(N)=12+75=87.

平均個数3を固定して分散12とする計算では、個数の揺れによる75を落とします。個数と作業量が関連する現実の状況では、この独立性を仮定した式をそのまま使えません。

確認問題

問1：全分散を復元する

本文のプラン別モデルの群内分散の平均、群間の分散、全分散を求めてください。

解答と理由

順に1.84、0.12、1.96です。条件付き分散の単純平均ではなく、群の確率0.75・0.25を使います。全体の平均2.2と各群の平均の違いも残します。

問2：群内が0の場合

8分に固定された群と12分に固定された群が半分ずつあります。全分散は0でしょうか。

解答と理由

全分散は4です。群内の項は0ですが、平均10に対して群の平均が−2、2だけ離れ、その二乗の平均が4です。

問3：ランダムな個数

本文の依頼数と作業量のモデルで、合計の平均と分散を求めてください。分散12だけでは足りない理由も説明してください。

解答と理由

平均15、分散87です。Nを固定した場合の分散の平均12に加え、条件付き平均5N自体の分散75が必要です。

問4：条件を使う予測

プランを知らずに2.2と予測する方法から、X=0で2、X=1で2.8と予測する方法へ変えると、モデル上の平均二乗誤差はどう変わりますか。

解答と理由

1.96から1.84へ減り、差は0.12です。群内の不確かさは残ります。観測値Yが必ず予測と一致することや、因果効果があることを意味しません。

詳しく確かめる

全分散を、二乗平均の恒等式から証明する

m(X)=E[Y|X]とします。反復期待値よりE[m(X)]=E[Y]、E[E[Y²|X]]=E[Y²]です。したがって、

E[Var⁡(Y∣X)]=E[Y2]−E[m(X)2],Var⁡(m(X))=E[m(X)2]−{E[Y]}2.\begin{aligned} E[\operatorname{Var}(Y\mid X)] &=E[Y^2]-E[m(X)^2],\\ \operatorname{Var}(m(X)) &=E[m(X)^2]-\{E[Y]\}^2. \end{aligned}E[Var(Y∣X)]Var(m(X))​=E[Y2]−E[m(X)2],=E[m(X)2]−{E[Y]}2.​

二式を足せば中間のE[m(X)²]が消え、Var(Y)です。E[Y²]<∞のもとでは条件付きJensenの不等式からE[m(X)²]≤E[Y²]で、各項を有限量として扱えます。有限表であれば、Jensenの代わりに各行の重み付き平方和を直接展開しても確認できます。

条件付き平均が二乗誤差を最小にすることを示す

Xから作る予測g(X)にE[g(X)²]<∞を仮定します。Y−g(X)=(Y−m(X))+(m(X)−g(X))を二乗して期待値を取ります。交差項の期待値は、Xを条件にするとE[Y−m(X)|X]=0なので0です。よって、

E[(Y−g(X))2]=E[Var⁡(Y∣X)]+E[(m(X)−g(X))2].E[(Y-g(X))^2]=E[\operatorname{Var}(Y\mid X)]+E[(m(X)-g(X))^2].E[(Y−g(X))2]=E[Var(Y∣X)]+E[(m(X)−g(X))2].

第2項は非負で、g(X)=m(X)が確率1で成り立つ場合に0となります。これは指定した情報と損失のもとでの最適性です。未知のモデルをデータから推定する際の過学習や、別の損失関数まで解決する定理ではありません。
