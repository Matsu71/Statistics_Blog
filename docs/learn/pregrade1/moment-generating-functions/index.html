一つの関数から、いくつもの平均を取り出す

E[X]、E[X²]、E[X³]のような量を原点まわりのモーメントと呼びます。モーメント母関数は、指数関数の中へXを入れて平均し、これらの量を一つの関数にまとめる道具です。

MX(t)=E[etX].M_X(t)=E[e^{tX}].MX​(t)=E[etX].

tは実数の引数で、標本数や観測値ではありません。通常「母関数が存在する」と使うときは、0を含むある開区間でM_X(t)が有限であることを要求します。t=0でM_X(0)=1になるだけでは、必要な存在条件を満たしたことになりません。[1]

基本の計算では、定義から関数を作り、存在する範囲を記し、微分して0を代入する順序にします。式を暗記するだけでなく、何の期待値を表したかへ戻れるようにします。

二つの値を取る仮想モデルで計算する

Xが−2を確率0.4、1を確率0.6で取るとします。説明用のモデルです。母関数は

MX(t)=0.4e−2t+0.6etM_X(t)=0.4e^{-2t}+0.6e^tMX​(t)=0.4e−2t+0.6et

で、すべての実数tで有限です。M_X(0)=0.4+0.6=1は確率の和の確認にもなります。t=log 2なら、M_X(log 2)=0.4/4+0.6×2=1.3です。母関数の値は確率ではないため、1を超えても問題ありません。

一回微分すると MX′(t)=−0.8e−2t+0.6etM'_X(t)=-0.8e^{-2t}+0.6e^tMX′​(t)=−0.8e−2t+0.6et、二回なら MX′′(t)=1.6e−2t+0.6etM''_X(t)=1.6e^{-2t}+0.6e^tMX′′​(t)=1.6e−2t+0.6et です。0を入れると平均−0.2、二乗の期待値2.2が得られます。

Var⁡(X)=MX′′(0)−{MX′(0)}2=2.2−0.04=2.16.\operatorname{Var}(X)=M''_X(0)-\{M'_X(0)\}^2=2.2-0.04=2.16.Var(X)=MX′′​(0)−{MX′​(0)}2=2.2−0.04=2.16.

二階微分をそのまま分散としないようにします。二階微分が与えるのはE[X²]で、平均の二乗を引く操作が残ります。

位置と尺度を変えたとき

既知の定数a,bについてY=aX+bなら、指数の規則から

MY(t)=E[et(aX+b)]=ebtMX(at).M_Y(t)=E[e^{t(aX+b)}]=e^{bt}M_X(at).MY​(t)=E[et(aX+b)]=ebtMX​(at).

定義が有限な範囲で使います。本文のY=3X+4では MY(t)=e4tMX(3t)M_Y(t)=e^{4t}M_X(3t)MY​(t)=e4tMX​(3t)、平均3.4、分散19.44です。元のXの期待値を使って3×(−0.2)+4、分散を使って9×2.16と計算しても一致します。

e^{bt}を掛けずに、M_Xの引数だけ変えると、位置の移動を落としてしまいます。母関数の変換と、G09で学んだ期待値・分散の式を照合すると確認しやすくなります。

和を積へ変えるのは、独立性を使う段階

XとYが独立なら、両方の母関数が有限な範囲で

MX+Y(t)=E[etXetY]=MX(t)MY(t)M_{X+Y}(t)=E[e^{tX}e^{tY}]=M_X(t)M_Y(t)MX+Y​(t)=E[etXetY]=MX​(t)MY​(t)

です。同じ分布の独立なn個の和ならM_X(t)^nです。しかしY=Xという完全に同じ量なら、X+Y=2Xの母関数はM_X(2t)です。独立な二つのXを足したときとは違います。

本文のモデルでt=log 2とすると、M_X(2t)=0.4/16+0.6×4=2.425に対し、M_X(t)²=1.69です。「分布が同じ」と「変数が独立」を区別する数値例になっています。

連続分布では積分と収束範囲を確認する

率λ=2の指数分布は、x>0で密度2e^{-2x}です。定義から

MX(t)=∫0∞2e−(2−t)x dx=22−t,t<2.M_X(t)=\int_0^\infty 2e^{-(2-t)x}\,dx=\frac2{2-t},\qquad t<2.MX​(t)=∫0∞​2e−(2−t)xdx=2−t2​,t<2.

t≥2では積分が発散するので、右辺の代数式をそのまま延長して母関数と呼びません。0の近くは有限なので、微分を用いる条件を満たしています。

0での一階微分は1/2、二階微分は1/2、分散は1/4です。率と尺度を混同すると式全体が変わります。密度のパラメータの意味から確認します。

すべてのモーメントがあれば十分、ではありません

0の近傍で有限なモーメント母関数が一致すれば、分布も一致するという一意性の定理があります。ただし、モーメントが存在するという条件だけへ弱めてよいわけではありません。[1]

例えば標準正規Zを指数変換したX=e^Zでは、すべての正の整数kに対してE[X^k]=e^{k²/2}は有限です。それでもE[e^{tX}]はt>0で発散します。この性質は後の対数正規分布にも関係します。存在しない母関数の微分を形式的に使わず、別の道具や定義から計算します。

確認問題

問1：母関数は確率か

本文の二点分布についてM_X(log 2)を求めてください。1を超えたら誤りでしょうか。

解答と理由

1.3です。母関数はe^{tX}の期待値であり、事象の確率ではありません。0〜1に入るという制約はありません。

問2：平均と分散

一階・二階微分から、二点分布の平均と分散を求めてください。

解答と理由

平均−0.2、分散2.16です。M”(0)=2.2はE[X²]で、平均の二乗0.04を引いて分散にします。

問3：一次変換と独立な和

Y=3X+4の母関数を書いてください。また、Xを二倍することと、同分布の独立な二変数を足すことは同じですか。

解答と理由

MY(t)=e4tMX(3t)M_Y(t)=e^{4t}M_X(3t)MY​(t)=e4tMX​(3t) です。二倍ならM_X(2t)、独立な和ならM_X(t)²で、一般には異なります。t=log 2で2.425と1.69になり、この例でも違います。

問4：指数分布の存在範囲

率2の指数分布で、M_X(1)とM_X(3)を考えてください。2/(2−3)=−2を母関数の値として使えますか。

解答と理由

M_X(1)=2です。t=3では定義の積分が発散し、有限な母関数の値はありません。−2は収束範囲の外で代数式だけを計算した値であり、正の量の期待値とも矛盾します。

詳しく確かめる

微分を期待値の中へ入れるための条件

あるa>0についてM_X(a)とM_X(−a)が有限なら、ea∣X∣≤eaX+e−aXe^{a|X|}\le e^{aX}+e^{-aX}ea∣X∣≤eaX+e−aX よりE[e^{a|X|}]<∞です。任意の非負整数kについて、u^k e^{-au/2}はu≥0で有界なので、|t|≤a/2において

∣X∣ketX≤∣X∣kea∣X∣/2≤Ca,kea∣X∣|X|^k e^{tX}\le |X|^k e^{a|X|/2}\le C_{a,k}e^{a|X|}∣X∣ketX≤∣X∣kea∣X∣/2≤Ca,k​ea∣X∣

と、一つの可積分な量で抑えられます。差分商には平均値の定理を使い、その導関数も同様に抑えられるため、優収束定理による微分と期待値の交換が正当化されます。これを繰り返すと MX(k)(0)=E[Xk]M_X^{(k)}(0)=E[X^k]MX(k)​(0)=E[Xk] です。単に指数関数を形式展開しただけでは、無限和と期待値の交換条件を確認したことにはなりません。

対数正規の反例で、存在条件の必要性を確かめる

Zが標準正規なら、正規密度の平方完成からE[e^{kZ}]=e^{k²/2}です。一方t>0に対するX=e^Zの母関数の積分は、定数倍を除くと ∫−∞∞exp⁡(tez−z2/2) dz\int_{-\infty}^{\infty}\exp(te^z-z^2/2)\,dz∫−∞∞​exp(tez−z2/2)dz です。

zが十分大きいと指数関数e^zは二次式z²/2より速く増え、te^z−z²/2≥0となります。その半無限区間では被積分関数が1以上なので積分は発散します。各次数のモーメントが有限であることと、0の近傍の指数モーメントが有限であることは異なる、と具体的に確認できました。
