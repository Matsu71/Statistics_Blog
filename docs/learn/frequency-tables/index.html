値の一覧を、分布の表にする

前の講座で、割合は分母によって意味が変わると学びました。今度は、多くの測定値をいくつかの区間に分け、その区間に入る件数と割合を見ます。区間ごとの件数を度数、区間を階級、それらを並べた表を度数分布表と呼びます。

ある学習室で10回の待ち時間を記録したとします。以下は架空のデータです。

1、2、2、4、5、5、7、8、9、12分

小さい順に並べると、5分未満もあれば10分以上もあります。これを「0分以上5分未満」「5分以上10分未満」「10分以上15分未満」の三つに分けます。階級の幅はどれも5分です。この幅を階級幅と呼びます。

境界の値を、二重に数えない

「0〜5分」「5〜10分」だけでは、ちょうど5分をどちらへ入れるか曖昧です。本講座では下端を含み、上端を含まない区間にします。従って5分は第2階級、10分は第3階級です。全観測値が必ず一つの階級に入るように定めます。

階級（分）階級値（分）度数（件）相対度数累積度数累積相対度数
0以上5未満2.540.440.4
5以上10未満7.550.590.9
10以上15未満12.510.1101.0
合計—101.0——

階級値は区間の中央です。第1階級なら (0+5)/2=2.5(0+5)/2=2.5(0+5)/2=2.5 分です。第1階級の観測値が全部2.5分だった、という意味ではありません。階級値と、個々の観測値やその階級内の実際の平均を区別します。

表の度数を足すと、元の観測数10件になることを確かめます。合わなければ境界で二重に数えたか、観測を落とした可能性があります。最後の階級より大きい値がある場合は、階級を追加するなどして全件を含めます。

相対度数は「その階級の割合」

相対度数は、階級の度数を全体の件数で割った値です。第2階級には5件あり、全10件なので 5/10=0.55/10=0.55/10=0.5、百分率なら50%です。

相対度数=階級の度数全体の度数.\text{相対度数}=\frac{\text{階級の度数}}{\text{全体の度数}}.相対度数=全体の度数階級の度数​.

日によって調べた件数が違う場合、度数だけで分布を比較すると、単に件数の多い日が大きく見えます。相対度数にそろえると構成の違いを比較できます。ただし、同じ割合でも5件中の1件と500件中の100件では、得られた情報量は異なります。元の件数も残します。

小数を丸めると、表示した相対度数の合計が0.999などになることがあります。途中計算は丸める前の値を使い、表示の丸めと集計ミスを区別します。全体の件数が0の場合には、相対度数を計算できません。

累積は「そこまでを足した値」

小さい階級から順に度数を足すのが累積度数です。第2階級までなら 4+5=94+5=94+5=9 件で、10分未満が9件と読めます。同様に、累積相対度数0.9は10分未満が全体の90%だったことを表します。

累積相対度数グラフを作るなら、横軸を階級の境界、縦軸を累積割合にして、(0, 0)、(5, 0.4)、(10, 0.9)、(15, 1.0) を対応させます。区間をまたぐたびに割合が加わるので、線が下がることはありません。境界間を直線で結んでも、その区間内の個々の値が分かったことにはなりません。

「5分以上10分未満」は第2階級だけなので50%です。「10分未満」は第1・第2階級の合計なので90%です。「そこだけ」と「そこまで」を読み分けることが重要です。

この表だけでは答えられない問い

元の一覧を隠し、度数分布表だけを見ているとします。「7分未満は何件か」には、正確に答えられません。第1階級の4件は確実に7分未満ですが、第2階級の5件のうち何件が7分未満かは分からないからです。

元データなら、1、2、2、4、5、5の6件と答えられます。表にまとめると読みやすくなる一方、階級内の詳しい位置を失います。階級値を使う平均は、その失った位置を中央で代表させる近似です。第13講で計算します。

また、名義尺度の予約方法を任意の順序で並べて累積しても、「小さい値からそこまで」という意味はありません。累積は、数量や順序を持つ内容について、足し合わせる順序に意味があるときに使います。

確認問題

問1：ちょうど境界の値

下端を含み上端を含まない階級を使うとき、5分の記録を0以上5未満と5以上10未満のどちらへ入れますか。後者の階級値も答えてください。

解答と理由

5以上10未満へ入れます。階級値は (5+10)/2=7.5(5+10)/2=7.5(5+10)/2=7.5 分です。境界の5分を両方の階級へ入れると、度数の合計が観測数を超えてしまいます。

問2：そこだけと、そこまで

本文の表から、5分以上10分未満の割合と、10分未満の割合を求めてください。

解答と理由

前者は 5/10=50%5/10=50\%5/10=50%、後者は (4+5)/10=90%(4+5)/10=90\%(4+5)/10=90% です。累積度数9を、第2階級だけの件数と読み違えないことがポイントです。

問3：元データを見ずに答えられるか

度数分布表だけから、7分未満の件数を必ず6件と決められますか。確実に言える件数の範囲も考えてください。

解答と理由

決められません。第1階級の4件は必ず入り、第2階級の5件は0〜5件が入り得るので、4〜9件です。これは表の情報だけから決まる範囲で、確率的な信頼区間ではありません。
