正規分布表と1.96の使い方

表が左側・右側・中央からの面積のどれを示すかを確認します。片側2.5%と両側5%を、元の単位へ戻して使います。

表の説明を読んでから、数字を探す

Zが標準正規分布N(0,1)に従うとします。−∞からzまでの左側の確率を Φ(z)=P(Z≤z)\Phi(z)=P(Z\le z)Φ(z)=P(Z≤z) と書きます。本講座の表はこの累積確率を示します。[1]

z=1.96ならΦ(1.96)≈0.97500です。右側の確率は全体1から引いた約0.02500です。0からzまでの面積は、左半分の0.5を引いた約0.47500です。

z≥0で表している領域z=1.96での値
左端からz：Φ(z)約0.97500
0からz：Φ(z)−0.5約0.47500
zより右：1−Φ(z)約0.02500

別の資料で表の値が0.4750だから誤り、とは判断しません。どの領域を載せているかが違う可能性があります。表の図・見出し・注記を先に確認し、求めたい領域と一致させます。

よくある表では行が整数と小数第1位、列が小数第2位です。次はz=1.90〜1.99の累積確率を、5桁へ丸めて載せた抜粋です。

通常の二次元表なら、1.9の行と0.06の列を合わせて1.96を探します。1.96の行と0.06の列を再度足す、といった誤読をしないようにします。表の桁が粗いとき、補間や丸めの規則は問題の指定に従います。

左側・右側・区間の三つの計算

右側は1−Φ(z)、二つの境界a≤bの間はΦ(b)−Φ(a)です。対称性からΦ(−z)=1−Φ(z)も使えます。例えばP(Z≤−1.96)≈0.025、P(−1.96≤Z≤1.96)≈0.95です。

P(a≤Z≤b)=Φ(b)−Φ(a).P(a\le Z\le b)=\Phi(b)-\Phi(a).P(a≤Z≤b)=Φ(b)−Φ(a).

z=1ならΦ(1)≈0.8413447なので、右側は約0.1586553、−1から1の間は約0.6826895です。1.96で覚えた2.5%を、違うzにもそのまま流用しないようにします。

区間が負の側だけの場合も、同じ差の式で計算できます。図を思い浮かべ、結果が0〜1の範囲か、広い区間ほど確率が小さくなっていないかを点検します。

1.96は、片側2.5%に対応する丸めた境界

正確に上側2.5%となる境界は、97.5%分位点 z0.975≈1.9599639845z_{0.975}\approx1.9599639845z0.975​≈1.9599639845 です。1.96はその近似で、P(Z≥1.96)≈0.024997895です。教材や試験では丸めた約2.5%として使います。

両側を合わせて5%にしたいときは、片側に2.5%ずつ置くので±1.96です。一方、片側5%なら境界は約1.64485で、よく1.645と丸めます。片側5%にも1.96を使うと、求めたい領域が変わります。

目的標準正規分布の境界の近似
上側5%1.645
上側2.5%1.960
中央95%−1.960〜1.960
中央99%−2.576〜2.576

±2標準偏差の中央は約95.45%で、正確に95%ではありません。近似と等号を使い分けます。

元の単位のしきい値へ戻す

XがN(50,10²)に従うとします。上側約2.5%の境界は 50+1.96×10=69.650+1.96\times10=69.650+1.96×10=69.6 です。「Xが1.96以上なら2.5%」ではなく、平均から標準偏差1.96個分上の値が境界です。

中央約95%なら50±19.6で、30.4〜69.6です。これはこの分布の個々の値が入る範囲を示しています。未知の平均を標本から推定する信頼区間ではありません。標本平均の標準誤差を使う話は第34・35講で区別します。

元の値の単位、μ、σを確認し、Nの第2引数に分散が書かれていたら平方根を取って標準偏差に戻します。式への代入より前に、何が正規分布に従うとされているかを確認します。

動かして確かめる

片側・両側を切り替えて面積を確かめる。操作前に結果を予想し、操作後に変わった量と変わらなかった量を説明してください。図を動かした結果は、一般的な数学の証明とは区別します。

確認問題

問1：表の種類

ある表でz=1.96に0.4750と載っていました。0からzまでの面積を示す表だとすると、上側確率はいくつですか。

解答と理由

0.5−0.4750=0.0250です。1−0.4750とすると、左半分を二重に含む違う領域になります。どの面積の表かを先に確認します。

問2：片側と両側

Zが標準正規分布のとき、P(|Z|≥1.96)とP(Z≥1.96)を約何%と読めますか。

解答と理由

前者は両端を合わせた約5%、後者は右だけの約2.5%です。絶対値が入ると、負の端も条件に入ります。

問3：分位点から元へ戻す

XがN(100,15²)に従います。上側約2.5%の境界を1.96を使って求めてください。

解答と理由

100+1.96×15=129.4です。標準偏差15を使い、分散225を掛けません。求めたのは個々のXのしきい値です。

詳しく確かめる

対称性から、負の値と両側の式を導く

密度φ(t)がφ(−t)と等しいので、積分の変数u=−tを使えば Φ(−z)=∫z∞ϕ(u)du=1−Φ(z)\Phi(-z)=\int_z^\infty\phi(u)du=1-\Phi(z)Φ(−z)=∫z∞​ϕ(u)du=1−Φ(z) です。z≥0について、

P(∣Z∣≤z)=Φ(z)−Φ(−z)=2Φ(z)−1.P(|Z|\le z)=\Phi(z)-\Phi(-z)=2\Phi(z)-1.P(∣Z∣≤z)=Φ(z)−Φ(−z)=2Φ(z)−1.

中央確率を1−αにしたいとき、2Φ(z)−1=1−αを解いてΦ(z)=1−α/2です。従って両側区間の境界は z1−α/2z_{1-\alpha/2}z1−α/2​ となります。片側ならα/2へ分けず、z1−αz_{1-\alpha}z1−α​ を使います。分布表の使い分けは、この領域の分割から説明できます。
