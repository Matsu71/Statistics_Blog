点を一本の直線で要約する

前講の架空データ(1,2)、(2,3)、(3,5)、(4,4)を使い、時間xから得点yを説明する直線を考えます。直線上の値を予測値 y^=a+bx\hat y=a+bxy^​=a+bx と書きます。aは切片、bは傾きです。

傾きbは、xが1単位増えたときの予測値の増加量です。xが時間、yが点なら、単位は点/時間です。切片aはx=0での予測値ですが、実際に0付近を観測していなければ、その値の現実的な意味を慎重に扱います。

点は直線にぴったり乗るとは限りません。観測値から予測値を引いた ei=yi−y^ie_i=y_i-\hat y_iei​=yi​−y^​i​ が残差です。正なら観測が直線より上、負なら下です。残差と、観測できない真のモデル誤差は同じ概念ではありません。

最小二乗法は、縦方向のずれの二乗を小さくする

最小二乗法では、残差の二乗和 ∑i(yi−a−bxi)2\sum_i(y_i-a-bx_i)^2∑i​(yi​−a−bxi​)2 が最小になるa,bを選びます。[1] 点から線までの最短距離の二乗和ではなく、y方向のずれです。xとyを入れ替えた回帰は、一般に同じ線にはなりません。

xxx にばらつきがある場合、傾きと切片は次で求められます。

b=∑i(xi−xˉ)(yi−yˉ)∑i(xi−xˉ)2,a=yˉ−bxˉ.b=\frac{\sum_i(x_i-\bar x)(y_i-\bar y)}{\sum_i(x_i-\bar x)^2},\qquad a=\bar y-b\bar x.b=∑i​(xi​−xˉ)2∑i​(xi​−xˉ)(yi​−yˉ​)​,a=yˉ​−bxˉ.

前講で偏差積の合計は4、xの偏差二乗和は5、平均は2.5と3.5でした。よってb=4/5=0.8、a=3.5−0.8×2.5=1.5で、y^=1.5+0.8x\hat y=1.5+0.8xy^​=1.5+0.8x です。

残差の二乗和は1.8です。x=3の予測は3.9ですが、実際の一人は5でした。予測値が個人の結果を確定するわけではありません。残差を図や表で見て、大きなずれや規則的な曲がりがないかを点検します。

残差を足すと0になります。この性質は切片を含めた最小二乗当てはめでの性質で、どんなモデルの残差も必ずそうなるわけではありません。また、残差が0平均だから新しいデータへの予測も偏らないと自動的に保証されるわけではありません。

当てはまりと予測性能は別

参考として、yの平均だけで予測したときの二乗和は5です。回帰直線では1.8なので、決定係数は R2=1−1.8/5=0.64R^2=1-1.8/5=0.64R2=1−1.8/5=0.64 です。この切片付き単回帰では前講の相関0.8の二乗と一致します。

0.64は「64%の人を正しく予測した」「因果効果を64%説明した」ではありません。観測データのyの二乗変動に対し、どの程度二乗誤差が減ったかという指標です。yが全員同じで総変動が0なら、この比によるR²は定義できません。

モデルを作ったデータへの当てはまりが良くても、まだ見ていないデータで同程度に予測できるとは限りません。新しい観測で確かめるなど、目的に合う評価が必要です。基礎ではまず残差と予測の意味を理解し、高度なモデル選択は後続コースで学びます。

外挿と因果解釈に注意

観測したxは1〜4です。式へ100を入れることは計算上できますが、81.5点を妥当な予測とする根拠はこの4件にはありません。観測範囲の外で使うことを外挿と呼びます。得点に上限がある場合には、直線がその上限を越えてしまうこともあります。

傾き0.8も、「この集団の観測データを直線で要約した値」です。学習時間を意図的に1時間増やせば必ず0.8点上がるという因果効果ではありません。ほかの変数、測定誤差、対象者の違いを考えます。

記述的な直線の計算そのものには正規分布の仮定は不要です。一方、係数の信頼区間や検定、予測区間を作る場合には、誤差の構造や独立性など追加の条件が必要です。この区別を保ちます。

確認問題

問1：係数を求める

平均が2.5と3.5、偏差積の合計4、xの偏差二乗和5です。傾きと切片を求めてください。

解答と理由

傾き0.8、切片1.5です。傾きは4/5、切片は3.5−0.8×2.5です。相関係数と回帰係数は一般には異なり、今回は両変数の標準偏差が同じため数値が一致しています。

問2：残差の符号

x=3、観測y=5のとき、y^=1.5+0.8x\hat y=1.5+0.8xy^​=1.5+0.8x の予測値と残差を求めてください。

解答と理由

予測3.9、残差5−3.9=1.1です。正の残差は観測が予測より上にあることを表します。引く順序を逆にしません。

問3：別の線と比べる

4点に対して y^=1+x\hat y=1+xy^​=1+x を使った残差二乗和を求め、最小二乗直線の1.8と比較してください。

解答と理由

予測は2、3、4、5、残差は0、0、1、−1なので二乗和2です。1.8より大きく、この線より最小二乗直線の方が定めた基準でよく当てはまります。別の誤差基準なら別の線が選ばれる場合もあります。

まとめと次の一歩

直線は観測の要約で、残差はそのずれです。最小化した基準、単位、範囲、因果の限界を確認します。次は、関連の見え方が集団の混ざり方で変わる例を学びます。
