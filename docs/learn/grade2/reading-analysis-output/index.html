まず、何をどのデータで分析した表か

解析ソフトの表には多くの数値が並びます。最初に読むべきものは、目的変数、説明変数、分析した観測数、手法、標準誤差の種類です。列名にp-valueがあっても、それだけでは帰無仮説や条件は分かりません。

本講座ではG35の架空データ8行、Y=β0+β1x+β2D+εY=\beta_0+\beta_1x+\beta_2D+\varepsilonY=β0​+β1​x+β2​D+εというモデルを使います。D=0はA、D=1はBです。下の表は教材用に計算した表示例で、特定ソフトの実際の出力画面を転載・再現したものではありません。元の8行と式から再計算できます。

欠測により自動的に除かれた行があれば、元の表の人数と分析のnが違う場合があります。モデルを比較するときも同じ観測集合かを確認します。標本の一部を変えて得たR²の違いを、変数を追加しただけの変化と扱いません。

係数の表は、推定と精度と検定を分ける

通常の等分散の標準誤差による係数表は、次のようになります。

帰無値が0のとき、t=β^j/SE⁡(β^j)t=\hat\beta_j/\operatorname{SE}(\hat\beta_j)t=β^​j​/SE(β^​j​) です。t値は、推定値を標準誤差で割った数値です。係数0以外を帰無値にした場合は、その値を引いてから割ります。通常の正規線形モデルでは、ここで使うtの自由度は残差自由度5です。

Estimateの3は、同じxでのB−Aのモデル上の差です。SEの√0.8は、その係数推定量のばらつきの推定値です。tの約3.354は標準誤差何個分離れているかを表し、差が3.354という意味ではありません。

p値と信頼区間は、分布と設定を確認して読む

係数ごとの両側p値は、自由度5のt分布で2P(T≥|t|)として求めます。95%信頼区間は β^j±t0.975,5SE⁡(β^j)\hat\beta_j\pm t_{0.975,5}\operatorname{SE}(\hat\beta_j)β^​j​±t0.975,5​SE(β^​j​) です。xの係数なら2±約2.57058×0.4で、約0.972〜3.028です。

出力のp値が0.000などに丸めて表示されても、数学的に確率0と報告しません。必要な桁、指数表示、または適切な不等号で示します。「有意」を星の数だけで読むのではなく、何の帰無仮説を、どの標準誤差で、何回比較したかを確認します。

頑健標準誤差、クラスタを考慮した標準誤差、通常の等分散標準誤差などでは、同じ係数推定値でもSEや検定分布が違う場合があります。この表は通常の等分散モデルの計算です。設定を省略して他の出力と比較しません。

残差標準偏差と決定係数

出力のresidual standard errorに対応する値は√1.6です。これはyの単位で誤差の散らばりを推定した量で、個別係数の標準誤差とは別です。

R²=29/33≈0.87879、調整済みR²=137/165≈0.83030です。調整済みの計算では、切片を含む推定係数3個を数えます。R²が高いことだけでは、モデル条件、標本外予測、因果解釈が保証されたことにはなりません。

表の自由度から分析件数を検算することもできます。残差自由度5に推定係数3を足すとn=8です。ただしモデルが特異で実際の階数が落ちている場合などは、列の本数でなく有効な推定次元が関係します。

手法選択は、目的と観測単位から始める

二群の平均を比べるなら、独立二群か対応ありかを先に決めます。0・1の結果の割合なら、成功と失敗の件数、分母、帰無仮説を確認します。三群の平均なら一元配置分散分析などの全体の比較を考えますが、同じ人の三測定を独立三群と扱いません。

少数試行で成功0、母比率の帰無値0.1という例では、正規近似のz値を出す前に二項の確率を検討しました。方法選択を「変数が数値かカテゴリか」だけの分岐にしないことが重要です。

解析表が出たことは、入力データや手法が適切という保証ではありません。対象、単位、欠測、対応、仮定、どの結果を選んで報告したかまで、分析の経路を残します。

確認問題

問1：係数の表を解釈する

Dの推定値3、標準誤差√0.8、t値約3.354です。それぞれの役割を説明してください。

解答と理由

3は同じxでのB−Aのモデル上の平均差、√0.8はその推定量の標準誤差、約3.354は係数0からの差をSEで測った値です。t値を元の単位の効果量として扱いません。

問2：全体のF検定

SSR=58、回帰自由度2、SSE=8、残差自由度5です。F値と、このモデルでの帰無仮説を答えてください。

解答と理由

F=(58/2)/(8/5)=18.125、帰無仮説はxとDの母係数がともに0です。切片0を同時に検定しているわけではありません。

問3：R²と分析人数

残差自由度5、推定した独立な係数が切片込み3個、SSE=8、SST=66です。人数とR²、調整済みR²を確認してください。

解答と理由

n=8、R²=29/33、調整済みR²=137/165です。調整済みの分母の自由度は、残差5と全体7です。高い値でも将来予測の保証ではありません。

問4：前後の平均を比較する

同じ20人の前後の数値を比較したいとします。独立二群の出力が得られたので、そのままp値だけを報告してよいですか。

解答と理由

よくありません。同じ人の対応を考慮する必要があります。誰を一組とし、差の分布と組間の独立性がどうかを確認して手法を選び直します。

詳しく確かめる

表の値を、残差と設計から再構成する

G35の残差は±1が8個でSSE=8です。切片・x・Dの列は線形独立なので残差自由度5となり、s²=1.6です。xの中心化平方和は10、Dの中心化平方和は2で、両者の中心化積和は0です。

従って係数の推定分散はxで1.6/10=0.16、Dで1.6/2=0.8です。切片では1.6{1/8+2.5²/10+0.5²/2}=1.4です。これらの平方根が係数表のSEです。

独立正規・等分散のモデルを使うと、回帰全体のF値は、回帰と残差の独立な二乗和を自由度で割った比として評価できます。表を別の式へ戻して検算することで、分母や自由度を見落としにくくなります。
