基礎の計算を、推測の言葉へつなぐ

ある機器の測定誤差を調べるため、同じ条件で4回測定し、2、4、6、8という値を得たとします。説明用の架空データです。観測した4値の平均は5です。しかし、この装置を同じ条件で測り続けたときの平均まで、5と確定したわけではありません。

2級では、「この4値を要約する」という記述に加え、「この4値から、値を生み出す仕組みの特徴を考える」という推測を扱います。どちらも同じ平均の計算を使えますが、結論の対象が違います。公式へ代入する前に、何について知りたいかを一文で定めます。

以後、特に断りがなければ母平均は μ\muμ、母分散は σ2\sigma^2σ2、母比率は ppp と書きます。頻度論の基本モデルでは、母数は未知でも固定した値として扱い、標本を取り直すたびに変わるものとは区別します。別の枠組みで母数へ確率分布を置くベイズ統計は、準1級以降で整理します。

大文字と小文字は、観測前後を分ける手掛かり

観測する前の第i番目の値を XiX_iXi​、実際に得た値を xix_ixi​ とします。観測前の標本平均 Xˉ\bar XXˉ は、どんな標本が出るかによって値が変わる確率変数です。観測後の xˉ=5\bar x=5xˉ=5 は、一つの具体的な計算結果です。

すべての統計量を常に推定量と呼ぶわけではありません。統計量は検定やデータ要約にも使います。また、通常、統計量は標本と既知の定数から計算できる量です。未知の真の母平均を代入しなければ計算できない式を、観測だけで分かる統計量と取り違えないようにします。

文献によって大文字・小文字の省略や慣習は異なります。文字の形だけを暗記せず、「標本を取り直すと変わるのか」「観測して計算できるのか」を確かめると意味を追えます。

同じデータにも、二種類の分散が登場する

今回の平均は5で、偏差は−3、−1、1、3、偏差二乗和は20です。分母nの記述的な分散は20/4=5、不偏分散は20/3です。2級の公式範囲ではn−1で割る分散も明示されています。式の分母と用途を必ず確認します。

確認問題

問1：5は何の値か

4回の観測が2、4、6、8でした。母平均を標本平均で推定するとき、推定量と推定値を書いてください。

解答と理由

推定量は Xˉ=(X1+X2+X3+X4)/4\bar X=(X_1+X_2+X_3+X_4)/4Xˉ=(X1​+X2​+X3​+X4​)/4、今回の推定値は5です。未知の母平均 μ\muμ が5と判明したわけではありません。規則と、その規則へ観測値を入れた答えを区別します。

問2：定数はいくつ足すか

上のデータで ∑i=14(xi−2)\sum_{i=1}^4(x_i-2)∑i=14​(xi​−2) を求めてください。

解答と理由

20−4×2=12です。各値から2を引くので、合計からは8を引きます。20−2=18ではありません。

問3：二乗する場所

∑ixi2\sum_i x_i^2∑i​xi2​ と (∑ixi)2(\sum_i x_i)^2(∑i​xi​)2 を、それぞれ求めてください。

解答と理由

前者は4+16+36+64=120、後者は20²=400です。合計の二乗には異なる値の積も入ります。分散計算で二つを交換しないようにします。

問4：分散の分母

偏差二乗和20、n=4です。不偏分散とその平方根を求め、真の母分散との関係を説明してください。

解答と理由

不偏分散は20/3≈6.667、標本標準偏差は約2.582です。独立同分布で有限分散などの条件のもと、不偏分散の期待値が母分散になります。一回の値が母分散に等しい保証ではありません。

詳しく確かめる

偏差の和が0になることを、定義だけから示す

n個の有限の実数値について、平均の定義から ∑ixi=nxˉ\sum_i x_i=n\bar x∑i​xi​=nxˉ です。よって、

∑i(xi−xˉ)=∑ixi−∑ixˉ=nxˉ−nxˉ=0.\sum_i(x_i-\bar x)=\sum_i x_i-\sum_i\bar x=n\bar x-n\bar x=0.i∑​(xi​−xˉ)=i∑​xi​−i∑​xˉ=nxˉ−nxˉ=0.

正規分布や独立性は不要で、どの有限データにも成り立つ恒等式です。確率変数で書いた場合も、各標本の結果ごとに成り立ちます。この「すべての結果で0」と、「ある量の期待値が0」は別の強さの主張です。例えば誤差が正負にぶれて平均として0でも、各回が0とは限りません。

n−1という分母も、この恒等式を見ただけで完全に正当化されたわけではありません。母分散を推定する目的と確率モデルを置き、二乗和の期待値を計算する段階が必要です。直感的な自由度の説明と、後の不偏性の証明を分けて読みます。
