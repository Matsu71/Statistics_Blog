回数ではなく、成功したら止める規則

成功確率pの独立な試行を繰り返し、最初の成功で止めます。成功を含む総試行数Tは1、2、3、…です。T=tは、最初のt−1回が失敗で、t回目が成功という型なので、

P(T=t)=(1−p)t−1p,t=1,2,….P(T=t)=(1-p)^{t-1}p,\qquad t=1,2,\ldots.P(T=t)=(1−p)t−1p,t=1,2,….

これが試行数を数える幾何分布です。この講座では0<p≤1で、各回のpが共通とします。途中の学習によって成功率が上がる試行などへ、説明なしに当てはめません。

二項分布では回数nを先に固定し、成功数が変わりました。ここでは成功したら止めるので試行数が変わります。「何を固定し、何を数えるか」を問題文から読み取ることが先です。

試行数か、失敗数かを最初に確かめる

失敗数K=T−1で幾何分布を定義する資料もあります。その場合、値域はK=0、1、2、…で、確率はP(K=k)=(1−p)^k pです。同じ試行の違う数え方なので、平均は1だけ違い、分散は変わりません。

仮想のp=0.3なら、3回目に初めて成功する確率は0.7²×0.3=0.147です。平均試行数は1/p≈3.333、平均失敗数は(1−p)/p≈2.333、分散はどちらも(1−p)/p²≈7.778です。

成功を含む試行数T11/p(1−p)/p²
成功前の失敗数K0(1−p)/p(1−p)/p²

平均が小数でも、実際に3.333回で停止する意味ではありません。離散変数の期待値は、取り得る値の中にある必要はありません。ソフトの関数を使うときも、値域が0からか1からかを確認します。

まだ成功しなくても、残りの条件は同じ

m回失敗したと分かった後、さらにn回を超えて待つ確率は、0<p<1で

P(T>m+n∣T>m)=(1−p)m+n(1−p)m=(1−p)nP(T>m+n\mid T>m)=\frac{(1-p)^{m+n}}{(1-p)^m}=(1-p)^nP(T>m+n∣T>m)=(1−p)m(1−p)m+n​=(1−p)n

です。m,nは非負整数です。これを無記憶性と呼びます。すでに待った分を含む総試行数が同じ分布という意味ではなく、残りの待ち回数の条件付き分布が同じです。

失敗が続いたから次こそ成功しやすい、という帳尻合わせはありません。独立で共通pというモデルを固定しているからです。現実の装置のpが未知で、失敗を見て性能への見方を更新する問題とは区別します。

r回成功するまでの試行数

rを正の整数とし、r回目の成功まで続けます。総試行数Tはr以上です。T=tなら最後のt回目が成功で、それ以前のt−1回にはr−1回の成功が必要なので、

P(T=t)=(t−1r−1)pr(1−p)t−r,t=r,r+1,….P(T=t)=\binom{t-1}{r-1}p^r(1-p)^{t-r},\qquad t=r,r+1,\ldots.P(T=t)=(r−1t−1​)pr(1−p)t−r,t=r,r+1,….

これが総試行数で表した負の二項分布です。二項分布のように最後の成功位置も自由に選ぶ (tr)\binom tr(rt​) ではありません。「停止した最後は必ず成功」という条件が、組合せの数を変えます。

p=0.3、r=2で5回目に2回目の成功が出る確率は、4×0.3²×0.7³=0.12348です。r=1にすれば、幾何分布へ戻ります。

負の二項分布にも、失敗数の定義がある

K=T−rを失敗数とすれば、K≥0で、確率は (k+r−1r−1)pr(1−p)k\binom{k+r-1}{r-1}p^r(1-p)^k(r−1k+r−1​)pr(1−p)k です。平均試行数はr/p、平均失敗数はr(1−p)/p、分散はどちらもr(1−p)/p²です。

r=2、p=0.3なら平均試行数約6.667、平均失敗数約4.667、分散約15.556です。成功から次の成功までの待ち回数を、独立な幾何変数r個の和として考えられます。

計数データのモデルでは、rを実数に一般化したり、平均と過分散でパラメータ化したりすることもあります。ただし、実数rを「r回目の成功」という停止規則へそのまま読み替えるものではありません。まず問題文が採用する定義を確認します。

p=1ではT=r、K=0に固定されます。p=0では成功が起こらず、有限の待ち回数を取るこの分布の条件外です。端の値で無条件に平均1/pを使わないようにします。

確認問題

問1：最初の成功

p=0.3の独立試行で、3回目に初めて成功する確率を求めてください。

解答と理由

0.7²×0.3=0.147です。先に2回失敗し最後に成功する順序が固定されています。成功位置の3通りを掛ける問題ではありません。

問2：2回目の成功まで

同じpで、5回目に2回目の成功が出る確率は何ですか。

解答と理由

(41)0.320.73=0.12348\binom41 0.3^2 0.7^3=0.12348(14​)0.320.73=0.12348 です。5回目は成功なので、最初の4回のうち1回を成功にします。

問3：平均の定義

r=2、p=0.3で、総試行数と失敗数の期待値を求めてください。

解答と理由

総試行数は2/0.3≈6.667、失敗数は2×0.7/0.3≈4.667です。成功2回分を含むかどうかで違います。分散はどちらも約15.556です。

問4：失敗が続いた後

p=0.3で5回失敗したと分かりました。さらに2回とも失敗する確率はいくつですか。

解答と理由

0.7²=0.49です。独立・共通pを仮定しているため、すでに待った5回で次の条件は変わりません。

詳しく確かめる

幾何分布の平均と分散を級数から導く

q=1−p、0≤q<1とすると、幾何級数はΣ_{t=0}∞q^t=1/(1−q)です。収束円内で項別微分し、Σ_{t=1}∞tq^{t−1}=1/(1−q)²を得ます。pを掛ければE[T]=1/pです。

もう一度微分した式からE[T(T−1)]=2q/p²です。E[T²]=E[T(T−1)]+E[T]なので、

V(T)=2qp2+1p−1p2=qp2.V(T)=\frac{2q}{p^2}+\frac1p-\frac1{p^2}=\frac q{p^2}.V(T)=p22q​+p1​−p21​=p2q​.

独立な幾何待ち回数をr個足せば、平均r/p、分散rq/p²です。失敗数へ変えるために定数rを引いても、分散は変わりません。停止規則による確率の数え上げと、級数によるモーメントの計算がつながります。
