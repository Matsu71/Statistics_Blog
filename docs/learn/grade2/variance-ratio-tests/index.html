平均の差とは別の問い

工程の平均が基準と同じでも、所要時間の散らばりが増えているかもしれません。母分散がσ₀²と等しいか、二群の分散比が1かなど、散らばりそのものを検定する問いを定めます。

この講座の正確な検定は、独立同分布の正規標本に基づきます。分散の推測は非正規性や外れ値に敏感なので、母平均の大標本近似と同じ感覚で条件を省略しません。以下は仮想の標本要約です。

一つの母分散の帰無仮説

H₀:σ²=σ₀²>0に対し、統計量は

U=(n−1)S2σ02∼χn−12U=\frac{(n-1)S^2}{\sigma_0^2}\sim\chi^2_{n-1}U=σ02​(n−1)S2​∼χn−12​

です。S²は分母n−1の不偏分散です。分母は帰無仮説の母分散で、母標準偏差σ₀をそのまま入れません。

n=10、s²=25、帰無分散9なら、u=9×25/9=25、自由度9です。両側5%の等しい裾の検定では、左側2.5%点約2.70039と97.5%点約19.02277の外側で棄却します。25は上端を超えるため棄却します。

左右対称ではないので、下端を−19.02277としてはいけません。小さすぎる分散も、大きすぎる分散も、両側の対立仮説では対象になります。

両側p値の定義を示す

本講座では等しい裾の検定に対応して、連続分布の両側p値を2×min{左側累積確率、右側確率}とします。値は高々1です。この定義で、G23の等裾の分散区間と判定が対応します。

非対称な分布で「極端さ」を別に定める検定もあり得ます。両側という名前だけで、すべてが同じp値の定義になるわけではありません。ソフトや問題の指定とそろえます。

上側の片側検定なら右側だけ、小さい分散の片側検定なら左側だけを使います。結果が大きかったから上側へ変更することはせず、問いの方向を先に定めます。

二群の分散比のF検定

独立な正規二群について、H₀:σ₁²/σ₂²=θ₀>0を検定します。統計量は

F=S12/S22θ0∼Fn1−1,n2−1.F=\frac{S_1^2/S_2^2}{\theta_0}\sim F_{n_1-1,n_2-1}.F=θ0​S12​/S22​​∼Fn1​−1,n2​−1​.

等分散ならθ₀=1です。群の順序を固定し、分子・分母の自由度もそれに合わせます。大きい標本分散を上に置き換える方法を使う場合でも、自由度と両側の定義を対応させる必要があります。

各群n=3、s₁²=8、s₂²=4で等分散を検定するなら、f=2、自由度2,2です。F_{2,2}の累積確率はf/(1+f)なので、左側2/3、右側1/3、等裾の両側p値は2/3です。5%では棄却しません。

比を逆にしても、同じ両側の問いなら整合する

同じ例で群2/群1を取るとf=0.5です。分布の自由度を交換し、左右の裾も対応させれば、両側p値は同じ2/3になります。一般に自由度が異なる場合、分散の比だけ逆にして自由度をそのままにすると誤ります。

F検定という言葉は回帰や分散分析にも現れますが、それらでは「説明できる変動が誤差に比べて大きいか」という右側の検定を行います。この分散比の両側p値の2倍ルールを、すべてのF統計量へ当てはめません。

非有意は等分散の証明ではない

小標本では、真の分散比が1からかなり離れていても検出できないことがあります。本文のn=3の例では、G23の分散比区間が非常に広いこととも整合します。p値だけで「二群のばらつきは同じ」と断定しません。

平均差の分析の前に分散検定を行い、非有意なら等分散と確定するという使い方も避けます。等分散を仮定した方法の条件と、Welchなど別の方法の性質を比較して判断します。

非正規データでは、絶対偏差などを用いる別の分散比較もありますが、帰無仮説や条件が同じとは限りません。本講座のカイ二乗・F法の正確な結果は、明記した正規・独立のモデルに限定します。

確認問題

問1：母分散9を検定する

n=10、s²=25の独立正規標本です。H₀:σ²=9について統計量、自由度、両側5%の判断を答えてください。

解答と理由

u=25、自由度9です。上側境界19.02277を超えるので棄却します。σ₀=3ではなくσ₀²=9で割ります。

問2：等分散のF検定

独立正規二群で各n=3、標本分散8と4です。等裾の両側p値を求めてください。

解答と理由

F=2、自由度2,2、左側2/3・右側1/3なのでp=2/3です。上側1/3をそのまま両側p値とは呼びません。

問3：自由度の順序

群1がn=6、群2がn=11です。S₂²/S₁²を使うとき、帰無仮説のF分布の自由度はどの順ですか。

解答と理由

分子が群2なので10,5です。元の群番号の順に5,10としたまま、比だけ逆にしません。

問4：非有意の利用

等分散の検定が非有意でした。母分散が等しいと確定し、どの平均差分析にも等分散法を使ってよいですか。

解答と理由

よくありません。非有意は等分散の証明ではなく、検出力不足の可能性もあります。研究設計や分布、方法全体の性質を確認します。

詳しく確かめる

等裾検定と分散区間の対応を確かめる

母分散の帰無値σ₀²を棄却しない条件は、cL≤(n−1)s²/σ₀²≤cUです。すべて正の量なので、これは(n−1)s²/cU≤σ₀²≤(n−1)s²/cLと同値です。G23の同じ等裾区間に帰無値が入る条件です。

Fの比でも、fL≤R/θ₀≤fUを反転すればR/fU≤θ₀≤R/fLです。非対称な分布であっても、同じ分位点と構成を使えば区間と検定は整合します。

ここで2×小さい裾というp値を選んだことは重要です。別の極端さを用いる検定や区間と混ぜて、必ず一致すると一般化しません。
