三群の平均を一つの検定で比較する

三つの案内方式の所要時間を比較する、架空のデータを作ります。各人は一方式だけを使用し、各群の人は独立であると考えます。データはAが8、9、10、Bが10、11、12、Cが12、13、14です。

方式観測値人数標本平均
A8、9、1039
B10、11、12311
C12、13、14313

H₀:μA=μB=μCが帰無仮説です。対立仮説は「すべて同じではない」であり、「すべての組がそれぞれ違う」とは別です。全体で9人、全体平均は11です。

一元配置の一元は、分類する要因が一つという意味です。群が一つという意味ではありません。ここでは方式という一つの要因に三つの水準があります。

全体の変動を二つに分ける

各観測が全体平均からどれだけ離れているかを二乗して足したものが全平方和SSTです。群内では各群の平均からのずれを使い、群内平方和SSWを計算します。

各群の平均からの偏差は−1、0、1なので、各群の平方和は2、三群の合計SSW=6です。群の平均が違っていても、その内部の散らばりはこの例では同じです。

群間平方和SSBは、各群の平均と全体平均の差の二乗に群の人数を掛け、足したものです。

SSB=∑j=1knj(yˉj−yˉ)2.SSB=\sum_{j=1}^k n_j(\bar y_j-\bar y)^2.SSB=j=1∑k​nj​(yˉ​j​−yˉ​)2.

本文では3×(9−11)²+3×(11−11)²+3×(13−11)²=24です。全平方和は30で、24+6=30と分解できます。人数が違う群でも、群平均を単純平均せず、全人数で重み付けした全体平均を使います。

平方和を、対応する自由度で割る

群数k、全人数Nのとき、群間の自由度はk−1、群内はN−k、全体はN−1です。各群で平均を一つずつ推定するため、群内ではk個の自由度を使います。

平方和を自由度で割ったものが平均平方です。群間平均平方MSBを群内平均平方MSWで割ってF統計量を作ります。

変動の由来平方和自由度平均平方F
群間2421212
群内・誤差661—
全体308——

F=12/1=12、分子自由度2、分母自由度6です。平方和24をそのまま6で割って4とするのではなく、両方をそれぞれの自由度で割ります。

帰無仮説のもとで右側の確率を読む

独立した正規観測で、各群の母分散が共通というモデルを仮定すると、等平均の帰無仮説のもとでFはF_{k−1,N−k}に従います。群平均が誤差に比べて大きく離れたときにFが大きくなるので、右側を使います。

本文はF_{2,6}の右側確率P(F≥12)=0.008です。有意水準5%では等平均を棄却します。少なくとも一部の母平均が異なるという証拠ですが、どの組がどの程度違うかは、この一つの検定だけでは決まりません。

群の平均・散らばり・人数と、必要な効果の推定を合わせて報告します。検定が有意であることから、差がすべて実用上重要だと自動判断しません。

なぜ三組のt検定だけで済ませないのか

A対B、A対C、B対Cをそれぞれ5%で検定し、どれかが有意なら差があるとする手順は、全体として5%の第一種過誤率と同じではありません。比較を多数行うときには、検定の集合として誤り率をどう管理するかを考えます。

分散分析の全体検定の後、どの比較が研究上必要かを明示し、適切な多重比較法や事前に定めた対比を使います。全体検定が有意だから、後のあらゆる比較を無補正で何回でも行ってよいわけではありません。

三群の検定で非有意だったことも、全群の平均が同じと証明した結果ではありません。標本数が少ない、群内のばらつきが大きいなどの理由で、重要な差を検出できない可能性があります。

モデルと研究設計の条件を確認する

同じ人が三方式を順に使ったデータは、独立三群のこの分析ではありません。個人内の対応や順序の効果を考える必要があります。同じ施設の記録を多数含む場合も、独立な単位を確認します。

群内の強い歪みや外れ値、分散の違いは、通常のF分布による推測へ影響します。残差図や研究対象の知識を使って点検し、必要なら異なる方法を検討します。一つの前提確認の検定が非有意だから、条件が証明されたとは扱いません。

平方和の分解そのものは、有限データの代数的な恒等式です。そこからF分布のp値を計算する段階で、独立正規・等分散などの条件を使います。計算と推測の根拠を区別します。

確認問題

問1：分散分析表

本文の三群についてSSB、SSW、両自由度、F値を求めてください。

解答と理由

SSB=24、SSW=6、自由度2と6です。MSB=12、MSW=1なのでF=12です。帰無仮説のF_{2,6}の右側p値は0.008です。

問2：全体検定の結論

等平均の帰無仮説を棄却しました。A対B、A対C、B対Cのすべてに差があると証明できましたか。

解答と理由

できません。全体検定の対立仮説は、全母平均が同じではないことです。どの組がどれだけ違うかは、推定や計画した比較を別に行います。

問3：全平方和と自由度

群間平方和24、群内平方和6、N=9、k=3です。全平方和と、三つの自由度の関係を確認してください。

解答と理由

全平方和30、全自由度8です。群間2と群内6の和が8になります。各群の平均を求めた制約が、群内自由度へ入っています。

問4：同じ人が三方式を試す

同じ3人がA、B、Cをすべて試しました。測定値が9個あるので独立9人として本文の一元配置分散分析を使えますか。

解答と理由

そのままは使えません。同じ人の測定に対応があり、9個の独立な人の観測とは異なります。個人や順序を考慮する設計・分析が必要です。

詳しく確かめる

全平方和を群間と群内へ分解する

観測yijについて、yij−ȳ=(yij−ȳj)+(ȳj−ȳ)と書けます。二乗して群内で足すと、交差項にはΣᵢ(yij−ȳj)=0が含まれるため消えます。従って、

∑j∑i(yij−yˉ)2=∑j∑i(yij−yˉj)2+∑jnj(yˉj−yˉ)2.\sum_j\sum_i(y_{ij}-\bar y)^2 =\sum_j\sum_i(y_{ij}-\bar y_j)^2 +\sum_j n_j(\bar y_j-\bar y)^2.j∑​i∑​(yij​−yˉ​)2=j∑​i∑​(yij​−yˉ​j​)2+j∑​nj​(yˉ​j​−yˉ​)2.

左辺がSST、右辺がSSWとSSBです。群の人数が等しくなくても、重みnjを保てば成り立ちます。

正規・等分散の帰無モデルでは、群間と群内の平方和をσ²で割った量が、対応する自由度の独立なカイ二乗変数になります。その自由度で割った比としてF分布を得ます。有限データの分解だけから、無条件にこの確率分布まで導けるわけではありません。
