相関行列は、二変数の関係を一覧にする

三つの変数X,Y,Zの相関をまとめた行列では、対角成分は1、対角を挟む成分は同じです。各変数の分散が正で、同じ観測集合を使って計算した場合を考えます。

仮想例としてrXY=0.8、rXZ=0.5、rYZ=0.6なら、

R=(10.80.50.810.60.50.61).R=\begin{pmatrix}1&0.8&0.5\\0.8&1&0.6\\0.5&0.6&1\end{pmatrix}.R=​10.80.5​0.810.6​0.50.61​​.

共分散行列は対角に各分散が入り、単位にも依存します。相関行列は標準化した共分散を並べたものです。欠測によりペアごとに別の対象を使った場合には、単一の観測集合の相関行列としての性質が崩れることもあるので、計算対象を確認します。

第三の変数と一緒に変わる部分を考える

XとYが相関していても、両方がZに関連していることが影響しているかもしれません。偏相関は、XとYからZによる線形の部分をそれぞれ取り除いた残差どうしの相関です。

一つのZを調整するとき、分母が正なら

rXY⋅Z=rXY−rXZrYZ(1−rXZ2)(1−rYZ2)r_{XY\cdot Z}=\frac{r_{XY}-r_{XZ}r_{YZ}} {\sqrt{(1-r_{XZ}^2)(1-r_{YZ}^2)}}rXY⋅Z​=(1−rXZ2​)(1−rYZ2​)​rXY​−rXZ​rYZ​​

です。本文の値なら分子0.8−0.5×0.6=0.5、分母√0.48なので、偏相関は約0.72169です。単純相関0.8から、線形調整した関連へ問いが変わりました。

ZとXが完全な直線関係なら、Xの残差が0になり、通常の偏相関を計算できない場合があります。分母0を便宜的に0へ置き換えず、変数の関係を確認します。

調整しただけで因果効果とは言えない

偏相関は、指定した変数に対する線形調整の結果です。測っていない交絡、非線形の関係、測定誤差、結果の後に決まる変数を調整する問題などは、式へ代入しただけでは解決しません。

偏相関が0でも、一般には条件付き独立が証明されたことにはなりません。また「偏相関0.7だから、Xを増やすとYが0.7増える」という回帰係数や因果効果の読み方も誤りです。相関は単位をそろえた直線的関連の指標です。

何を調整するかは研究目的とデータ生成の仕組みから決めます。都合のよい値になるまで変数を選び直した場合、結果の不確かさや選択の影響を別に考える必要があります。

標本相関と母相関を区別する

観測した相関rは、固定した母相関ρそのものではありません。標本を取り直すとrも変わります。相関が0.5でも、n=8とn=200では、母相関についての精度が違います。

独立な組の2変量正規標本では、Fisher変換 z=atanh⁡(r)=12log⁡((1+r)/(1−r))z=\operatorname{atanh}(r)=\frac12\log((1+r)/(1-r))z=atanh(r)=21​log((1+r)/(1−r)) を使う近似があります。n>3、|r|<1として、変換後の標準誤差を約1/√(n−3)とします。

z±z1−α/2normal1n−3z\pm z_{1-\alpha/2}^{\mathrm{normal}}\frac1{\sqrt{n-3}}z±z1−α/2normal​n−3​1​

を求め、両端をtanhで戻してρの近似区間にします。ここで右側のz分位点は標準正規の分位点です。同じzという文字でも、Fisher変換値と分位点の役割を区別します。

Fisher変換の数値例

n=20、r=0.5なら、変換値は約0.54931、標準誤差は約0.24254です。1.96を使った変換後の区間は約0.07394〜1.02468、逆変換した母相関の95%近似区間は約0.074〜0.772です。

rの周りに左右同じ幅の区間ではありません。非線形な逆変換をしたためです。またrに直接±1.96/√(n−3)を足し引きする方法ではありません。まず変換した尺度で区間を作ります。

小標本、非正規、外れ値や強い非線形がある場合には、この近似の妥当性を検討します。r=±1では通常のFisher変換が無限になるため、定型式へ無条件に代入しません。

相関0の検定との関係

独立な2変量正規標本でH₀:ρ=0を検定するときは、t=r(n−2)/(1−r2)t=r\sqrt{(n-2)/(1-r^2)}t=r(n−2)/(1−r2)​ が帰無仮説のもとで自由度n−2のt分布です。n=20、r=0.5ならt=√6≈2.44949です。

この正確な帰無分布の自由度n−2と、Fisher近似の標準誤差にあるn−3は違います。対象と構成が異なる式を混ぜません。Fisherの近似区間と厳密なρ=0のt検定は、あらゆる数値で完全に同じ手順ではないことにも注意します。

確認問題

問1：偏相関

rXY=0.8、rXZ=0.5、rYZ=0.6のとき、Zを調整した偏相関を求めてください。

解答と理由

0.5/√0.48≈0.72169です。0.8−0.5−0.6ではありません。残差の尺度に合わせる分母も必要です。

問2：相関と共分散

Xの標準偏差2、Yの標準偏差3、相関0.5です。共分散行列のX,Yに対応する非対角成分はいくつですか。

解答と理由

0.5×2×3=3です。相関行列なら0.5ですが、共分散行列では各変数の尺度を戻します。

問3：母相関の近似区間

n=20、r=0.5について、本文のFisher変換による95%近似区間を説明してください。

解答と理由

変換値約0.54931に±1.96/√17を付け、端点をtanhで戻します。ρの区間は約0.074〜0.772です。相関rの尺度に直接同じ半幅を加えません。

問4：偏相関と因果

Zで調整した偏相関が正でした。「Xを介入で増やせばYも増える」と結論してよいですか。

解答と理由

この計算だけでは結論できません。線形調整した関連であり、未測定の交絡や調整する変数の選び方など、因果推論の追加条件が必要です。

詳しく確かめる

残差の共分散から偏相関の式を導く

三変数を平均0・分散1へ標準化します。Zへの単回帰によるX,Yの残差はU=X−rXZ Z、V=Y−rYZ Zです。共分散の線形性からCov(U,V)=rXY−rXZ rYZ、分散はそれぞれ1−rXZ²、1−rYZ²です。

両分散が正なら、共分散を標準偏差の積で割ると本文の偏相関になります。これは同じデータ集合の線形残差の代数的な関係であり、因果の矢印を証明したものではありません。

Fisher変換による標準誤差1/√(n−3)は近似結果です。この残差の恒等式の証明とは別で、近似を「厳密な有限標本の恒等式」として扱いません。

まとめと次の一歩

行列、偏相関、母相関の区間は異なる目的を持ちます。調整と因果を分け、推測の条件を確認します。次章は仮説検定の構成です。
