合計と差では、共通の動きが逆に働く

二つの工程の時間XとYが、混雑した日には一緒に長くなるとします。合計時間X+Yは、その共通する増加を受けて大きくぶれます。一方、二つの時間の差X−Yでは、共通の増加が打ち消されることがあります。

それぞれの分散だけでは、この違いを計算できません。どの程度一緒に動くかを表す共分散が必要です。「二つの工程だから独立」と決めず、同じ日、担当者、材料などの共通要因を確認します。

この講座では、期待値には必要な絶対可積分性、分散には有限の二次モーメントを仮定します。存在しない平均や分散へ、形式だけの式を当てはめないための条件です。以下の数値例は説明用の仮想モデルです。

期待値の足し算には独立性はいりません

既知の定数a,b,cについて、

E[aX+bY+c]=aE[X]+bE[Y]+cE[aX+bY+c]=aE[X]+bE[Y]+cE[aX+bY+c]=aE[X]+bE[Y]+c

が成り立ちます。XとYが独立でなくてもよい、期待値の線形性です。一方、積についての E[XY]=E[X]E[Y]E[XY]=E[X]E[Y]E[XY]=E[X]E[Y] は一般には成立しません。独立性は、その分解を保証する代表的な条件です。

例えばY=XならE[X+Y]=2E[X]ですが、E[XY]=E[X²]です。Xにばらつきがあれば、E[X²]はE[X]²より大きくなります。和・定数倍に使えるルールを、積や二乗へ広げないようにします。

分散には、偏差どうしの積が現れる

共分散は Cov⁡(X,Y)=E[(X−E[X])(Y−E[Y])]\operatorname{Cov}(X,Y)=E[(X-E[X])(Y-E[Y])]Cov(X,Y)=E[(X−E[X])(Y−E[Y])] です。展開すれば E[XY]−E[X]E[Y]E[XY]-E[X]E[Y]E[XY]−E[X]E[Y] と同じです。線形結合の分散は、

Var⁡(aX+bY+c)=a2Var⁡(X)+b2Var⁡(Y)+2abCov⁡(X,Y).\operatorname{Var}(aX+bY+c) =a^2\operatorname{Var}(X)+b^2\operatorname{Var}(Y)+2ab\operatorname{Cov}(X,Y).Var(aX+bY+c)=a2Var(X)+b2Var(Y)+2abCov(X,Y).

定数cは分散に入りません。a,bは、それぞれの分散に掛けるときには二乗し、共分散に掛けるときには積にします。差ならb=−1なので、共分散の項は負になります。

求める量分散の式
X+YV(X)+V(Y)+2Cov⁡(X,Y)V(X)+V(Y)+2\operatorname{Cov}(X,Y)V(X)+V(Y)+2Cov(X,Y)
X−YV(X)+V(Y)−2Cov⁡(X,Y)V(X)+V(Y)-2\operatorname{Cov}(X,Y)V(X)+V(Y)−2Cov(X,Y)
2X−Y4V(X)+V(Y)−4Cov⁡(X,Y)4V(X)+V(Y)-4\operatorname{Cov}(X,Y)4V(X)+V(Y)−4Cov(X,Y)

Vは分散の略記です。独立なら共分散は0になり、分散を足せます。ただし共分散0から独立を逆に結論することは、一般にはできません。また、標準偏差を直接足す公式ではなく、最後に分散の平方根を取ります。

同時分布からの直接計算と照合する

G08のモデルでは、P(X=0,Y=0)=0.4、P(0,1)=0.1、P(1,0)=0.2、P(1,1)=0.3でした。E[X]=0.5、E[Y]=0.4、V(X)=0.25、V(Y)=0.24、共分散は0.1です。

和S=X+Yの平均は0.9、分散は0.25+0.24+0.2=0.69です。差D=X−Yの平均は0.1、分散は0.25+0.24−0.2=0.29です。同じ二変数でも、和と差ではばらつきが違います。

和の分布を使っても確認できます。Sが0、1、2となる確率は0.4、0.3、0.3なので、E[S²]=0.3+4×0.3=1.5です。E[S]²=0.81を引けば、V(S)=0.69と一致します。式へ代入した結果と、値ごとの確率からの計算が結び付きました。

相関係数を、そのまま共分散に代入しない

標準偏差が σX,σY>0\sigma_X,\sigma_Y>0σX​,σY​>0、相関がρなら、共分散は ρσXσY\rho\sigma_X\sigma_YρσX​σY​ です。相関は単位のない指標ですが、共分散には二つの変数の単位の積があります。

標準偏差2分と3分、相関0.5なら、共分散は3分²です。合計の分散は4+9+6=19分²、差の分散は4+9−6=7分²になります。相関0.5を共分散の場所へそのまま入れると、数値も単位の意味も誤ります。

相関が1の場合には合計の標準偏差が2+3=5分になりますが、いつもこの結果になるわけではありません。正の相関、負の相関、無相関で合計の不確かさが変わることを考えます。

観測の対応を保つ

二列を別々に並べ替えると、それぞれの平均や分散は保たれても、共分散は変わります。実際には一緒に観測されなかった組を作るからです。同じ人、時点、製品など、何を一組としているかを残します。

多変数の和にも、各組の共分散が入ります。時系列や同じ人の繰り返し測定で、件数だけを見て独立な標本平均の式を使わないようにします。計算ルールを覚えるだけでなく、データの得られ方に戻って条件を点検することが重要です。

確認問題

問1：和と差

本文の0・1モデルで、X+YとX−Yの平均・分散を求めてください。

解答と理由

和は平均0.9・分散0.69、差は平均0.1・分散0.29です。平均は足し引きし、分散では共分散0.1の2倍を加減します。

問2：定数を含む線形結合

同じモデルで2X−Y+5の期待値と分散を求めてください。

解答と理由

期待値は2×0.5−0.4+5=5.6、分散は4×0.25+0.24−4×0.1=0.84です。定数5は期待値に入り、分散には入りません。

問3：相関から共分散へ

標準偏差が2と3、相関0.5です。共分散と合計の分散を求めてください。

解答と理由

共分散は0.5×2×3=3、合計の分散は4+9+2×3=19です。相関を分散として足すわけではありません。

問4：二乗の期待値

E[X]=3、V(X)=4のとき、E[X²]はいくつですか。

解答と理由

4+3²=13です。E[X]²=9とは違います。分散が0のときに限り、この二つの値が一致します。

詳しく確かめる

線形結合の分散を、偏差の二乗から導く

U=X−E[X]U=X-E[X]U=X−E[X]、V=Y−E[Y]V=Y-E[Y]V=Y−E[Y] と置きます。aX+bY+cからその期待値を引くとaU+bVです。二乗して期待値を取れば、

E[(aU+bV)2]=a2E[U2]+b2E[V2]+2abE[UV].E[(aU+bV)^2]=a^2E[U^2]+b^2E[V^2]+2abE[UV].E[(aU+bV)2]=a2E[U2]+b2E[V2]+2abE[UV].

各項が分散と共分散なので本文の式を得ます。有限の二次モーメントがあれば、Cauchy–Schwarzの不等式によりE[|UV|]も有限で、これらを正当に扱えます。

この導出に独立性や正規性は要りません。独立性を使うのは、共分散を0として簡略化する段階です。一般式の条件と、簡略化のための追加条件を区別します。
