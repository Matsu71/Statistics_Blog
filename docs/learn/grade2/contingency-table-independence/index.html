二つの分類が、関連しているかを問う

仮想の100人について、利用した案内がAかBか、手続きを完了できたかを一人一回ずつ記録したとします。観測度数は次の通りです。説明用に作成したデータで、実際の利用者調査ではありません。

案内完了未完了合計
A302050
B203050
合計5050100

Aの完了率は60%、Bは40%です。違いは20パーセントポイントですが、母集団でも案内と完了が関連しているかは、標本の変動を考えて推測します。

一つの無作為標本で二変数の独立を調べる場合と、別々に抽出した二群の割合が同じかを調べる場合では、標本の取り方と問いが異なります。通常の独立な観測と適切な条件のもとでは、同じPearson統計量と漸近的な自由度で比較できます。ただしデータ収集の説明まで同じになるわけではありません。

独立なら、行と列の割合を掛ける

帰無仮説は、二つのカテゴリ変数が母集団で独立であることです。独立なら各セルの確率は行の周辺確率と列の周辺確率の積になります。未知の周辺確率を標本から推定すると、期待度数は

Eij=行iの合計×列jの合計nE_{ij}=\frac{\text{行}i\text{の合計}\times\text{列}j\text{の合計}}{n}Eij​=n行iの合計×列jの合計​

です。本文では全セルが50×50/100=25になります。「全体100を4で割る」という近道が使えたのは、今回は周辺合計が等しいためです。一般の表では各行・各列の合計を使います。

例えば別の表で、全体100、ある行の合計40、ある列の合計30なら、そのセルの期待度数は12です。観測セルの件数を分母へ使う式ではありません。期待度数は整数でなくても構いません。

Pearson統計量と自由度

観測度数をO、期待度数をEとして、

X2=∑i,j(Oij−Eij)2EijX^2=\sum_{i,j}\frac{(O_{ij}-E_{ij})^2}{E_{ij}}X2=i,j∑​Eij​(Oij​−Eij​)2​

を計算します。ここでは連続修正を加えないPearson検定を扱います。本文は各セルの差が±5なので、X²=4×25/25=4です。

行数をr、列数をcとする通常の表では、自由度は(r−1)(c−1)です。2×2表なら1で、上側p値は約0.04550です。この近似法による両側の関連の検定では、有意水準5%で独立性の帰無仮説を棄却します。統計量は二乗で方向をまとめた量なので、カイ二乗分布の右側を使います。ここでさらにp値を2倍しません。

2×2表では、比率差のz検定ともつながる

本文の二群を独立な群とすると、プールした完了率は0.5です。等比率の帰無仮説での標準誤差は√{0.5×0.5×(1/50+1/50)}=0.1なので、z=(0.6−0.4)/0.1=2です。

その二乗z²=4が、連続修正なしのPearson統計量と一致します。標準正規の両側p値と、自由度1のカイ二乗の右側p値も一致します。同じ表を別の表現で調べていることが分かります。

ただし、補正の有無や標準誤差の作り方を変えれば、同じ数値ではなくなることがあります。計算結果が違ったときは、手法名だけでなく設定も照合します。

補正や正確検定を、同じ値と扱わない

2×2表でYatesの連続修正を使うと、この例の統計量は4×(5−0.5)²/25=3.24、p値は約0.07186です。5%の判定も変わります。正確な条件付き確率を使うFisherの検定も別の手法です。

この違いを隠して、都合のよいp値だけを選びません。本文は補正なしと明記しており、ソフトが補正を既定で使う場合には、そのまま比較しないようにします。統計的な証拠を、0.05の前後だけで断絶した真偽の判定として読むことも避けます。

期待度数が小さい場合には、カイ二乗近似が不十分なことがあります。見るのは主に帰無仮説の期待度数であり、観測が0だから直ちに計算不能ではありません。行・列合計が0、構造的に起こり得ないセルがある場合などは、表とモデルを整理し直します。

関連の大きさと、原因を別に考える

棄却したことだけでは、関連がどの程度実用上重要かは分かりません。本文なら完了率60%と40%、差20パーセントポイントという元の値を示します。補助的な指標CramérのVは、√{X²/[n min(r−1,c−1)]}で、この例では0.2です。Vは原因や成功確率ではありません。

案内を研究者が無作為に割り付けたのか、利用者が選んだのかによって、因果の解釈は異なります。観察されたクロス表の関連だけから、案内を変えると必ず完了率が20ポイント改善すると結論しません。

同じ人の前後の回答を二つの独立な群として計算することも避けます。人数、分母、対応、抽出方法を記録するという基本は、検定の段階でも必要です。

確認問題

問1：補正なしの検定

本文の表について、期待度数、Pearson統計量、自由度とp値を求めてください。

解答と理由

期待度数は各25、X²=4、自由度1、上側p値約0.04550です。連続修正なしという設定での結果です。カイ二乗の右側p値をさらに2倍しません。

問2：期待度数の作り方

全体100人、ある行の合計40人、ある列の合計30人です。独立モデルのそのセルの期待度数はいくつですか。

解答と理由

40×30/100=12人です。セル数で全体を均等に割る方法は、一般には使えません。周辺の割合を掛けた値です。

問3：小さい件数の点検

観測度数が0のセルがありました。それだけでPearson検定が計算不能、または正確に使えると判断できますか。

解答と理由

どちらも判断できません。期待度数が正なら寄与は計算できますが、小さい期待度数が多いと近似の精度に問題があります。期待度数0や構造的な不可能セル、対応の有無も確認します。

問4：関連と介入

本文の表で独立性を棄却しました。Aへ変更すれば母集団全員の完了率が必ず20ポイント上がると結論できますか。

解答と理由

できません。観測された関連と因果効果は別で、抽出・割付・交絡などを検討する必要があります。差の推定にも不確かさがあります。

詳しく確かめる

独立モデルの自由度を、推定する確率の数から考える

制約のないr×c表のセル確率は、合計1の条件によりrc−1個の自由な値で指定できます。独立モデルでは、行の確率r−1個と列の確率c−1個があれば、積として全セルの確率が決まります。

差はrc−1−{(r−1)+(c−1)}=(r−1)(c−1)です。通常の正則条件のもとで、この差がPearson検定の漸近的な自由度になります。構造的な0や識別できない母数がある場合まで、同じ数式を機械的に当てはめません。

2×2表では、等比率のプールしたz統計量を二乗するとPearson統計量に整理できます。二値データに対する同じ制約を、割合の差とセル度数のずれという二つの形で表しているためです。近似条件や補正の選択まで自動的に一致するという主張ではありません。

周辺合計から期待度数を作り、補正・自由度・近似の条件をそろえます。次章では、数量の関係を回帰モデルとして推定します。
