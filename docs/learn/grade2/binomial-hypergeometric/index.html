回数を先に固定し、成功数を数える

一回ごとに成功・失敗の二つの結果を考え、n回の独立な試行を行います。各回の成功確率が同じpなら、成功数Kは二項分布に従います。成功とは数えたい結果の名前で、望ましい結果に限りません。不良品が出ることを成功として数えても構いません。

P(K=k)=(nk)pk(1−p)n−k,k=0,1,…,n.P(K=k)=\binom nk p^k(1-p)^{n-k},\qquad k=0,1,\ldots,n.P(K=k)=(kn​)pk(1−p)n−k,k=0,1,…,n.

nは非負整数、0≤p≤1です。成功が出るまで試行を延ばす場合は固定nではなく、次講の待ち回数のモデルです。「0・1の結果だから二項分布」ではなく、固定回数、共通p、独立性を確認します。

一つの並びと、すべての並び

仮想の成功確率p=0.4で5回試行します。成功2回となる特定の並びの確率は0.4²×0.6³です。成功の位置は (52)=10\binom52=10(25​)=10 通りなので、成功2回の確率は0.3456です。

成功・成功・失敗・失敗・失敗という一つの並びだけを計算して、成功数2の全体の確率としてはいけません。異なる並びは同時には起こらないので、組合せの数だけ足せます。

平均はE[K]=np、分散はV(K)=np(1−p)です。この例では平均2、分散1.2です。平均が2でも、毎回必ず2回成功するわけではありません。また、成功割合K/nの分散は成功数Kの分散をn²で割った値です。

戻さずに取るなら、抽出結果が結び付く

10個のうち4個が対象品で、その中から3個を重複なく単純無作為に選びます。選んだ対象品の数Kは超幾何分布です。全体をN、対象品をM、抽出数をnとすると、

P(K=k)=(Mk)(N−Mn−k)(Nn).P(K=k)=\frac{\binom Mk\binom{N-M}{n-k}}{\binom Nn}.P(K=k)=(nN​)(kM​)(n−kN−M​)​.

可能なkは max⁡(0,n−(N−M))≤k≤min⁡(n,M)\max(0,n-(N-M))\le k\le\min(n,M)max(0,n−(N−M))≤k≤min(n,M) の整数です。分母は全標本の組合せ、分子は対象品k個と、それ以外n−k個を選ぶ組合せです。全標本が等確率という選び方を仮定しています。

N=10、M=4、n=3でk=2なら、(42)(61)/(103)=36/120=0.3\binom42\binom61/\binom{10}3=36/120=0.3(24​)(16​)/(310​)=36/120=0.3 です。独立な3回の成功確率0.4を使う二項分布では0.288なので、厳密には一致しません。非復元では最初に対象品を取ると、残りの対象割合が変わるからです。

同じ平均でも、分散が違う

超幾何分布の平均はnM/Nです。N>1のとき、p=M/Nとして分散は

V(K)=np(1−p)N−nN−1V(K)=np(1-p)\frac{N-n}{N-1}V(K)=np(1−p)N−1N−n​

です。この例では平均1.2、分散3×0.4×0.6×7/9=0.56です。二項分布の分散0.72より小さくなります。

対象品を引くと残りに対象品が少なくなる、という負の依存が変動を抑えます。G05の有限母集団補正が成功数にも現れています。各位置の無条件の対象確率が同じ0.4でも、独立であるとは限りません。

近似と、厳密なモデルを分ける

Nが大きくn/Nが小さい場合、非復元による残りの構成変化が小さく、二項分布で近似することがあります。ただし抽出率の目安だけで、あらゆる裾確率に同じ精度が保証されるわけではありません。厳密計算ができる場面では差を確かめます。

独立でも各回のpが違えば、共通pの二項分布ではありません。逆に、同じpでも一つの隠れた要因で結果が結び付いていれば独立ではありません。「回数が多いから」という理由だけで、この三条件を省略しないようにします。

p=0や1では成功数は0やnに固定されます。数式の0の0乗をそのままソフトへ渡すより、境界の確率を定義から別に扱います。標準的な近似や検定も、こうした端のモデルで同じように動くとは限りません。

確認問題

問1：二項分布の確率

独立に成功確率0.4の試行を5回行います。成功2回の確率を求めてください。

解答と理由

10×0.4²×0.6³=0.3456です。成功位置の10通りを含めます。固定した一つの並びの確率だけではありません。

問2：非復元の確率

10個中4個が対象品で、3個を非復元単純無作為に選びます。対象品2個の確率は何ですか。

解答と理由

6×6/120=0.3です。対象品2個と、それ以外1個の選び方を数えます。二項分布の0.288を厳密値として使いません。

問3：平均と分散

問2のKの平均と分散を求めてください。

解答と理由

平均1.2、分散0.56です。分散に有限母集団の係数7/9を掛けます。標準偏差なら最後に平方根を取ります。

問4：同じ確率なら独立か

非復元抽出で、各位置が対象品である無条件の確率は4/10です。このことから独立と判断できますか。

解答と理由

できません。最初が対象品なら次の条件付き確率は3/9です。周辺の確率が同じことと、選択結果が結び付かないことは別です。

詳しく確かめる

指示変数の和から、平均と分散を導く

i回目が成功ならI_i=1、失敗なら0としてK=ΣI_iです。E[I_i]=p、I_i²=I_iなのでV(I_i)=p−p²です。独立なら共分散0で、E[K]=np、V(K)=np(1−p)を得ます。

非復元ではi≠jで E[IiIj]=M(M−1)/(N(N−1))E[I_iI_j]=M(M-1)/(N(N-1))E[Ii​Ij​]=M(M−1)/(N(N−1)) です。p²を引くと共分散は−p(1−p)/(N−1)になります。和の分散へ代入すると、

np(1−p)−n(n−1)p(1−p)N−1=np(1−p)N−nN−1.np(1-p)-\frac{n(n-1)p(1-p)}{N-1} =np(1-p)\frac{N-n}{N-1}.np(1−p)−N−1n(n−1)p(1−p)​=np(1−p)N−1N−n​.

確率の公式は組合せ、平均と分散は指示変数から導けます。独立性を使う場所と、非復元によって変わる場所が明確になります。
