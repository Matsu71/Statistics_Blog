分散・歪度・尖度と定義の違い

平均と標準偏差だけでは、分布の非対称さや裾は分かりません。偏差の三乗・四乗を使う指標を、分母や補正の慣習も含めて読みます。

同じ散らばりでも、形は違います

配送時間が平均から左右同じように散らばる場合と、大部分は短いのにごく一部だけ非常に長い場合では、平均と標準偏差が近くても業務上の意味が違います。まずヒストグラムや箱ひげ図を見て、指標を図へ対応させます。

分散は偏差の二乗を使います。非対称さを見る歪度では三乗、裾や極端な値に強く反応する尖度では四乗が現れます。高いべきほど遠い値の寄与が急に大きくなるため、小標本や外れ値の影響に注意します。尖度を単に「山が尖っている度合い」とだけ覚えると、分布によって誤読します。[1]

正規分布の基準と、観測値の揺れを分ける

正規分布の母集団の歪度は0、尖度は3、超過尖度は0です。しかし正規分布から有限個を取った標本の指標が、毎回ちょうどその値になるわけではありません。歪度0だから必ず正規分布、と逆向きに結論することもできません。

例えば−1、−1、1、1という対称な四つの値は歪度0ですが、二つの値にしか観測がありません。母集団についても、歪度0で非正規の分布は多数あります。また、一般に三次モーメントが0という条件だけでは左右対称性まで保証されません。

尖度は標準化された四乗平均なので、極端に遠い値を強く重く見ます。同じ平均・分散の分布を比較する際の一つの情報ですが、尖度だけで外れ値の原因や必要な対応を決めるものではありません。

実務と問題文で確認すること

全値が同じなら m2=0m_2=0m2​=0 で、ここでの標準化した歪度・尖度は割り算できません。ソフトが計算不能を返しても、歪度0と勝手に置き換えません。件数が少なすぎると補正式自体が定義されない場合もあります。

極端な値を除く前には元の記録・単位・対象を確かめます。正しく記録された異常な遅延が、分析目的から重要な場合もあります。必要ならその値を含む場合と、明示した除外規則による場合を比較し、中央値・四分位範囲・図も添えます。

試験では、式が与えられていればその定義に従います。自分が覚えたソフトの既定値を優先して、別の正しい慣習を誤りとしないことが重要です。

確認問題

問1：二つの分散

0、0、1、3の m2m_2m2​ と不偏分散を求めてください。

解答と理由

平均1、偏差二乗和6より、m2=6/4=1.5m_2=6/4=1.5m2​=6/4=1.5、不偏分散は6/3=2です。同じ名前の「分散」でも分母を確認します。

問2：尖度の基準

m2=1.5,m4=4.5m_2=1.5,m_4=4.5m2​=1.5,m4​=4.5 の尖度と超過尖度を求めてください。

解答と理由

尖度2、超過尖度−1です。四次モーメントを分散の二乗で割り、その後に必要なら3を引きます。標準偏差で一度だけ割る計算ではありません。

問3：歪度0の意味

歪度が0だったので「母集団は正規分布」と判断してよいですか。

解答と理由

いけません。歪度は一つの要約で、分布全体を特定しません。−1、−1、1、1も歪度0です。標本から母集団へ推測する段階も別に必要です。
