当てはまりがよいことと、モデルが適切なこと

前講の8行の架空データについて、ŷ=10+2x+3Dを当てはめました。残差平方和SSE=8、yの全体平均は16.5で、平均からの総平方和SST=66です。ここから、モデルが標本内の変動をどの程度要約したかを計算できます。

ただし、標本内で小さい残差が得られても、将来の値に同じ精度で予測できることや、係数を因果効果と解釈できることは保証されません。数値の指標と、モデル条件の点検を分けます。

以下では、切片を含む通常の最小二乗、同じ観測集合、SST>0を前提に決定係数を考えます。切片なしや重み付きのモデル、標本外の予測評価では定義や性質が異なる場合があります。

決定係数は、標本内の二乗誤差の減少を表す

決定係数はR²=1−SSE/SSTです。本文では1−8/66=29/33、約0.87879です。平均だけで予測した場合に比べ、残差平方和がどの程度減ったかを表します。

「87.9%の人を正しく予測した」「原因を87.9%説明した」という意味ではありません。yの二乗変動という基準に対する値です。大きい一部の値や観測範囲にも影響されるため、異なる目的変数や集団のR²を無条件に順位付けしません。

同じ観測で、もとの変数をすべて含む入れ子の最小二乗モデルへ変数を追加すると、SSEは増えません。追加係数を0にすれば以前と同じ予測を再現でき、最適化では少なくとも同じ二乗誤差を選べるからです。従ってR²も下がりません。この性質だけで変数追加を評価すると、複雑なモデルが有利になります。

調整済み決定係数は、自由度を考慮する

切片を含む推定係数の数をpとします。n>pで、調整済み決定係数は

Rˉ2=1−SSE/(n−p)SST/(n−1)\bar R^2=1-\frac{SSE/(n-p)}{SST/(n-1)}Rˉ2=1−SST/(n−1)SSE/(n−p)​

です。本文ではn=8、p=3なので、1−(8/5)/(66/7)=137/165、約0.83030です。pを「説明変数だけの個数2」と取り違えると、残差自由度が変わってしまいます。

変数を追加してSSEが少し減っても、残差自由度が減るため、調整済みR²は下がることがあります。負になる場合もあります。必ず0〜1になる割合として扱いません。調整済みR²が最大のモデルも、将来の予測や因果の目的に常に最善とは限りません。

残差の形から、何を疑うか

予測値に対して残差を描き、0の周囲にどのような形があるかを見ます。曲がったパターンなら直線の平均関係が不十分かもしれません。予測値が大きいほど扇状に広がるなら、共通分散の条件を再検討します。

時間順に残差が長く同じ符号で続く場合は、系列相関や時間的な要因の不足を考えます。Q–Qプロットは分布の裾や対称性の点検を助けます。ただし、どれか一つの図がきれいだから、すべてのモデル条件が証明されたわけではありません。

観察した形考える候補次の確認
残差が曲線状平均関係の非線形適切な変換・追加項・観測範囲
残差の広がりが場所で違う異分散測定単位、誤差分散、推測法
時間順に規則性がある依存や時間要因記録順、抽出・測定の仕組み
一点だけ離れている誤記・外れ値・影響点原記録とその点を含む感度分析

外れた点を、p値やR²を改善するために自動削除しません。入力誤りと確認できれば訂正し、実際の観測なら影響と研究上の意味を記録します。

説明変数どうしが似ていると、係数を分けにくい

多重共線性は、説明変数の間に強い線形関係がある状態です。例えば総額と、そのほぼ同じ内訳合計を同時に入れると、各係数の役割を分離しにくくなることがあります。

完全な線形関係なら、前講のダミーの重複のように係数が一意に決まりません。ほぼ線形関係なら計算できても、標準誤差が大きく、少しのデータ変更で係数が大きく動く場合があります。回帰全体の当てはまりがよいことと、個々の係数が精密であることは別です。

説明変数jを他の説明変数へ回帰した決定係数をRj²とすると、通常のVIFは1/(1−Rj²)です。Rj²=0.9ならVIF=10です。これは「その変数の因果効果が10倍」ではなく、通常の線形モデルで係数の分散の増大を表す指標です。一般に使われる閾値も、目的や設計を無視した絶対判定にはしません。

予測評価と解釈の目的を区別する

説明変数が似ているため個々の係数が不安定でも、観測に近い組合せでの予測は安定する場合があります。逆に、標本内の高いR²でも、新しい領域への予測は不安定かもしれません。何を使いたいかで点検する量が違います。

モデルを比較するときは、同じ対象と目的変数か、欠測処理で観測が変わっていないか、評価データに学習時の情報が混ざっていないかを確認します。未来の予測では時間順序も守ります。単一のスコアを最大化することを、分析の全目的と取り違えないようにします。

確認問題

問1：調整済み決定係数

n=8、切片を含む係数3個、SSE=8、SST=66です。R²と調整済みR²を求めてください。

解答と理由

R²=29/33≈0.87879、調整済みR²=137/165≈0.83030です。残差自由度は8−3=5です。二つの指標を同じ値として表示しません。

問2：VIF

ある説明変数を他の説明変数に回帰したRj²が0.9でした。VIFを求め、その意味を説明してください。

解答と理由

VIF=1/(1−0.9)=10です。他の説明変数と強く線形に関連しており、個別係数の精度に影響することを示します。効果の大きさや因果性を表す値ではありません。

問3：残差が扇状に広がる

予測値が大きいほど残差の幅が広くなりました。何を再検討しますか。図だけで原因が確定しますか。

解答と理由

共通分散の仮定、尺度、平均モデル、測定の仕組みなどを点検します。異分散を疑う手掛かりですが、図だけで唯一の原因を確定したわけではありません。

問4：変数追加でR²が上がる

同じ観測への入れ子の最小二乗モデルでR²が上がりました。将来予測も必ずよくなりましたか。

解答と理由

必ずではありません。標本内のR²は変数追加で下がらない性質があります。新しいデータでの性能、自由度、モデル条件、研究目的を別に確認します。

詳しく確かめる

VIFが係数の分散へ現れる理由

説明変数xjを、切片と他の説明変数へ回帰した残差をrjとします。通常の線形モデルでβjの分散はσ²/Σrj²です。xjの全平方和をSjjとすると、残差平方和はSjj(1−Rj²)なので、

V(β^j)=σ2Sjj11−Rj2.V(\hat\beta_j)=\frac{\sigma^2}{S_{jj}}\frac1{1-R_j^2}.V(β^​j​)=Sjj​σ2​1−Rj2​1​.

同じSjjとσ²のもとで、他の変数と直交する場合に比べた分散の倍率がVIFです。標準誤差の倍率は平方根であり、VIFをそのまま標準誤差に掛けるという意味ではありません。

Rj²=1なら残差が0で、その変数の独立な変動がありません。特異な設計行列で一意な係数が求められないことと対応します。非線形な関連や、モデルの誤り全般をVIFだけで検出できるわけではありません。
