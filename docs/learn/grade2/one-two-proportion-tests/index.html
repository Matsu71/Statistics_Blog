帰無仮説が指定する比率を基準にする

成功数Kが二項分布B(n,p)に従うとし、H₀:p=p₀を検定します。0<p₀<1で、帰無仮説のもとで成功・失敗の期待件数が十分ある場合、

Z=p^−p0p0(1−p0)/nZ=\frac{\hat p-p_0}{\sqrt{p_0(1-p_0)/n}}Z=p0​(1−p0​)/n​p^​−p0​​

を標準正規で近似します。分母のp₀は帰無仮説の値です。Wald区間でp̂を使った標準誤差と、ここでの帰無分布の標準誤差は役割が違います。

本講座の基本計算は連続修正なしの正規近似です。修正を使う問題では、その指定と極端な側の境界を確認します。二項分布で直接計算する方法とも、有限標本では値が違う場合があります。

一つの母比率の例

仮想の100件で成功60件でした。H₀:p=0.5、H₁:p≠0.5なら、p̂=0.6、帰無標準誤差√0.0025=0.05、z=2です。両側p値は約0.04550で、近似法では5%で棄却します。

このp値は、成功確率が0.5というモデルのもとでの極端さです。真のpが0.5である確率4.55%という意味ではありません。二項の正確な両側検定や連続修正した近似とは別の方法なので、採用した方法を報告します。

また、100件が独立な試行であるかを確認します。同じ人の回答を何度も数えた、同一ロット内で強く依存する、といった場合には二項の標準誤差を無条件に使えません。

二群が等しいという帰無仮説

独立二群でH₀:p₁=p₂を検定すると、帰無仮説のもとでは共通のpがあります。その推定値を

p^pool=k1+k2n1+n2\hat p_{\mathrm{pool}}=\frac{k_1+k_2}{n_1+n_2}p^​pool​=n1​+n2​k1​+k2​​

とします。二つの標本比率の単純平均ではなく、各分母で重み付けした割合です。正規近似の統計量は

Z=p^1−p^2p^pool(1−p^pool)(1/n1+1/n2).Z=\frac{\hat p_1-\hat p_2} {\sqrt{\hat p_{\mathrm{pool}}(1-\hat p_{\mathrm{pool}})(1/n_1+1/n_2)}}.Z=p^​pool​(1−p^​pool​)(1/n1​+1/n2​)​p^​1​−p^​2​​.

p₁−p₂を自由に推定するWald型区間では、各群の比率を別々に分散へ代入しました。ここでは帰無仮説の制約を使います。両方の式の分母を理由なく入れ替えません。

比率差の検定の数値例

群1は100件中40、群2は200件中60とします。観測比率は0.4と0.3、差0.1です。プール比率は100/300=1/3、標準誤差は√(1/300)≈0.05774なので、z=√3≈1.73205です。

両側p値は約0.08326で、5%では棄却しません。差0.1がなかったことになったのではなく、推測に不確かさが残るという判断です。推定差と、G22のような条件に合う区間を一緒に報告します。

各群の成功・失敗の期待件数が小さい場合、正規近似の精度を検討します。特に小さなクロス表では、正確な検定などの別の手法を考えます。グループの総人数だけを見て判断しないようにします。

少数試行では、二項確率へ戻る

10試行で成功0、H₀:p=0.1に対し小さい方向を検定するとします。観測値0以下は0だけなので、正確な片側p値は

Pp=0.1(K=0)=0.910≈0.34868P_{p=0.1}(K=0)=0.9^{10}\approx0.34868Pp=0.1​(K=0)=0.910≈0.34868

です。成功0という記録だけで、p=0.1を不自然だと強く結論する値ではありません。ここでは帰無仮説の成功期待件数は1で、正規近似に適した状況ではありません。

離散分布の両側p値には、確率の小さい結果を集める定義などがあります。単純にいつも片側の2倍とせず、手法やソフトの定義を明示します。p₀=0や1の退化した帰無モデルも、分母0になる正規近似の式では扱いません。

同じ人の前後は、独立二群ではない

同じ対象の前後で成功・失敗を測った場合、二つの比率の差には組内の依存が関係します。前後を独立な二群としてプールする計算は、設計と合いません。不一致の組などを使う対応したカテゴリデータの方法を検討します。

数値を比べる前に、成功の定義、分母、欠測、観測単位、対応の有無を確認します。比率の検定でも、最初のデータ設計の講座で学んだことが必要です。

確認問題

問1：一つの母比率

100件中60件成功、H₀:p=0.5です。連続修正なしの両側正規近似検定を行ってください。

解答と理由

帰無標準誤差0.05、z=2、p≈0.04550で5%では棄却します。分母に帰無値0.5を使っています。

問2：独立二群の比率差

群1は100件中40、群2は200件中60です。等比率の帰無仮説についてz値と両側p値を求めてください。

解答と理由

プール比率1/3、標準誤差√(1/300)、z=√3≈1.73205、p≈0.08326です。5%では棄却しません。

問3：単純平均にしない

問2の帰無仮説の共通比率を、(0.4+0.3)/2=0.35としてよいですか。

解答と理由

よくありません。各群の人数が違うので、全成功数100を全試行数300で割る1/3を使います。比率の分母を重みにする考え方です。

問4：少数試行の正確なp値

10試行で成功0、H₀:p=0.1、小さい方向の対立仮説です。二項分布によるp値を求めてください。

解答と理由

0.9¹⁰≈0.34868です。成功0だから真の確率0と決めず、帰無モデルでもどの程度起こるかを計算します。

詳しく確かめる

共通比率の推定値が、全成功数を全人数で割る理由

独立な二群が帰無仮説のもとで共通pを持つとき、尤度のpに関係する部分は、p^{k₁+k₂}(1−p)^{n₁+n₂−k₁−k₂}です。対数を微分して0と置くと、内部の解はp=(k₁+k₂)/(n₁+n₂)です。全成功または全失敗の境界は別に扱います。

そのpを帰無モデルの分散p(1−p)(1/n₁+1/n₂)へ代入します。共通pという制約を使った推定と、自由なp₁,p₂を使う差の区間推定が異なる理由です。

尤度を使ったこの導出は、正規近似がすべての標本数で正確になる証明ではありません。推定規則と、帰無分布の近似精度を分けます。
