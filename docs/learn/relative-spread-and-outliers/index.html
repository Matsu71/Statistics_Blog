変動係数と外れ値の点検

同じ標準偏差でも、平均の大きさに比べた散らばりは違います。変動係数を使える条件と、外れた値を残すか判断する手順を学びます。

絶対的な散らばりと、相対的な散らばり

架空の作業Aは8分と12分、作業Bは95分と105分かかったとします。分母nで計算した平均と標準偏差は、Aが10分・2分、Bが100分・5分です。分単位の散らばりはBの方が大きいですが、平均に対しての割合ではどうでしょうか。

平均が正の比例尺度データについて、標準偏差を平均で割った値を変動係数と呼びます。CVと略し、比または百分率で示します。

CV=sxˉ(xˉ>0).\mathrm{CV}=\frac{s}{\bar x}\quad(\bar x>0).CV=xˉs​(xˉ>0).

Aは2/10=0.2、つまり20%、Bは5/100=0.05、つまり5%です。相対的な散らばりはAの方が大きいと読めます。標準偏差と変動係数は違う問いに答えており、一方だけが正しい評価ということではありません。

単位を変えても比は同じになる

Aの値を秒で表すと480秒・720秒、平均600秒・標準偏差120秒です。変動係数は120/600=20%で変わりません。分子と分母に同じ倍率が掛かり、単位が打ち消されるためです。

ただし「単位がない」だけで異なる対象を何でも比較できるわけではありません。短い作業と長い作業をどんな目的で比べるのか、平均の定義や記録方法が同じかを確認します。安全上、絶対的な遅延が重要なら標準偏差や大きな遅延の割合も必要です。

標準偏差を分母nとn−1のどちらで求めたかも示します。二群の比較で定義を混ぜると、小標本では無視しにくい差になります。このページの二点の例は記述の説明で、母集団の安定性を十分に推定したという意味ではありません。

平均0付近や任意の原点では使いにくい

平均が0なら割り算ができず、0に近いと小さな変化で変動係数が非常に大きく変わります。正負の値が打ち消し合うデータでも、平均に対する比が目的に合うとは限りません。

摂氏温度のような間隔尺度では0の基準が任意なので、変動係数は通常、相対的な散らばりの比較に適しません。例えば平均20℃・標準偏差2℃なら10%ですが、同じ温度を別の原点へ移すと、標準偏差は同じでも平均だけが変わります。原点に依存する比へ、普遍的な物理的意味を与えないようにします。

「正の値なら必ず使える」でもありません。得点に正の数しかなくても、その0や比が能力の0・比を意味するかは別問題です。第3講の尺度の意味をここでも使います。

外れた値は、検出してから理由を調べる

架空の7件、1、2、3、4、5、6、20分を見ます。本講座の四分位数の方法では Q1=2,Q2=4,Q3=6Q_1=2,Q_2=4,Q_3=6Q1​=2,Q2​=4,Q3​=6、IQR=4です。1.5IQRの境界は−4と12なので、20分は外れ値候補になります。

ここで自動的に20を消しません。元の記録や単位を確認し、200秒を20分と入力した誤りか、本当に20分待ったのか、別の受付の記録が混ざったのかを調べます。入力誤りと確認できれば訂正し、その理由を残します。実際の長い待ち時間なら、改善の目的から見て重要な情報かもしれません。

候補を検出するルールは、何を重点的に点検するかを決める補助です。ルールの外側だから異常、内側だから安全と断定できる分類器ではありません。分布の形や記録の仕組みによって、適切な見方は変わります。

除いた場合と含めた場合を比較する

7件の合計は41分、平均は41/7≈5.86分、中央値は4分です。20分を除いた6件の平均は3.5分へ下がります。平均が下がったから除外が正当、という順序にはしません。

感度分析として、含めた結果と、明記した条件で除外した結果を両方示す方法があります。結論が大きく変われば、その記録の影響が大きいことが分かります。元データを保存し、除外・訂正の条件は結果を都合よくするために後付けしません。

中央値や四分位範囲のような影響されにくい要約を併記する方法もあります。しかし、それで長い待ち時間をなかったことにしてよいわけではありません。問いに合わせて中心、散らばり、端の重要な事例を別々に伝えます。

確認問題

問1：二つの散らばり

Aは平均10・標準偏差2、Bは平均100・標準偏差5です。変動係数と、相対的な散らばりの大きい方を答えてください。

解答と理由

Aが20%、Bが5%なので相対的にはAです。一方、標準偏差という絶対的な尺度ではBが大きいことも正しいです。

問2：変動係数が変わる操作

全値を60倍にする場合と、全値に100を足す場合で、変動係数はどちらでも同じですか。

解答と理由

同じとは限りません。正の倍率60は平均と標準偏差へ同じように掛かるのでCVは同じです。100を足すと平均だけが変わり、CVは変わります。原点の変更に対する弱さが分かります。

問3：点検と削除

1、2、3、4、5、6、20の20は1.5IQRの境界を越えました。このことだけで削除してよいですか。

解答と理由

よくありません。境界は候補を点検するためのものです。記録の誤り、単位、対象の違い、実際の珍しい値を確認し、修正や除外をするなら理由と元データを残します。

詳しく確かめる

変動係数が正の倍率で変わらず、平行移動で変わることを示す

平均 xˉ>0\bar x>0xˉ>0、標準偏差 sss のデータを yi=axiy_i=ax_iyi​=axi​、a>0a>0a>0 と変えます。第16講より平均は axˉa\bar xaxˉ、標準偏差は asasas なので、CVは as/(axˉ)=s/xˉas/(a\bar x)=s/\bar xas/(axˉ)=s/xˉ です。

一方 yi=xi+by_i=x_i+byi​=xi​+b なら、xˉ+b>0\bar x+b>0xˉ+b>0 のもとでCVは s/(xˉ+b)s/(\bar x+b)s/(xˉ+b) となり、一般には元の値と違います。この二つを区別するために比例尺度を重視します。

外れ値の影響について、追加する一つの値 MMM を大きくすれば平均と分散は際限なく大きくできます。中央付近の順位が変わらない範囲では中央値が変わらないことがあり、要約方法の性質の違いを確認できます。ただし、順位に関する指標もどんな変更に対しても不変ではありません。

まとめと次の一歩

絶対量と平均に対する比を分け、使える尺度かを確認します。外れ値候補は理由を点検します。次の第4章では、二つの数量の関係を散布図と相関で読みます。
