図の形より先に、比較する問いを決める

予約方法を一人一つだけ答えてもらった、架空の20人のデータを考えます。アプリ10人、窓口6人、ウェブ4人でした。最も多い方法を知りたいなら人数の差を比べ、全体の構成を知りたいなら割合を見ます。同じ表から作る図でも、得意な問いが違います。[1]

予約方法人数全体20人に占める割合
アプリ1050%
窓口630%
ウェブ420%

カテゴリ名を横軸または縦軸に並べ、棒の長さを人数に対応させれば棒グラフです。横棒なら長いカテゴリ名も読みやすくなります。棒同士の間隔はカテゴリが別々であることを示すもので、ヒストグラムのような数量区間の幅ではありません。

棒の長さは、共通の0から比べる

棒グラフでは基準を0にすると、長さの比が値の比に対応します。10人の棒は、5人の棒の2倍です。縦軸を途中から始めると、長さの比と人数の比が一致しなくなります。

例えば90人と100人の棒を80から描くと、見える長さは10と20で2倍ですが、人数は100/90で約1.11倍です。差を拡大して見る必要があるなら、その目的と軸の省略をはっきり示し、点グラフなど別の表示も検討します。「すべてのグラフは必ず0から」という規則ではなく、長さや面積を量として比較する図の性質を考えます。

分類に順序がないなら、棒を件数順に並べると順位を読みやすくなります。満足度のように元の順序に意味がある場合は、順序を維持した方が適切なこともあります。

円と帯は、同じ全体の構成を見る

円グラフは全体を360度とし、割合に対応する角度で扇形に分けます。この例ではアプリが半円の180度、窓口が108度、ウェブが72度です。

中心角=360∘×割合.\text{中心角}=360^\circ\times\text{割合}.中心角=360∘×割合.

帯グラフでは全体を一本の長方形として区切ります。全長を100%とした下の図は、同じ50%・30%・20%を表します。角度よりも横の長さを読んだ方が比較しやすい場合があります。

カテゴリは互いに重ならず、全体を覆う必要があります。「使ったことのある方法」を複数回答で尋ねた場合、割合の合計は100%を超え得ます。それを一つの全体として円に押し込まず、カテゴリごとの回答割合を棒などで示します。3Dの円は遠近で扇形の見かけの面積を変えるため、読み取りを難しくします。

積み上げ棒は、総量と内訳を両方持つ

別の日にアプリ8人、窓口8人、ウェブ24人の計40人だったとします。人数を積み上げれば、20人の日と40人の日の総量の差と内訳を同時に表示できます。100%にそろえた帯なら、後者は20%・20%・60%となり、構成を比較できます。

100%表示にすると総人数の差は棒の長さから消えます。人数も重要なら、20人・40人と別に書きます。積み上げ棒の中央部分は開始位置がそろわないため、小さな差の比較には向かない場合があります。同じカテゴリの差を正確に見たいときは、横に並べる棒や表が役立ちます。

面グラフは、時点ごとの数量を線で結び、その下を塗った図です。積み上げ面グラフでは合計と内訳の時間変化を表せます。負の値を含む場合や区分が重なる場合に、面積を単純な全体構成として読まないようにします。時間軸の間隔も一定か確認します。

絵グラフとパレート図の注意点

絵グラフで「人の絵一つが5人」なら、絵が四つで20人です。凡例が分かれば直感的ですが、絵そのものを縦横とも2倍に拡大すると面積は4倍になります。人数2倍を面積4倍で表すと過大な差に見えます。個数を増やすか、何を数量に対応させるかを明示します。

パレート図ではカテゴリを度数の大きい順に並べ、累積割合の線を加えます。予約方法の例なら、アプリまで50%、窓口まで80%、全体で100%です。頻度の高い分類から検討する手助けになりますが、最も多い項目が最も重大とは限りません。安全性や損失の大きさは別に評価する必要があります。

確認問題

問1：円の角度

20人中6人が窓口を選びました。全員が一つの方法を選んだ円グラフで、窓口の中心角は何度ですか。

解答と理由

割合は6/20=0.3なので、360×0.3=108360\times0.3=108360×0.3=108 度です。30という百分率の数値をそのまま360倍しないようにします。

問2：総量を隠していないか

20人の日と40人の日を同じ長さの100%帯で示しました。帯の長さが同じなので、利用者数も同じと言えますか。

解答と理由

言えません。全長をそれぞれの全体の100%へそろえた図だからです。構成比較には便利ですが、人数20と40を別に確認します。

問3：複数回答の割合

複数回答でアプリ60%、窓口40%、ウェブ30%でした。この三つを合計100%の円へ、そのまま扇形として入れてよいですか。

解答と理由

よくありません。同じ人が複数に含まれ、割合の合計が130%になります。回答者を分母にした各方法の割合として棒で示すなどし、複数回答であることを明記します。合計を130として再百分率化するなら、分母が「回答総数」へ変わる点を説明しなければなりません。

詳しく確かめる

0を省略すると、見た目の比が変わる理由

値を x1,x2x_1,x_2x1​,x2​、棒を描き始める基準を ccc とすると、見える長さの比は (x2−c)/(x1−c)(x_2-c)/(x_1-c)(x2​−c)/(x1​−c) です。通常知りたい x2/x1x_2/x_1x2​/x1​ とは一般には違います。x1=90,x2=100,c=80x_1=90,x_2=100,c=80x1​=90,x2​=100,c=80 なら見た目は2倍ですが、実際は約1.11倍です。

この式は「差を拡大して描くことを禁止する」ものではなく、棒の長さを数量として読む場合に起こるずれの説明です。線グラフで小さな変動を見るなど、別の目的では軸を限定する意味もあります。目的と表示の対応を明示します。
