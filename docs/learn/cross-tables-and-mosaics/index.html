二つの特徴を、同時に分類する

予約方法がアプリか窓口か、案内に満足したかしなかったかを、20人に尋ねた架空の例です。一人が予約方法を一つ、満足度を一つ答え、欠測はないものとします。

予約方法満足不満足合計
アプリ8210
窓口3710
合計11920

行と列を組み合わせて件数を数えたものをクロス集計表と呼びます。「アプリかつ満足」が8人です。行の合計10人は満足度をまとめたアプリ利用者数、列の合計11人は予約方法をまとめた満足者数です。これらの端の合計を周辺度数と呼びます。

同じ対象を同じ分類ルールで集計したことが前提です。複数回答がある表や、行と列で異なる集団を集計した表では、同じように割合を読むことができない場合があります。表を読む前に、一つのセルがどの対象を表すかを確認します。

分母を変えると、問いが変わる

アプリ利用者の満足率を知りたいなら、アプリの行を全体にします。8/10=80%8/10=80\%8/10=80% です。窓口利用者は 3/10=30%3/10=30\%3/10=30% なので、この20人ではアプリの行の方が満足割合は高かったと読めます。

一方、満足した人のうちアプリを使った割合は、満足の列の11人を分母にした 8/11≈72.7%8/11\approx72.7\%8/11≈72.7% です。全体20人のうちアプリかつ満足の割合なら 8/20=40%8/20=40\%8/20=40% です。

聞きたいこと計算結果
アプリ利用者のうち満足8÷1080%
満足者のうちアプリ利用8÷11約72.7%
全員のうちアプリかつ満足8÷2040%

行を分母にした割合が行比率、列を分母にした割合が列比率です。同じ8という人数を使っても答えが違います。「〜のうち」を先に言葉にすると分母を選びやすくなります。行と列を入れ替えて表を作れば、行比率と列比率という呼び方も入れ替わります。位置より、何を条件にしているかが重要です。

件数が違う群を比較する

アプリ利用者が100人、窓口利用者が10人なら、満足した人数だけの比較では群の大きさが混ざります。利用者の中の満足しやすさを比べたいなら、各群の割合にそろえます。逆に、満足者への案内配布枚数を知りたいなら、人数が必要です。

割合を出せばすべての問題が解決するわけではありません。回答していない人がいるか、同じ人を複数回数えたか、方法を自分で選んだかなどによって、結論の範囲が変わります。この例は観察された関連で、アプリを使わせれば必ず満足度が上がるという実験結果ではありません。

モザイク図は、件数を長方形の面積にする

モザイク図では全体を一つの長方形とし、まず横幅を予約方法の割合に分けます。アプリと窓口は各10/20なので幅は半分ずつです。各区画の高さを、その方法の中の満足・不満足の割合に分けます。

アプリかつ満足の区画は、幅0.5×高さ0.8=面積0.4で、全体の40%に対応します。窓口かつ満足なら0.5×0.3=0.15で、3/20と一致します。図の高さだけを見ると行比率、面積を見ると全体比率です。

同じ表から何が言えて、何が言えないか

ここでは満足率に50パーセントポイントの差がありました。しかし、20人の記録だけで登録者全体にも同じ差があると確定したり、原因を断定したりはできません。群の選ばれ方、標本の大きさ、ほかの条件を検討します。

また、周辺合計だけを知っても内部の4セルは決まりません。アプリと窓口が各10人、満足が11人という合計は同じでも、満足者がアプリ側へどれだけ入るかは変わり得ます。二つの変数の関連を見るために、クロスして数える意味があります。

確認問題

問1：満足者を全体とする

本文の表で、満足した人のうち窓口を使った割合を求めてください。

解答と理由

分母は満足者11人なので 3/11≈27.3%3/11\approx27.3\%3/11≈27.3% です。3/10=30%は窓口利用者の満足率で、問いが逆です。

問2：モザイクの面積

アプリかつ不満足の区画の面積は、全体の何%ですか。

解答と理由

幅10/20×高さ2/10=2/20=10%です。不満足20%という高さはアプリ群内の割合で、全体に対する面積とは違います。

問3：関連を原因と言い換えない

「アプリの行の満足率が80%なので、窓口利用者全員をアプリへ変えれば80%が満足する」と言えますか。

解答と理由

言えません。予約方法と別の特徴が関連している可能性があり、この表は条件を割り当てた実験を示していません。観察した行比率の違いと、介入した場合の効果を区別します。

行合計が約分されるので、面積はセルの全体比率です。行合計が0なら、その行内の割合は定義できず、幅0の区画として別途扱います。この積の考え方は、後の条件付き確率の乗法定理につながります。ここでは確率モデルを仮定せず、観測された件数の比として確認しています。
