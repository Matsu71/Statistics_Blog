最後は、方法を選ぶところから考える

ここまで、記録の単位、グラフ、代表値と散らばり、確率、分布、推定と検定を学びました。この講座では、直前の例の数字だけを入れ替えるのではなく、問題を読み、どの考え方を使うかを選びます。

解答を閉じたまま、式だけでなく理由を一文で書いてください。数値が合っても、分母や独立性の理由が違っていたら、該当箇所へ戻ります。必要なら電卓を使って構いません。数式を使う前に、対象・単位・条件を明示することが大切です。

確認のしかた

各問を「自力で理由まで説明できた」「計算は合ったが理由が曖昧」「ヒントや解答を見て分かった」「まだ分からない」の四つで自己確認します。これは学習用の目安で、公式試験の採点基準や合格予測ではありません。

誤答をすべて「数学が苦手」でまとめないようにします。分母の取り違え、図の尺度、公式の条件、途中の計算、結果の解釈では、戻る場所が違います。下の復習表を使い、同じ問題の答えだけを暗記せず、理由を説明し直します。

確認問題

問1：観測単位と欠測

ある記録は同じ5人を各2日調べた10行で、待ち時間に0分が一つ、未記録が一つあります。「10人の独立な記録で、値があるのは8件」としてよいですか。

解答と復習先

よくありません。人数は5人、観測記録は10件、待ち時間があるのは0分も含め9件です。同じ人の二日は依存する可能性があり、10行をそのまま独立とみなせません。F02 データの単位とF04 抽出へ戻ります。

問2：度数と密度

0以上2未満に6件、2以上6未満に8件ありました。面積を度数に比例させるヒストグラムの高さを、それぞれ求めてください。

解答と復習先

高さは6/2=3件/単位と8/4=2件/単位です。後の階級は件数が多い一方、幅も広いので密度は低くなります。F08 ヒストグラムへ戻ります。

問3：群の大きさを反映する

A組8人の平均が50、B組12人の平均が70です。全20人の平均を求めてください。

解答と復習先

(8×50+12×70)/20=62です。平均の単純平均60ではありません。合計値へ戻してから全人数で割ります。F13 加重平均へ戻ります。

問4：変換と偏差値

平均20、標準偏差4の基準集団で値が14でした。z値と偏差値を求めてください。また全値を3倍すると、平均・分散はどうなりますか。

解答と復習先

z=(14−20)/4=−1.5、偏差値35です。全値3倍なら平均60、分散は元の16の9倍で144です。標準偏差は12です。F16 変換とF17 標準化へ戻ります。

問5：相関を読む

xが−2、−1、0、1、2、yが4、1、0、1、4でした。相関0を根拠に「関係はない」「因果関係もない」と確定してよいですか。

解答と復習先

よくありません。y=x²の非線形な関係があります。因果の有無も、相関だけから確定できません。F19 相関とF21 因果との違いへ戻ります。

問6：順位と重複

6人から役割のない委員2人を等確率の組として選びます。選び方は何通りで、特定のAさんが含まれる確率は何ですか。

解答と復習先

組合せは6×5/2=15通り。Aを含む組は残りから一人を選ぶ5通りなので確率5/15=1/3です。委員の順番は区別しません。F25 場合の数へ戻ります。

問7：条件の向き

20品中、要確認の警告が5品、そのうち不良は2品でした。全体の不良は4品です。警告を条件にした不良確率と、不良を条件にした警告確率を求めてください。

解答と復習先

前者2/5=40%、後者2/4=50%です。全体20で割った10%は、不良かつ警告という同時の割合です。F27 条件付き確率へ戻ります。

問8：確率分布の平均と分散

Xが0、1、2を確率0.2、0.5、0.3で取ります。期待値、二乗の期待値、分散を求めてください。

解答と復習先

E[X]=1.1、E[X²]=1.7、分散1.7−1.1²=0.49です。標準偏差は0.7です。確率を重みに使います。F29 期待値と分散へ戻ります。

問9：二項モデルの条件

100人の回答のうち賛成が何人かを二項分布で扱いたいとします。同じ家族の回答が強く連動していても、人数100だけを根拠に独立二項モデルを正確に使えますか。

解答と復習先

使えません。試行の独立性が崩れ、分散や推測の精度が異なる可能性があります。件数が大きいだけでは条件の違いは解消しません。F26 独立とF30 二項分布へ戻ります。

問10：平均の区間

独立正規標本で母標準偏差2が既知、n=16、標本平均10でした。1.96を使う母平均の95%区間を求め、「データの95%が入る区間」との違いを説明してください。

解答と復習先

SE=2/4=0.5、区間[9.02,10.98]です。対象は母平均で、個々の値の95%を囲むという意味ではありません。F34 標本分布とF35 母平均の区間へ戻ります。

問11：比率の検定

独立二項モデルで100回中56回成功しました。帰無比率0.5を両側で検定する、連続性補正なしの正規近似のz値とp値を求めてください。Φ(1.2)≈0.88493とします。

解答と復習先

帰無SE=√(0.5×0.5/100)=0.05、z=(0.56−0.5)/0.05=1.2、p値≈2×(1−0.88493)=0.23014です。5%では棄却できませんが、pが正確に0.5と証明されたわけではありません。F37 検定の意味とF38 使い分けへ戻ります。

問12：結果を言いすぎない

自発的に回答した20人の結果でp値が0.02でした。「全国の全員に効果があり、98%の確率で仮説は正しい」とする文章を、何が問題か分かるように書き直してください。

解答例と復習先

「この回答者と指定した統計モデルについて、帰無仮説のもとで観測以上に極端な結果が生じる確率は約0.02だった。ただし、自発回答による選択の偏り、対象への一般化、因果効果、実務上の重要性は別途検討が必要である」とします。p値を仮説の事後確率に変換せず、全員への効果も断定しません。F04 抽出、F21 因果、F39 報告へ戻ります。

2級へ進むとき、何を深めるか

次の段階では、確率変数の性質、複数の分布、標本分布、推定・検定、回帰と分散分析などを、より広い条件と問題で扱います。基礎で知ったt法やn−1の理由も、分布の関係を含めて理解します。[1]

数学は、分数・平方根・式変形、添字と総和、場合の数、関数の読み方を確かにします。微分積分などの発展は、必要な導出へ進むときに補います。基礎の全証明を最初から完璧に再現できないと次へ進めない、という足止めはしません。

現時点で2級以降の順序コースがすべて完成したわけではありません。既存の用語辞典や学習コースの入口から、次の内容を確認できます。教材の制作状況と、資格そのものの公式範囲を区別してください。

詳しく確かめる

総和記号を使った式変形を、2級への準備として確認する

n個の値の平均が xˉ=(1/n)∑ixi\bar x=(1/n)\sum_i x_ixˉ=(1/n)∑i​xi​ であることから、Σ(x_i−平均)=Σx_i−n平均=0です。この一つの等式が、分散の展開、最小二乗法、n−1の証明などに何度も現れました。

∑i(xi−a)2=∑i(xi−xˉ)2+n(xˉ−a)2.\sum_i(x_i-a)^2=\sum_i(x_i-\bar x)^2+n(\bar x-a)^2.i∑​(xi​−a)2=i∑​(xi​−xˉ)2+n(xˉ−a)2.

右辺の最後の項は、任意のaを中心に取ることで追加される二乗誤差です。式の形だけを暗記するのでなく、偏差の和が0なので交差項が消える、と説明できれば複数の話題がつながります。

確率モデルでは和を期待値へ置き換える場面が増えます。その際は、有限データの恒等式、期待値の性質、独立性を使う部分を分けて読むことが、厳密な理解の土台になります。

まとめと次の一歩

40講座で、データを集めて読み、確率モデルで変動を考え、推定と検定を条件付きで使う一連の基礎を学びました。次は弱点の講座を復習し、2級の確率変数・標本分布・推定検定を深めます。基本説明を読み直すときも、以前は閉じていた導出を必要に応じて開けます。
