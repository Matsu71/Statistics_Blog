# 検証済み成果物の回収とmain反映

2026-09-11。ユーザーから、まずmainまで適切に反映する指示を受けたため、未確認の処理を増やすのではなく、実際に全検証を通った成果物を回収する。

実行34589747612では、構造、145件の数値検証、基礎と学習機能、2級の2030項目のブラウザ検証、原稿ハッシュによる確定まで成功し、最後のブランチ保存で停止している。成果物10195520868を取得し、原稿、生成HTML、検証記録が存在することを確認した。ローカル照合で、レビュー用アーカイブに含まれる全生成ファイルのハッシュが検証記録に一致した。省略された59件はフォント資産で、リポジトリ内の既存資産との一致を回収時に確認する。

回収処理は成果物のZIP全体のSHA-256を固定し、成功した数値検証・ブラウザ検証・候補原稿・確定原稿の一致を検査する。公開済み基礎の原稿を変更せず、後から追加された作業やworkflowファイルを上書きしない。まず検証用ブランチへ保存し、その実コミットを確認してから、非強制でmainへ反映する。配信後は全80講座・302問と全ファイルの一致を確認し、publication.jsonへ結果を残す。

次：main反映と実配信確認の成功後、準1級の公式範囲と前提を照合し、順序教材の制作へ進む。現時点の本書は完了宣言ではなく、回収方式と次の手順の記録。
