## カリキュラム

`src/data/grade2-course.json` に10章・40講座の固定ID、slug、中心的な到達目標を保存した。基礎で学んだ操作の繰り返しだけにせず、分母n−1、依存関係、正規性・近似、自由度、等分散とWelch、対応のある差、回帰出力など2級で判断が必要になる条件を補う。

4級を独立コースにしない。基礎→2級→準1級→1級という学習順序を維持する。必要な数学は該当講座で補い、微積分や線形代数の全コースを先に必修としない。厳密な導出は基本表示から分け、使用条件は隠さない。

## 品質基準

基本部分は一つの問いを完了できる量にし、目安は日本語で1,500〜2,500字、解答・導出を含め2,500〜4,500字程度。数式・表が多い場合は分量より理解の完結を優先する。3問以上の独自問題に概念・計算・解釈を混ぜ、終章は横断問題を用意する。字数や問題数のために同型問題を水増ししない。

本文・数値例・図・問題は独自制作。公式や他サイトの過去問・記憶再現は使用しない。比較対象はとけたろう、統計WEB、OpenIntro、NIST、Statlect等の実際に確認した公開ページ。数学の根拠と教材構成の比較を分け、出典ごとに確認箇所を残す。

内容を数講座単位でコミットして進捗を更新する。公開済み基礎の原稿や学習記録を上書きしない。新コースは独立した原稿コレクションとURLへ追加し、共有化は既存テストを維持して行う。最新mainに別の変更があれば照合し、force pushで上書きしない。
