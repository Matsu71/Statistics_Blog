# 情報設計・必要な画面・学習導線

作成日: 2026-09-11 / 状態: 次期サイトの設計案（未実装）

## 1. サイトの中心構造

**共通の教材を、教科書・辞典・演習の三つの使い方で提供する。**

- 教科書: 目標の級を選ぶと、必要な内容が前提知識の順に並ぶ。
- 辞典: 用語・数式・手法から直接調べられる。
- 演習: 問題の解説から、対応する教材の該当箇所へ戻れる。

「2級の正規分布」「準1級の正規分布」を別原稿として複製しない。正規分布という正本ページに基本・導出・証明・発展を持ち、コースが読む範囲を指定する。本文の深さと試験の級は別軸にする。

### 想定する入口

|読者|最初にすること|適した導線|
|数学に不安のある初学者|目標を選び、任意の短い確認問題に答える|2級を選んでも、必要な割合・平方根・グラフだけを補習できる|
|4・3級を目指す学習者|基礎コースを順に読む|生活のデータ→グラフ→数値の要約→確率・推測の入口|
|2級を目指す学習者|既習項目を確認し、単元を進む|公式の範囲に対応した標準コース→単元演習→総合演習|
|準1級・1級の学習者|受験区分・受験予定時期を選ぶ|範囲の版を固定し、導出・証明・応用問題を含むコース|
|実務で調べたい人|「平均の差を比較したい」等で検索する|問い→データ構造・仮定→候補手法→解釈・注意点|

診断は任意。診断や会員登録を終えないと本文を読めない設計にはしない。

## 2. 主ナビゲーション

PCの主ナビゲーションは「学ぶ」「調べる」「動かす」「問題を解く」「学習記録」の5項目を基本とする。検索は独立した入力欄。スマートフォンでは同じ情報構造を保ち、メニュー・検索・続きへの入口を優先する。ナビゲーションを全分野・全級で埋め尽くさない。

ブログの投稿日順をホームの主軸にしない。新着情報は補助情報とする。

## 4. ホームの構成案

```text
[ロゴ] 学ぶ 調べる 動かす 問題を解く 学習記録 [検索]

統計を学ぶ
[はじめて学ぶ] [目標の級から学ぶ] [用語・公式を調べる]

（学習履歴がある場合のみ）
前回の続き: 正規分布 / 右側の面積を読む [再開]

主な分野
[データの読み方] [確率と分布] [推定と検定] [回帰と応用]

[よくある混同から学ぶ] [図を動かして確かめる]

運営・出典・訂正情報
```

ホームに全記事一覧、運用中の制作件数、未完成の機能説明、長いコンセプト文は並べない。未公開のコースを押せるようにして空ページへ誘導しない。対応範囲の限界は対応表で正直に示す。

## 5. 教材の構成案

```text
パンくず: 2級コース > 確率分布 > 正規分布

正規分布
[基本: 3・2級の関連内容] [導出・証明: 任意の発展]
このページでできること: しきい値を標準化し、確率を読む
必要な知識: 平均 / 標準偏差 / 面積としての確率

30秒で分かる説明
図と短い説明

基本を理解する
式 → 記号 → 条件 → 小さな数値例
使えない場合・混同しやすい点

確かめる [確認問題]

▶ なぜこの形なのか（導出の見取り図）
▶ 密度の積分が1になることを証明する（積分を使用）
▶ 変数変換から一般の式を導く（ヤコビアンを使用）
▶ 発展: 中心極限定理との関係

[前の教材] [次に学ぶ: 標本平均の分布]
参考資料 / 訂正を送る
```

学習コースから来た場合はコースの前後関係を示す。検索から直接来た人には、無関係なコースを強制せず「この内容の前提」「次に理解すると役立つこと」を示す。

## 6. 折りたたみとタブの使い分け

主に採用するのは、その場所で本文が開く折りたたみ。ユーザーの要望である「押すと詳しい情報が開く」を、文脈を失わない形で実現する。

- 基本事項、式の使用条件、重要な例外・誤用は閉じない。
- 導出・証明は初期状態では閉じる。見出しに内容と必要数学を明記する。
- 証明だけへ直接リンクでき、リンク先では該当部分を自動的に開く。
- 証明の本文も検索対象にする。単に非表示だから検索から落とさない。
- 印刷用表示と「すべて開く」を提供する。大量の入れ子の折りたたみは避ける。
- コードのPython/R/Excelのような並列の選択肢にはタブを使ってもよい。基本と証明を排他的なタブにして往復を強制しない。
- 表示設定は保存できても、利用者の習熟度を勝手に変えない。証明を開いただけでは理解済みと判定しない。

## 7. 可視化の最初の8本

|実験|操作|答えてほしい問い|接続する教材|
|平均・中央値・外れ値|点を動かす|一つの極端な値でどちらが動きやすいか|代表値・外れ値|
|分散と標準偏差|散らばりを変更|位置と広がりは別の性質か|分散・標準偏差|
|正規分布の面積|平均・標準偏差・境界を変更|右側2.5%と両側5%はどう違うか|正規分布・分位点|
|標本平均と中心極限定理|元の分布と標本サイズを変更|元のデータと平均の分布のどちらが変わるか|標本分布・CLT|
|信頼区間の繰返し|標本抽出を繰り返す|95%という割合は何を繰り返した割合か|信頼区間|
|検定と検出力|差・標本サイズ・有意水準を変更|有意差と差の大きさは同じか|検定・効果量・検出力|
|回帰と残差|点や外れ値を動かす|係数と当てはまりはどう変わるか|単回帰・診断|
|条件付き確率|有病率等を合成データで変更|感度と陽性的中率はどう違うか|ベイズの定理|

実験には乱数seed、操作条件、静止状態の説明、表形式の代替、再実行を設ける。動いたこと自体を証明と呼ばない。中核教材の説明を読むだけでも学習できるようにする。

## 8. アクセシビリティと読みやすさの受入条件

W3CのDisclosure PatternとWCAG 2.2を参照する [01-research.md: U01–02]。適合を名乗るのは検証後とする。

- キーボードで開閉・入力・解答でき、フォーカスを見失わない。
- 数式は画像だけにせず、意味を読み取れるテキスト・MathML等の出力を検証する。
- 図の結論を色だけで伝えない。凡例・境界線・ラベル・文章を併用する。
- 小画面と拡大表示で、本文の読む順番が崩れない。長い式のみ局所的な横スクロールを許す。
- スライダーに数値入力の代替を付け、アニメーション停止・動きを抑える表示を用意する。
- 支援技術での開閉状態、見出し階層、図の説明をテストする。ネイティブ要素で実現できる動作に不要なARIAを重ねない。

## 9. 今回あえて初期必須にしないもの

AIチャット、会員登録、ランキング、SNS、決済、講師向け管理画面、巨大な3D演出は初期価値を確立してから判断する。これらの導入で本文・数学検証・演習制作の優先順位を下げない。
