# 制作順序・品質基準・次の作業

作成日: 2026-09-11 / 状態: 実施計画。定期タスクや制作ジョブを設定・実行したという意味ではない。

## 1. 成功の定義

本サイトの価値は記事数だけでは測らない。初学者が基本を理解して問題に使え、上級者が定義・条件・証明まで確認できることを優先する。競合より良いという評価は、以下の観点を実際に検証してから行う。

- 目標の教材まで迷わず到達できる。
- 説明を読んだ後、別の数値・別の文脈の問題にも答えられる。
- 分からない前提に戻り、元の教材へ復帰できる。
- 証明を探す人が必要な証明を見つけられる。
- 公式範囲との対応と未対応が確認できる。
- 数学的な誤り・誤解を招く説明を訂正し、影響先まで追える。

アクセス数や学習時間の長さだけで成功としない。迷って長く滞在している可能性もあるため、問題への理解と合わせて見る。

|P3 準1級|手法の比較、発展数学、導出、多変量・時系列・ベイズ等、2027年版の対応|範囲版を選べ、追加学習が分かり、数値入力・解釈問題にも対応|

段階は記事を大量生成する順序ではなく、利用者に届ける完成した範囲の順序。P3の設計を今行っても、P1の学習体験を後回しにはしない。制作速度の見積もりや公開日は、担当・実装・検証体制が決まる前に断定しない。

## 5. 一つの教材を公開するまで

企画ブリーフ → 根拠資料確認 → 基本説明 → 図・例題 → 導出・証明 → 独自問題 → 数学確認 → 初学者向け編集 → 表示確認 → 公開、の順を基本とする。

同じ人や同じAIで複数観点を確認する場合も、何をどこまで確認したかを分ける。独立した別担当者が見た事実がないのに「監修済み」としない。新しい数式・証明・問題については、できるだけ作成者と異なる確認経路を用いる。

### 公開の必須条件

- 到達目標に対する説明・例・解答付き問題がある。
- 重要な使用条件が基本表示から読める。
- 証明の完全性・省略・外部参照の区別が適切である。
- 数値例の計算、図の軸・単位・面積、問題の正答が一致する。
- 出典を特定でき、利用素材の権利状態が記録されている。
- 参照先・前提・次の教材にリンク切れや循環がない。
- 小画面、キーボード、数式・折りたたみ、印刷で読める。
- 未確認の主張が残る場合は非公開の下書きにするか、該当部分を外す。未確認のまま確定的に書かない。

## 6. 重点的に監査する誤り

|領域|確認する誤り|
|定義|標本分散の分母、ガンマの尺度・率、幾何分布の値域、尖度の定義などの不統一|
|確率|密度と確率、独立と排反、条件の分母の混同|
|推測|母数と推定値、SDとSE、信頼区間と信用区間の混同|
|検定|p値の逆確率化、非有意と同等性の混同、事後的な片側化|
|回帰|因果の過剰解釈、外挿、独立性・分散の仮定を無視|
|証明|正則条件の省略、逆が成り立たない推論、定理の循環参照|
|計算|丸め、数値誤差、極端な確率、自由度、単位の不一致|
|試験対応|旧版の混入、出題範囲と教材の深さの混同、1級応用の欠落|

## 7. 訂正の扱い

誤字、説明の改善、数値・解答の訂正、定理・適用条件の訂正を区別する。重大な訂正は、対象教材と問題の版、変更内容、影響するコース・学習目標を記録する。

誤答を学習者の誤りとして保存していた場合は、問題版の訂正に応じて進捗を再評価できるようにする。重大な誤りを見つけたページは、訂正まで公開範囲を制限する選択肢を持つ。

## 8. 利用者テストと改善指標

初学者、2級学習者、準1級・1級学習者を分けて観察する。人数や合格率を大きく見せるための集計はしない。最初は少数の定性観察で問題を見つけ、比較可能な課題で改善前後を確かめる。

|指標|測りたいこと|解釈上の注意|
|目的の教材への到達|入口と検索の分かりやすさ|クリック数だけでなく迷いを観察|
|初見の応用問題への正答|説明を別の文脈へ使えるか|同じ問題の暗記と区別|
|誤解の再発|誤答説明が機能したか|回答数の少ない概念を断定評価しない|
|補習後の復帰|前提への戻り道が機能するか|本文の放棄と区別|
|必要な証明の発見|詳しい情報を見つけられるか|証明の開閉回数だけで理解としない|
|範囲の実対応|公開・確認済みの目標が揃っているか|予定記事や未確認の問題を含めない|
|訂正の追跡|品質問題を放置していないか|訂正件数が少ないだけで高品質としない|

これらは測定候補であり、現在のサイトの実測結果ではない。合格を保証する数値モデルや、根拠のない「競合より学習効率が何倍」といった表現は採用しない。
