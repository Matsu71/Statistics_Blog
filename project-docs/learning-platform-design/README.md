## 結論

**「級別に順番に学べる教科書」「必要なことを引ける辞典」「理解を確かめる演習」を、一つの教材基盤でつなぐ。**

初学者には直感・基本・使い方を見せ、詳しく知りたい人は導出・厳密な証明まで開ける。見た目の簡潔さを保ちながら、数学的な内容を省かずに深くする。

現在の2級中心の構成を上限にせず、4級・3級・2級・準1級・1級数理・1級応用4分野までの骨格を設計した。既存の良い原稿・Astro等の基盤は再利用候補とし、構成を変えること自体を目的にしない。

## 重要な設計判断

### 1. 同じ概念を級ごとに複製しない

「正規分布」の説明は一つの正本にする。基本的な確率の読み方と、正規化の厳密な証明を同じページの異なる層に持たせる。各コースは必要な層を参照する。用語索引・公式索引も同じ正本につなぐ。

### 2. 初学者に証明を強制しないが、証明を省略して浅くしない

基本に必要な条件は開いた状態で示す。証明は内容と必要数学を明記して折りたたむ。証明を読まないと基本コースが修了できない設計にはしない。一方、上級者が開いたら定義・途中式・根拠まで確認できるようにする。

### 3. 「式の証明」を曖昧にしない

正規分布なら、密度を指定する定義、正規化定数の導出、平均・分散の確認、変数変換、現実へのモデル適用を区別する。「標準化したらどんなデータも正規分布になる」といった誤解を防ぐ。06に具体例を記載した。

### 4. 準1級は2027年の範囲変更に対応する

公式の2026年末まで・2027年以降の範囲表を分けて確認した。受験予定時期に応じた範囲版と、以前の学習から補う項目を管理する。新しい表で明記・整理された項目を、すべて新規出題と決めつけない。根拠は01のE07〜E09。

### 5. 1級は数理だけで終わらせない

統計数理に加え、人文科学・社会科学・理工学・医薬生物学の応用ルートを分ける。共通の方法論を再利用しながら、分野の文脈・研究設計・答案の解釈を扱う。根拠は01のE10〜E11。

### 6. 記事件数より、到達目標の実対応を測る

307は制作候補の数であり、現在の公開数でも最終的な上限でもない。薄い記事を件数のために作らず、必要に応じて統合・分割する。公開済みの本文・演習・確認記録が揃った目標だけを範囲対応として数える。

## 制作の優先順位

最初の主コースは、既存資産を活用しやすい2級を軸とする。ただし4・3級の専用ルートと基礎補習も設ける。その後に準1級、1級の数理・応用へ拡張する。これは制作順序の提案であり、サイトの最終対象を2級に限定するものではない。

P1では14教材で「読んで理解する→問題で確認する→誤解を直す→次へ進む」という一連の体験を完成させる。その品質基準を固めてから全体を増やす。AIチャットや課金機能より、本文・数学・演習・学習経路を優先する。

## 既存リポジトリとの関係

この文書群は次期の内容・体験の方針である。現行の `AGENTS.md`、schema、キュー、生成Skillを書き換えたものではない。実装時には、新しい方針に合わせてそれらを一緒に更新し、矛盾する指示を残さない。既存ファイルを移行するまでは現行形式を不用意に壊さない。

既存の `src/`、`data/term-queue.json`、公開生成物 `docs/` は今回変更していない。サイトを再構築・公開したとは扱わない。
