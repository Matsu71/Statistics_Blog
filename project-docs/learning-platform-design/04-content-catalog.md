# 教材ページ候補一覧

作成日: 2026-09-11 / 状態: 設計段階。以下は公開済み記事数ではない。

## 読み方

24分野・307の教材単位を設計候補として整理した。既存記事と照合して改稿・統合・新規作成を決めるための棚卸し表であり、307本を一度に公開したり、各用語を機械的に別ページ化したりする指示ではない。

- `Mxx-yy` は設計上の固定ID。公開URLのslugや既存原稿との対応は移行台帳で管理する。
- 各項目の初期状態は一律 `planned`、試験対応は `candidate`。対応級の記載は制作上の候補であり、公式の全小項目との対応を保証しない。
- P1: 代表教材と学習導線の試作。P2: 4・3級の基礎と2級の範囲を完成。P3: 準1級、2027年版を含む。P4: 1級数理・4分野の応用と発展。
- 分野に複数の段階がある場合、基本説明を先に、導出・証明・発展を後から完成させる。分野全体を終えないと次へ進めないという意味ではない。
- 「主な参照元」は概念のつながり。参照分野の全教材を必修にするものではない。必須前提は各教材の各表示層に設定する。
- 同一概念の正本は一つにする。比較・手法選択・論述問題のページは、正本の説明を複製せず、使い分けや統合に焦点を当てる。
- 例: M07-08の正規分布は面積・式・使い方・正規化の証明を内包する。M07-09は正規分布の説明を繰り返さず、標準化の操作と分布表の違いを扱う。
- 非心分布、Box–Cox変換、コルモゴロフ–スミルノフ検定、指数平滑法などは下記の複合教材内の節として割り当てる。小項目は `03-curriculum.md` の対応ルールと制作時の対応表で検証する。

数学を全員に先に履修させず、統計の教材から必要な節へ戻れる構造にする。1級の応用ページは数理の代替ではなく、共通理論と組み合わせるケース教材である。

## 公開ページにする際の分割・統合ルール

一つの学習単位は一つの中心的な問いを持つ。短い内容を件数のために分割しない。一方、複数の独立した到達目標を持ち、前提が大きく異なる内容は制作時に分割してよい。その場合はIDの廃止・追加・移行先を記録し、件数を再計算する。

全ページ共通で必要なのは、到達目標、前提、基本説明、条件、例、理解確認、関連先、出典・確認状態。証明が必要なページでは証明を追加する。「証明に適さない用語」に架空の証明を作らない。

## 横断的な索引・教材は別管理

級別コース、公式索引、分布比較、誤解対比、可視化、問題バンク、事例、訂正情報は、上記307教材とは別の画面・データ種別として管理する。検索ページや問題の派生URLを教材本数に加算しない。画面構成は `02-information-architecture.md` を参照。
