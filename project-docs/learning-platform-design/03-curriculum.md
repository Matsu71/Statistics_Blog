## 1. 設計原則

主ルートは「基礎 → 4級相当 → 3級 → 2級 → 準1級 → 1級数理・応用」。これは知識の積み上げを示すもので、全級の受験や合格を必須にするものではない。公式FAQでは過去の合格実績等による受験制限は設けられていない [E12]。

級と数学的な深さを分離する。例えば正規分布の面積を読む学習と、二重積分による正規化の証明は、同じ正本ページにあっても異なる学習目標である。2級ルートで任意の証明を読まなかったことを「未修了」にしない。

数学補習は随時参照する。初学者にM01・M02の全教材の履修を先に要求しない。

## 6. 試験外の発展と並行コース

測度論の入口や高度な証明の一部は、理解を支える任意の発展として明示する。公式範囲にないものを必須として水増ししない。

調査士系・DS系は別の資格系列として扱う [E13]。将来、共通教材を再利用する専用ロードマップを作れるが、今回の4級〜1級コースだけでDS系等への完全対応を名乗らない。ソフト操作・実務事例のコースも試験コースと分離する。

## 7. 対応表は「記事の有無」ではなく到達目標で管理

実装時の最小行構造:

```json
{
  "objective_id": "g2-normal-tail-01",
  "syllabus_id": "grade2-snapshot-2026-09-11",
  "source_id": "E06",
  "source_locator": "p.1 / 確率分布 / 正規分布",
  "objective": "標準化し、片側と両側を区別して確率を求める",
  "lesson_id": "M07-08",
  "section_ids": ["core", "worked-example"],
  "required_depth": "basic",
  "question_ids": [],
  "coverage_status": "planned",
  "review_status": "not_reviewed"
}
```

ここでの到達目標文は編集側が学習用に定義したもので、公式表の逐語的な転載ではない。`source_locator` は公開前に実物の小項目と照合する。

状態は `unmapped → planned → drafted → reviewed → published` とする。対応率の分子に入れてよいのは、公式項目との対応確認、必要な本文、解答付きの適切な問題、必要な数学検証がすべて揃った目標だけ。予定ページへのリンクだけでは分子に入れない。

「読める」「計算できる」「結果を解釈できる」「証明できる」は必要な場合に別の目標へ分ける。証明が試験ルートで任意なら、証明未読を基本コースの不足と数えない。

## 8. 検証と更新

- 初版では範囲表の全行を読み、各小項目に対応先・根拠・状態を付ける。対応先なしを空欄のまま隠さず、未対応として残す。
- 公式の変更検出は制作運用上の作業として定義し、実際の定期実行を設定していない限り「自動監視中」とは表示しない。
- URL切れ、版変更、公開日と発効日の違い、教材の統合・移動を履歴に残す。
- 各級の公開前に、範囲・数学・演習の三つを別観点で監査する。
- 「全範囲対応」「このサイトだけで合格できる」は本設計から自動的に導かれない。前者は対応表の検証完了後に限り、後者は合格を保証する表現として使わない。
