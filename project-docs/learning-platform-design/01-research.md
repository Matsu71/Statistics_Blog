## 3. 競争上の方針：個別機能ではなく、学習のつながりを強くする

本サイトの差別化は次の組合せに置く。効果は今後の利用者テストで検証する仮説であり、既に競合を上回ったという評価ではない。

1. **試験範囲と学習内容の対応が見える。** 「この級の何が学べるか」を、公開済みの本文・演習の到達目標単位で確認できる。記事予定があるだけでは対応済みにしない。
2. **つまずいた場所から戻れる。** 分散、平方根、積分などの前提をその場で補い、元のページ・読書位置に戻る。初学者に長い数学コースを先に完走させない。
3. **一つのテーマを深くできる。** 基本説明は短く保ち、導出・厳密な証明・発展問題を段階的に開ける。級ごとに同じ説明を複製しない。
4. **誤りの理由で復習先を選ぶ。** 正答率だけでなく、「密度と確率」「標準偏差と標準誤差」「片側と両側」などの混同を記録する。
5. **試験後にも使える。** 用語、公式の条件、手法の選び方、再現可能な事例を辞典として引ける。

「動画が多い」「数式が多い」「記事数が多い」だけを目標にしない。最初の価値は、初学者が説明を読み、適切に使い、必要な人が証明まで確かめられることにある。

## 4. 既存リポジトリから確認したこと

調査開始時の参照コミット: `cf7100b613496ec12ef239cddd43a05004ae3512`。

- README上は Astro + TypeScript、KaTeXを使う静的な学習サイト。公開生成物は `docs/`、原稿は `src/content/terms/` 等に分離されている。
- 現行AGENTS.mdは統計検定2級の用語ページを主軸としている。今回の設計は対象級・学習導線を拡張する次期方針であり、既存の「2級中心」を上限にしない。
- `normal-distribution.md` には既に直感、数式、具体例、厳密説明・証明の項目がある。「今は証明が全くない」とは評価しない。
- 同ページの証明部分は主に標準化の概略である。密度の正規化、変数変換の根拠、定義とモデルの区別などを追加する余地がある。平均0・分散1だけでは標準正規分布と確定できないため、変換後の密度まで示す。
- 書誌情報を著者・版・節・URLなどで特定できる形に改善する。現在の一般的な書名だけでは根拠への到達が難しい。

上記は代表ファイルの確認であり、既存全記事を監査した結果ではない。既存の構成に合わせて学習設計を縮小する必要はないが、利用できる基盤まで理由なく捨てる必要もない。

## 5. 統計検定についての重要な確認

公式の級別ページと出題範囲表を正本とする [E01–11]。範囲表のPDFは画像としてのページ表示も確認した。

- 準1級の公式ページには、2026年12月31日までと2027年1月1日以降の二つの出題範囲がある。学習開始年ではなく、想定受験日に対応する版を選ぶ。
- 1級は統計数理と統計応用を区別する。応用には人文科学・社会科学・理工学・医薬生物学の4分野があり、数理だけを厚くして全体対応を名乗らない。
- 3級にも確率分布や推測の基礎がある。「4・3級は記述統計だけ」と単純化しない。
- 4級から順に受験しなければならないという条件はない。学習順序と受験資格を混同しない [E12]。
- 料金、実施日、持込物など変動する情報は教材本文から分離し、公式案内へのリンクと確認日で管理する。

## 6. オリジナル教材と出典の運用

試験運営者のFAQには、問題・名称・ロゴの使用に関する条件と、非公開CBT問題を使用できない旨がある [E12]。本プロジェクトは次を採用する。

- 他サイトの記事・図・問題の言い換え量産はしない。学ぶ順序などの設計原則を参考にし、説明・数値例・図・演習は独自に作る。
- 本試験問題の記憶再現、無断転載、数値だけ変えた転載を制作方針にしない。公開範囲に対応したオリジナル問題を作る。
- 過去問は原則として公式の掲載場所・書籍を案内する。転載を検討する場合は対象・用途ごとの条件と許諾を確認し、記録する。
- データ・写真・図版・コードは素材単位で出所とライセンスを記録する。「無料で読める」と「再配布できる」を区別する。
- サイト名・説明文・広告に「公式」「公認」を誤認させる表現を置かない。名称等の利用条件の確認は公開前の必須項目とする。
