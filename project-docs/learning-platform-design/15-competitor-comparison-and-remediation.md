# 基礎コースの比較・不足改善

比較日：2026-09-11。対象は公開されている目次と同テーマの代表教材。全教材・動画全編・有料講座の実機評価や、学習者を使う比較実験ではない。

## 結論

基礎40講座を、単なる用語の追加ではなく「説明→例→問題→根拠→復習」にそろえる。参照教材の強みを分けて比較し、初期原稿に不足していた操作型教材、図、検索・復習、試験範囲の対応、訂正窓口を補完する。これは実装上の改善であり、競合より学習効果が高いと実証した結論ではない。

## 公開後の改善の優先順位

最初は、実際の初心者による読了・初見問題・証明の発見・復習の観察と、独立した数学レビューを優先する。本文が長い箇所は、その観察に基づいて分割や図への置換を判断する。次に実データ事例と問題バリエーションを追加し、その基盤を使って2級コースを制作する。

動画、AIチャット、課金、ランキングを先に追加して、説明と問題の点検を後回しにしない。初期版の公開可否は40講座が途切れず利用でき、条件・計算・問題・表示に確認済みの重大な欠陥がなく、訂正の入口があることを基準にする。比較実験で競合への優越性を示すこととは別の判定である。
