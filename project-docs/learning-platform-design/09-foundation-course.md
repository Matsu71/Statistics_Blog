# 基礎コースの構成・教材分量・初期実装

決定日：2026-09-11 / 適用：本書を、初期設計01〜08に優先する。

## 1. 今回確定した学習順序

**基礎（4級・3級の内容を統合）→2級→準1級→1級**。

完全な初心者が基礎から始め、最初の資格目標として3級を考えられる構成にする。独立した4級コースは設けない。ただし、4級の内容を削除するのではなく、割合、表・グラフ、データを調べる考え方などを基礎の中に含める。知っている内容を飛ばして進んでもよい。

3級の基礎は記述統計だけではない。公式出題範囲には確率、二項・正規分布、正規近似、標本平均・比率、平均・比率の区間推定と検定も含まれる [E3]。ここまでを段階的に扱い、2級で数式・適用条件・手法をさらに深める。すべての級を順に受験しなければならないという条件は作らない。

最低目標は参照教材と同程度の明瞭さ・正確さ・具体性。さらに前提への戻り道、任意の導出、誤解を診断する問題、公式範囲との対応を一貫させる。現時点で参照教材より高品質と実証されたわけではない。文章・図・問題を転載・言い換えで量産せず、構造と説明の役割を参考に独自制作する。

### 一講座の公開ゲート

- 中心的な問いと1〜3個程度の到達目標がある。
- 初出の用語を説明し、前提の講座へ戻れる。
- 具体例があり、計算には対象・単位・分母・途中の理由がある。
- 重要な使用条件・例外を基本の表示から読める。
- 図、表、比較、手順の少なくとも適切な一つが理解を助ける。
- 3問以上の独自問題があり、解答・理由・典型的な誤解を説明する。
- 詳細が適切なテーマでは、導出、論拠、反例、厳密な定義を折りたたむ。すべてに無理な「証明」を作らない。
- 出典を特定でき、具体例を実測と誤認させない。
- 数式・表示・リンク・小画面・キーボードの確認が済んでいる。

## 3. 一ページの分量

字数を達成するための水増しはしない。最初の制作目安は次の通りとする。

|部分|分量の目安|含むもの|
|---|---|---|
|基本の説明・例|日本語本文で約1,500〜2,500字|導入、定義、数値例、表・図の説明、使用条件、典型的な誤り|
|確認問題|原則3問、計算中心なら3〜5問|概念・数値・解釈の異なる問い。解答は最初は閉じる|
|詳しい説明|必要に応じ約400〜1,200字以上|根拠、反例、途中式、証明。内容が長ければ論点ごとに分ける|
|全体|約2,500〜4,500字を中心とする|基本・問題・解答・詳しい説明。式や図の多いページは柔軟に調整|

読む目安は8〜12分程度、問題を考える時間は5〜10分程度から設定する。これは編集上の想定であり、閲覧者の実測速度や学習効果を意味しない。初期6講座には個別の目安を表示する。

文字数の機械計測では、frontmatter、HTMLタグ、URL、数式、出典欄等を除いた近似的な本文文字数を記録する。表・図・記号の学習負荷を文字数だけで評価しない。公開条件は目標・例・問題・条件が揃っていることであり、上記字数の厳密な下限・上限ではない。

最初に開いている部分を短く読みやすくし、必要な人だけ詳しく読める構成にする。ページ分割は読了時間だけでなく「一つの問いを完了できるか」で判断する。

## 6. 今回の実装範囲

最初の6講座を原稿・画面として実装する。第1章5講座を連続して読み、そのまま第2章の割合へ進める。

|ID|講座|具体例・詳しい説明|
|---|---|---|
|F01|統計で答えられる問いをつくる|6件の待ち時間、記述と推測、未観測部分が違う二つの全体の反例|
|F02|データの1行・1列は何を表すか|4回来室・3人・3件の記録、欠測と0、人/来室で平均が変わる理由|
|F03|データの種類と4つの尺度|番号・満足度・温度・時間、単位変換の式で差と比を確認|
|F04|母集団・標本と偏りのない選び方|4人から2人を選ぶ全6通り、標本平均の変動、等包含確率とSRSの違い|
|F05|観察と実験を区別する|案内改善の観察/実験、抽出/割付、潜在的結果の入口|
|F06|割合・百分率とパーセントポイント|20人中15回答6賛成、分母の異なる面積図、未回答を含む論理的上下限|

各3問、合計18問。F06には意味の異なる二つの分母の棒図を用意し、他のページも表・比較・流れ図などを使う。いずれも説明用の架空データと明記する。独立した第三者監修は未実施で、確認状態を自己点検と表示する。

### 実装する画面動作

- ホームとヘッダーから学習コースへ進める。
- 40講座の目次では、本文がある講座だけリンクにする。残りは準備中で、空のページへ飛ばさない。
- 基本説明・重要な条件は開いた状態で表示する。解答・発展はnative detailsで開閉する。
- 基本の文章・表・式はJavaScriptが無効でも読める。
- 目次、前提講座、直前/直後の講座へのリンクを付ける。
- 折りたたみ内へのhashリンクでは必要な部分を展開する。
- すべて開く/閉じる、印刷時の展開、印刷後の元の状態への復帰を用意する。
- 既存の用語ページを削除せず、辞典と順序教材の両方を使えるようにする。

自動採点、検索内の証明索引、学習履歴、弱点の自動分析、操作型シミュレータ、2級以降の順序コース全体は今回未実装。前の設計にある機能がすべて使えるようになったわけではない。

## 7. 本文の重複と正本の扱い

今回の6講座は旧用語ページを無理に全面置換せず、学習順序を持つlessonsコレクションとして追加する。既存termsは辞典として維持する。307候補のcatalog IDを構成データから参照し、同じ概念を将来別の級で二重に量産しない。

現時点では用語記事と基礎講座に説明の重なる箇所がある。これは段階移行であり、完全に共通化された単一正本基盤が完成したとは扱わない。共通の定義・公式・証明を抽出する段階では、両方を照合して参照先を一本化する。いま共通化するためだけに、初心者の文脈を細切れのリンクへ分解しない。

## 8. 検証と次の制作

内容の構造・ID・依存関係・問題数・計算例・生成HTMLを `scripts/validate-foundation.mjs` で検証する。既存サイトについてもgenerate:index、strict content validation、lint、Astro check、build、内部リンク検証を通す。Playwrightで各講座の基本表示、開閉、キーボード、深いリンク、印刷時展開、小画面の横はみ出しを確認する。

テストの実際の状態・件数は [10-foundation-validation.json](10-foundation-validation.json) に記録する。自動テストの成功は、教育効果や第三者の数学監修の代替ではない。スマートフォン実機での利用者テストは別途必要。

次の制作対象はF07（度数分布表と累積度数）から。F08〜F11を加え、第2章を完成させる。その後は代表値・分散へ進む。予定本数を埋めるより、初期6講座と同じ説明・問題・検証の基準を維持する。
