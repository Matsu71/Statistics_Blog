## 保存方針

検証用ブランチ `content/foundation-complete-20260911` に章ごとに原稿・実装と本ファイルをコミットする。未完成の内容は公開中のmainへ混ぜない。全件検証後に生成物docsも含めmainへ反映する。外部実行・監修・利用者テストは、実際に行ったものだけを記録する。

作業が中断した場合は、この文書とブランチ最新コミット、CIの結果から再開する。最終報告には完了内容・未完了内容・次にやることを必ず明示する。

## リリース判定

1. F01〜F40がすべて実ページとして開き、原稿と講座データが整合する。
2. 全講座に解答付きの独自問題があり、計算・式・重要な条件を確認できる。
3. 公式範囲の項目と教材/演習の対応を確認し、対応していない部分を隠さない。
4. ビルド、既存用語を含むリンク、数式、ブラウザ操作を検証する。
5. 競合の実際の教材を比較し、足りない点・改善した点・将来に残す点を記録する。
6. 誤った解答・欠落した本文・使用不能な導線など、学習を妨げる重大な欠陥を残さず公開する。

第三者の数学監修や学習効果の比較実験を行わない限り「第三者監修済み」「競合より効果が高い」とは表示しない。
